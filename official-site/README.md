# コタマのぼうけん 公式サイト

ゲーム本体とは独立して公開するための紹介サイトです。

## 運用方針
- 公式サイトとゲームは**別の公開URL**にします。
- このフォルダの `index.html` と `site-config.js` を公式サイト専用のホスティング先へ配置します。
- `site-config.js` の `gameUrl` に**ゲーム本体の正式なURL**を設定します。現在の値は候補URLであり、動作確認済みではありません。
- 「ゲームを始める」はその外部URLに移動します。ゲームの公開設定や認証はゲーム側で管理してください。
- 公式サイトのキャラクター画像は `../assets/` を参照しています。別ホスティングでは画像を公式サイトの `assets/` に複製してパスを変更するか、別途配信する必要があります。**現状のままでは別サイトで画像が表示されません。**
- ゲームの `index.html` などゲーム本体のファイルを公式サイトにコピーしないでください。
- 検索エンジンへのインデックスは現時点で `noindex` に設定しています。公開時に見直してください。
