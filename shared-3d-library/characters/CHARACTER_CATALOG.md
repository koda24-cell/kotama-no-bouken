# Character production sources and pipeline

## Head / face
Use an editable head mesh with real eye, mouth, nose, ear and jaw geometry; inspect front/profile/three-quarter before applying materials. VRoid source assets require license verification for each model.

## Hair
Start from scalp-fitting cap and directional guide curves; generate uneven broad and fine locks; inspect eye occlusion and head penetration in all three views. HairMesh requires Blender 5.1+ and is currently untested in the runner.

## Clothes / body
Keep base anatomy and clothing separate, record rig and bone naming, test deformations and retargeting before reuse. No downloadable third-party character source has been committed to this library yet.
