# Reusable 3D workflow

1. Read ../README.md and relevant catalog; select licensed source/tool.
2. Download from upstream; save version, original URL, license, SHA-256 and redistribution rights in a manifest.
3. Install/test addon in isolated Blender version; report pass/fail.
4. Preserve original meshes; add editable non-destructive geometry.
5. Render front, side and three-quarter PNG, inspect intersections and silhouette.
6. Export GLB only when needed; verify reimport and animations.
7. Ask user approval before promoting to official game assets.

This workspace is independent in purpose, but **currently physically located in Kotama repo on an isolated feature branch**, not a standalone GitHub repository. Entries marked catalogued are pointers, not downloaded files.
