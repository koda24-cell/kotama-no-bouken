# 第3階層：崩壊した廃ビル（試作）

参考コンセプトに沿った制作仕様。**画像はコンセプトであり実モデルのレンダリングではない。**

## モデル仕様
- 3階建ての鉄筋コンクリート廃ビル、各階の床・柱・梁を別メッシュで構成する。
- 外壁は不規則な欠損を設け、破断面には厚みと鉄筋を付ける。
- 右側を大きく崩し、露出した錆びた鉄骨・階段・窓枠・瓦礫を配置する。
- 屋上・外壁にはツタと草木を配置。通路を塞がないようゲーム内の衝突形状を分離する。
- 標準型・高層型・骨組み露出型・崩落特化型・再生侵食型の派生を想定する。

## 検証と承認
1. Blenderまたは検証済みの同等ツールでGLBを実際に書き出す。
2. 正面・側面・斜めの3方向PNGを**実モデルから**レンダリングし確認する。
3. Three.jsの実機画面で視認性、LOD、描画負荷、コリジョンを確認する。
4. 承認後に正式素材フォルダへ昇格。未承認の素材はゲームへ統合しない。

既存ゲームコードと既存モデルは変更しない。統合先はdevelopment、mainには触れない。
