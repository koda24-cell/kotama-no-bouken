### 1-9. セーブ・全滅
- `createSaveData()`（script.js 762行）：**saveVersion 11**。保存先はオートセーブ `fantasyRpgSave` ＋手動スロット `kotamaSaveSlotN`。
- **手動セーブは画面上部メニューからいつでもできる（戦闘中も）**。`updateListMenuForScreen()` で SAVE ボタンは常に表示。戦闘中のセーブは `slot.battle` として戦闘開始地点を保存。
- オートセーブ `persistAutoSave()` は、採集・宝箱・階段・勝利・敗北・ホーム帰還のたびに実行。
- **全滅（迷宮）**：`fieldOnDefeat()` が「ホームで態勢を立て直そう」と表示し、**そのまま `persistAutoSave()`**。その探索で得たお金・経験値・素材はすべて残り、次の出発で無料全回復。**ペナルティは無い。**
- 全滅（ボス戦）：`finishDefeat()`。「その戦闘の報酬なし」で再挑戦／ホームへ。それ以外は残る。
- **未統合 PR との衝突**：GPT PR #34（控え管理）も「saveVersion を 11 にする」と書いている。development は既に 11（採集の状態）。#34 を移植するときは**別の番号（12以降）に振り直しが必要**。

## 3. 修正案の一覧

**セーブの方針（全体）**：B の案でセーブ項目を増やすものは**まとめて saveVersion 12 に1回だけ上げる**（B-18）。旧セーブ（11以前）は既定値で補う。GPT PR #34 を移植する場合も 12 に含めるか 13 にする。

## 4. コタマの設定を変える案（大胆案）

### 4-1. ホームを「ふもとの村」の街にする（推奨）

- メリット：世界樹の「街で準備→迷宮→持ち帰る」の流れが画面の形で伝わる。施設ごとに役割が分かれ、ボタンの意味がわかりやすい。

- デメリット：2つの時間がある理由をプレイヤーに説明する必要がある。
- 代案：宿に泊まると採集も全回復（世界樹に近い）。ただしこの場合、宿代を払えば素材が無限に取れるので、宿代を高くする必要がある。

- FOE の復活を「ホームから出発するたび」（`field-navigation.js` 38行 `fieldState.foeDefeated = {}`）から「宿に泊まった日数」に変えたい（B-05）。撃破日 `foeDefeatedDay` のセーブは B が用意する。復活の日数（推奨3泊）と判定場所は A で。
- 「ホームへ」ボタンを入口付近だけにする判定（B-08）：各階層1階の開始位置からの距離か、入口マスの指定を A のマップデータに持ってほしい。
- 元老院ミッションでボス門を閉じる案（B-20）：`fieldOnGate()` の `gateRequires` にミッションのフラグを足す形で。
- 採集点の追加（レア枠つき）は `data/field-gathering.js` のみで行い、マップ文字列は触らない（現行どおり）。

### Claude C（戦闘・職業・敵・ボス）
- **第4・5階層の雑魚と FOE（サラマンダー・黒騎士団長）が素材を落とさない**（`dropAs` なし）。B-03 で `data/drops.js` を作るので、敵データ側の `dropAs` は触らなくてよい。
- 条件ドロップ（B-09）のため、敵を倒した最後の一撃の情報（属性・スキルID・使用者・その時の状態異常・封じ・ターン数）を `finishStage()`／`fieldFinishEncounter()` に渡してほしい。`battleEmit` に `defeat:info` のようなイベントがあれば B で拾う。
- 敵のゴールド削減（B-04）は `data/field-enemies.js` の数値なので合意が必要。
- 新アイテム（蘇生・状態異常回復・封じ解除。B-12）の戦闘中の効果処理。
- 全12職のスキルツリー（B-13）の中身と、能力値の対応（B-19、GPT #48・#50〜#53）。
- 5人・前後列（B-15）のバランス。

### GPT（画面）
- 店の「売る」タブ・「必要な納品 2/3」表示（B-01・B-02）。GPT #55 の売却 UI は**強化・育成画面ではなく店に**置く方向で。
- ホームを村にする場合の施設画面（§4-1、B-21）。
- 迷宮内のアイテム使用メニュー（B-08）。
- 図鑑の ITEM 欄・アイテム図鑑（B-17）。
- GPT #34 の saveVersion 11 は development と衝突するので、セーブ部分は B に任せてほしい（B-18）。
