### 1-2. ランダムエンカウント
- `fieldRollNextEncounter()`：`encounter.min`〜`max` の一様乱数で「次の戦闘までの歩数」を決め、0から数える。草むら `*` は1歩＝1.5歩分（`fieldAfterMove`）。安全地帯の上は数えない
- フロア値：第1階層 16–28／15–26／15–26 … 第5階層 12–22（深いほど短い）
- 危険度：`fieldUpdateDanger()` が「歩数÷次の戦闘歩数」で 0〜4（青→赤）。**残り歩数をそのまま色にしている**
- 戦闘は**常に敵1体**（`battleState.enemy` 単体。`fieldCreateEnemy` が1体を返す）

### A-01 FOE の戦闘乱入（第1段：連戦方式）
- **優先度**：P0
- **内容**：
  1. `field/field-movement-foe.js` に `fieldFoeBattleTick()` を新設。`battle:turn:end`（`script.js` 1459行の `battleEmit("turn:end")`）を `battleState.encounterMode` のときだけ受け、**戦闘1ターン＝FOE 1ターン**として、戦っている相手以外の各FOEを `fieldFoeTurn` と同じ規則で動かす（プレイヤーは動かない。`fieldFoeTurn` から「プレイヤーの移動に依存しない部分」を `fieldFoeAdvance(a, pt, opts)` として切り出して共用）。
  2. FOE がプレイヤーのマスに着いたら `battleState.foeReinforcements.push(f.key)`、戦闘ログに「◯◯が乱入してくる！」。到着の1ターン前に「足音が近づいてくる……（あと1ターン）」を出す（予兆。推測。GPT に表示依頼）。
  3. **第1段（敵1体のまま）**：今の敵を倒したら、勝利画面を出さずに `fieldStartEncounterBattle(foe.enemy, { foeKey, chained:true })` で**HP・SP・状態異常を引き継いで即FOE戦**。報酬は2戦分。「逃げる」成功時は乱入予定のFOEを移動前のマスへ戻す（逃走時の既存ルールと同じ）。
  4. FOE 戦の最中にも他のFOEは動く（FOE＋FOE の連戦もあり得る）。
  5. 第2段（A-01b）は C の複数敵戦闘ができてから。
- **世界樹の根拠**：I「1歩進むか戦闘が1ターン経過するごとに1歩移動」「戦闘中のマスに入ると乱入」（W1・確認済み）。III も乱入あり（W3・確認済み）
- **変更ファイル・関数**：`field/field-movement-foe.js`（`fieldFoeTurn` 分割・`fieldFoeBattleTick` 新設）、`field/field-interactions.js`（`fieldStartEncounterBattle`・`fieldFinishEncounter`・`fieldReturnFromBattle` に連戦分岐）、`script.js` は `[FIELD]` フック1行（`turn:end` は既存イベントで足りる見込み）
- **担当**：A（迷宮側）＋C（勝利処理・引き継ぎ）＋GPT（予兆・乱入演出、戦闘中ミニマップ）
- **規模**：M
