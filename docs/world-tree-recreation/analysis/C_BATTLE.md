## 1. 現状の事実（development 44c69e5）

### 1-1. 戦闘の骨組み
| 項目 | 事実（ファイル・関数） |
|---|---|
| 敵の持ち方 | `battleState.enemy` は**1つのオブジェクト**。集団は `enemy.members[]` で表す（いま使っているのはステージ2のゴブリンだけ：`script.js createEnemy()`）。オオカミの分身は別の仕組みで `battleState.wolfClones[]` に入る |
| 雑魚戦・FOE戦の敵の数 | **いつも1体**。`field/field-interactions.js fieldCreateEnemy(id, scale)` は `FIELD_ENEMIES[id]` を1体だけ作る。出現表 `floors[].encounter.table` も「敵1種類」を選ぶ形 |
| 敵の行動回数 | `battle-ext.js extBuildRoundOrder()` が入れる敵の順番は `{kind:"enemy"}` の**1つだけ**。ゴブリンが3〜5体いても、1ラウンドに動くのは「群れ全体で1回」（連携攻撃のときだけ「生きている数×3回」叩く） |
| 行動順 | 味方全員がコマンドを選び、優先度→速度の順で動く（`extBuildRoundOrder`）。優先度：ユニオン4＞防御系スキル3＞防御2＞速攻1＞その他0。速度は**職業ごとの固定値**（`data/jobs.js EXT_JOB_SPEED`：コタマ70・騎士40・治癒士55・戦士50・魔術師45・武士80・アサシン100…）。敵は `EXT_ENEMY_SPEED`・`speed`。**乱数が無いので毎ターン同じ順番**。チュートリアルだけは旧方式（選んだ順→敵） |
| ダメージ式 | `script.js calcDamage(atk, def, guarding)`：`max(floor(atk×0.1), atk−def, 1)`（防御中は 0.1 の下限なし）。乱数の幅・クリティカル・命中判定は**無い** |
| 回避 | 味方：装備の `evasionRate` 合計（上限50%）だけ（`partyEvasionRate`）。敵：オオカミの警鐘中30%・50%以下で1回だけ必ず回避、のみ |
| 防御 | `battleState.guarding[id]=actor.guardCut`。**職業ごとに軽減率が違う**（騎士80%・コタマ60%・戦士50%・武士35%・治癒士25%・魔術師20%）。ドラゴンブレス・黒炎・魔王フェーズ技は一律50% |
| 前衛・後衛 | **無い**。`EXT_REAR_IDS = [mage, healer, princess, gunner]` は、敵の `target:"rear"`（後衛狙い）とオオカミの狙いにだけ使われる。ダメージ補正は無い |
| 人数 | `script.js PARTY_LIMIT = 4`（5人は未統合 GPT #33） |
| SP（世界樹の TP） | 戦闘中は自然回復しない。迷宮では持ち越し、**ステージ戦（階層ボス）は `startBattle()` で HP・SP 全快**（`fieldOnGate()` → `startBattle(stage)`） |
| 逃走 | 迷宮の戦闘：撤退ボタンで**必ず成功・ターン消費なし**（`fieldSetupRetreatChoice`）。脚封じの味方がいると不可（`extEscapeBlocked`）。ステージ戦：撤退＝ホームへ |
| 先制・不意打ち | **無い** |
| 戦闘後の状態異常 | `extResetBattle()` が戦闘開始時に全部消す＝実質「戦闘後に回復」。戦闘不能（HP0）は迷宮で持ち越し |
| 15ターン制限 | **魔王だけ**。15ターン目に「破滅の光」で全員の HP を0にする（`enemyTurn()`）。ブレイク・スタン・イージスより優先。他の敵には制限なし |
| ブレイク | `BATTLE_RULES.break`（通常10・SP20・必殺30・ユニオン40、弱点×1.5・耐性×0.5）。ボスのゲージ：ドラゴン100・魔王150・混沌の幻影260。0 になると1回休み＋被ダメージ×1.2（`addBreakDamage`・`applyDamageToEnemyCore`）。世界樹 I〜III には無い本作独自の仕組み |
| ユニオン | 職業ごとのゲージ（`unionSkills`。必要4〜5回）。**行動するたびに +1**（`chargeGauge`）。戦闘不能で0。戦闘ごとにリセット。至高の魔弾（300・敵の次行動を妨害）、イージス（全快＋次の敵ターン無効）、フルヒーリング、メテオ（666）、一刀両断（攻撃×4・防御無視）、クロスブレイク（2人） |

### 1-2. 属性・弱点
- 属性：斬撃・打撃・壊・突（武器の `physicalElement`）＋炎・氷・雷・聖（スキル）。闇は敵専用（魔王・黒炎）。
- 倍率：`BATTLE_RULES.elements`＝弱点1.5／耐性0.5／無効0（`enemyElementMultiplier`）。段階は3つだけ。
- スライム型は物理を0.18倍（`calcEnemyPhysicalDamage` の `physicalDamageRate`）。
- 表示：`analyze-panel.js`・`script.js renderEnemyAnalysis()` が「弱点」「耐性」を**文字の一覧**で出す。**2回目の遭遇で開示**（`enemyEncounterCounts >= 2`）。状態異常の効きやすさは表示しない。図鑑（`monster-compendium.js`）も同じ一覧。

### 1-3. 状態異常（`data/status-effects.js`・`battle-ext.js`）
| ID | 効果（処理） | 敵→味方で使う敵 | 味方→敵で使えるスキル |
|---|---|---|---|

| poison 毒 | ラウンド開始時に最大HP×6%（ボスは2.5%上限） | キノコ・斥候・大蜘蛛・親衛隊長など | アサシン（毒刃・毒霧） |

| curse 呪い | 攻撃・SP攻撃−15%、回復量半分（世界樹の呪い＝与ダメージの反射とは別物） | 魔王・黒騎士・亡霊 | なし |
| sleep 睡眠 | 行動不能、被ダメージ×1.5、毒・火傷以外のダメージで起きる | **なし** | **なし** |
| confusion 混乱 | 50%で味方を殴る／敵はうろたえる | **なし** | **なし** |
| bindHead／Arm／Leg 封じ | 頭：頭スキル不可・敵は術不可とSP攻撃×0.6／腕：腕スキル不可・攻撃×0.6／脚：回避0・速度×0.5・逃走不可 | **なし** | **なし** |
| attackDown／defenseDown | 能力低下（世界樹では「弱体」で、状態異常とは別枠） | 多数 | リーパー・ガンナー |

- **複数の状態異常が同時にかかる**（1人の状態袋 `extStatusBag` に種類ごとに入る）。同じ種類は持続・強さの大きい方に更新（`addStatus`）。
- 付与率の式は1か所：`extStatusChance()`＝基本付与率 × 全体倍率 × （敵へ：ボスなら bossMul(既定0.5) × 敵の耐性 `ailmentResist` × ボスの累積0.5^回数 × 付与者補正）（味方へ：耐性補正・治った直後1ラウンド免疫・全員行動不能の上限）。補正の差し込み点 `extPartyAilmentResistMul()`・`extInflictorAilmentMul()` は**いまは1を返すだけ**。
- **`ailmentResist` を持つ敵は1体もいない**（データ未設定）。ボスだけ `bossDefaultResist`（睡眠・混乱0.3、封じ0.5）が効く。
- 封じとスキルの部位：`EXT_SKILL_BODY_PART`。腕＝charge・multiSlash・pierce・burst-blade、部位なし＝挑発・防御系、**それ以外はすべて頭**（通常攻撃は封じの影響なし）。新職業は `xj.kind` が phys なら腕。

- 雑魚10種・FOE5種。行動は `ai[]` の重み付き乱数（`extVariantAction`）。条件：`minTurn`・`hpBelow`・`everyTurns`・`target:"rear"`・`all`・`drain`・`heal`・`status`。**予兆つきの行動は無い**。
