# 世界樹の迷宮 参考資料・調査ガイド

この資料は『世界樹の迷宮』のゲーム体験を研究し、kotama-no-boukenへ再現するための参照先をまとめたもの。参照内容は公式説明と実機確認を分けて記録すること。

## 1. 公式資料

### アトラス公式：『世界樹の迷宮 I・II・III HD REMASTER』
https://sq-atlus.jp/sq123/

調査対象：
- 迷宮探索と地図作成の基本ループ
- 地図に記録する対象・記号・探索情報
- パーティ編成・職業・スキル・育成
- 階層攻略と迷宮の構造

### セガ公式：FOEの特徴・移動パターン
https://www.sega.jp/topics/detail/230320_2/

調査対象：
- FOEが通常敵と異なる存在として迷宮内に配置されること
- FOEの移動パターンを観察して回避する遊び
- プレイヤーの位置・タイミング・地形を使う判断

### 任天堂公式：『世界樹の迷宮』関連紹介
https://www.nintendo.com/jp/topics/article/6746519a-3a1a-452f-aa71-333c6faca071

調査対象：
- 弱点・耐性を利用した戦闘
- FOEや強敵の脅威
- 迷宮探索と戦闘準備の関係

## 2. 調査時のルール
- 公式資料に明記されている内容は「公式確認」として記録する。
- 公式ページに記載がない細かい仕様は、実際のゲームプレイ・取扱説明書・信頼できる攻略資料などで追加確認する。
- 作品ごとに仕様が違う場合、どの作品の仕様かを必ず記録する。初代・リマスター・後続作を混ぜない。
- 未確認の数値や内部式を断定しない。
- 参考作品の文章・画像・音楽・マップデータ・固有素材をコピーしない。ゲームルールと情報設計を抽象化して、本作独自の素材・名称で実装する。

## 4. 本作への適用方針
「世界樹の迷宮を再現する」は、単なる色・装飾の模倣ではない。地図を読む、FOEを避ける、探索資源を回収する、弱点・状態異常・敵の行動を読んで戦う、階層を攻略するという体験を再現することを指す。

本作の既存ストーリー・キャラクター・素材・5階層構成を保ちながら、ゲームプレイ上の核を実装する。
