## 3. 結論：「ボス逆転」の実態

1. **第1〜第3階層のボスは雑魚3Fより早く倒れる。** スキルを使えばスライム1ターン、ゴブリン2ターン、オオカミ3ターン。雑魚3F（2〜4ターン）と同じか短い。HP減少もほぼ0〜25%で、「節目」になっていない。
2. **固有ギミックが機能する前に戦闘が終わる。** ゴブリンの強打は「構え→次ターン」、連携は「構え→次ターン」だが、2ターンで全滅するので撃たれない。オオカミの分身は1ターン目に警鐘→2ターン目に分身なので、3ターンでは見る機会がほぼ無い。
3. **第4・第5階層のボスは数値上は雑魚より上だが、「対策しないと負ける」にはなっていない。** 対策なしで勝率100%。予兆（ドラゴンブレス・黒炎）に防御しても結果が変わらない。
4. **FOE の役割が逆転している。** 第1・第2階層の FOE は到着時に勝率100%（避ける理由が無い）。第4・第5階層の FOE だけが「避ける強敵」として成立。
5. **5人編成（#33）では全体が一段易しくなる。** 雑魚が約1ターン短く、FOE の到着時勝率が 15〜30ポイント上がる。C3 の目標値は4人基準で決め、5人は「余裕が出る」程度を許容する（5人を基準にすると4人で詰む）。
6. 未統合の GPT **#49 が同じ問題に対してボス数値を変更している**（スライム HP900／攻42／防22、ゴブリン 1体HP700／攻52／防22、オオカミ HP1800／攻76／防38。ドラゴン・魔王は据え置き）。C3 では #49 と二重に入れないよう、どちらの値を正とするかをユーザーに決めてもらう必要がある（§5-1 に両案の計測値を並べた）。

## 7. 計測の限界

- 行動方針は単純な自動操作で、プレイヤーの最適行動ではない（アイテム・製作装備・スキルツリー・新職業は使っていない）。
- 想定レベルは範囲の中央1点のみ。
- 描画・演出・入力の待ちは無効化しているため、表示やタイミングの不具合は検出できない。
- 5人編成は `state.party` を5人にしただけで、#33 のレイアウトや人数制限の変更は再現していない。
