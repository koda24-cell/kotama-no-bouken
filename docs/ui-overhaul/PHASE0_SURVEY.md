### 守る必要がある既存の結びつき（壊すと動かなくなる）
- **チュートリアルが `.main-nav [data-screen="formation"]`・`[data-screen="shop"]`、`#start-button`、`#retreat-button`、`#battle-party`、`#battle-enemy`、`.command-window`、`.command-info-window`、`.event-window`、`#turn-counter`、`#battle-commands [data-action=…]`、`#selected-party select[data-equip…]`、`#shop-items [data-buy-item…]` を強調表示に使う** → これらの ID・クラス・要素は残す。ヘッダーのナビは「メニューの中に隠す」のではなく「小さく1列にして常に見せる」
- `showScreen()` が `body[data-screen]` を設定済み → 画面ごとのレイアウト切り替えは CSS だけでできる
- 迷宮の DOM は `field-render.js` が実行時に作る（`#field-floor-label`・`#field-danger`・`#field-map-button`・`#field-minimap`・`#field-fog`・`#field-fullmap`・`#field-map-rail`）。GPT #98 の地図（`fieldDrawMap`・`fieldDrawMinimap`）は描画処理として残し、置き場所と大きさを変える

## 3. 実装方針（共通）

- **ゲームロジック・セーブには触れない。** 変えるのは HTML の配置・CSS・表示用の JS（描画の大きさ・置き場所）だけ
- CSS は新しい層を足して上書きするのではなく、**原因のあるルールはその場で直す**（例：`07` の minimap の絶対配置）。そのうえで、画面ごとの新しいレイアウトは次のファイルにまとめる（担当ごとに分けて同時作業の衝突を避ける）
  - `css/09-ui-base.css`：共通（ヘッダー・余白・文字・ボタン・safe-area・はみ出し防止）— Phase 1
  - `css/10-ui-field.css`：迷宮 — Phase 2
  - `css/11-ui-battle.css`：戦闘 — Phase 3
  - `css/12-ui-screens.css`：ホーム・編成・ショップ・育成・設定・図鑑・実績 — Phase 4
  - 4つの `<link>` は Phase 1 でまとめて `index.html` に追加する（後の PR で `<head>` が衝突しないように）
- 画面ごとのレイアウトは `body[data-screen="…"]` で切り替える
- スマホの基準：**390×844 で、迷宮・戦闘はページスクロールなしで1画面に収める**。一般画面は縦スクロール可だが、横はみ出しなし
- PC：横幅を使い、一覧と詳細を横に並べる
- 毎 Phase で 390×844・360×780・1280×800 の Before/After を撮影し、横はみ出しを自動計測する（`tools/ui-shots/`）

## 4. 画面設計

### 4-1. 共通（Phase 1）
- ヘッダーを1段に：左に画面名（ロゴは小さく）、右に GOLD と ☰。ナビ（ホーム・編成・ショップ・強化・設定）はその下に**高さ32px前後の1列**（狭いときは横スクロールするタブ）。チュートリアルの強調対象なので常に見える位置に置く
- 迷宮・戦闘ではナビを隠し、ヘッダーをさらに細く（画面名・GOLD・☰／撤退）
- `viewport-fit=cover` と `env(safe-area-inset-*)`。下部の操作は safe-area の内側
- DEV ボタンは迷宮・戦闘では左上の邪魔にならない位置へ移す（開発用。機能はそのまま）
- 文字・余白・パネル・ボタンの大きさを CSS 変数でそろえる

### 4-2. 迷宮（Phase 2・最優先）
スマホ縦（世界樹の「探索画面が主役、地図は連携する補助」）：
```
┌ HUD（1行）：1F 第1階層 はじまりの樹海 ｜危険度● ｜FOE警告 ｜MAP ｜ホーム
├ 探索画面（残りの高さいっぱい）
│   └ 右上に小さな周囲地図（9×9、1マス約11px＝約100px、半透明の枠）。タップで全体地図
│   └ 左下に小さな状態（座標・視界内FOE）
├ 正面の案内（1行）：「正面：宝箱　Aで調べる」（対象があるときだけ）
└ 操作：十字キー（左）／A（右）。safe-area の内側。押し間違えないよう離す
```
- 凡例は全体地図（MAP）の中と、周囲地図の「？」に移す（意味は変えない）
- 現在地の矢印を小さく（1マスの中に収める）
- PC（幅900px以上）：左に探索画面、右に地図列（周囲地図を大きく・状態・小さな凡例）。操作パッドは小さく

### 4-3. 戦闘（Phase 3）
- スマホ縦：上から「敵（大きく）＋ターン・LOG・敵/味方ボタン」→「メッセージ（1〜2行、敵に重ねる）」→「味方（2段に並べられる枠）」→「コマンド（縦の一覧）＋説明（コマンドの下に1行〜2行）」。ページスクロールなしで収める
- 敵が複数・味方が5人（上2・下3）になっても崩れない枠
- PC：敵とメッセージを上、味方を下、コマンドと説明を右

### 4-4. 一般画面（Phase 4）
- ホーム：パーティを2×2（スマホ）／横4（PC）の見やすいカード。START を主操作に。「冒険の記録」は別導線
- 編成：上にパーティ枠（小さなカード）、下に控え一覧。選んだ人の詳細・装備は下のパネル（スマホ）／右のパネル（PC）
- ショップ：カテゴリは横スクロールのタブ。一覧（名前・アイコン・価格・所持数）と詳細（説明・能力・装備比較・購入）を分ける
- 強化・育成：ツリーの領域だけを横スクロール可能にし、ノードを押しやすく。詳細は下（スマホ）／右（PC）
- 図鑑：一覧と詳細に分ける
- 設定・実績：共通の部品にそろえる
