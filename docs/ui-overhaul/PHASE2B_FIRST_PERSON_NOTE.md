- 前提：Phase 2 は俯瞰（上から見た表示）のまま、地図と操作の配置を整理した

## 描けるか
- 今のマップデータだけで描ける。迷宮は文字のマス目（`data/field-maps.js`）で、壁かどうかは `fieldOpaque`／`fieldWallLike`（壁に付いた物・開く前の扉・隠し通路は壁扱い）で判定できる。プレイヤーの向き（`fieldState.dir`）もある
- 描き方の案：Canvas 2D で「正面の奥3〜4マス × 左・中央・右」の壁・扉・床を、手前から奥へ決まった形で重ねて描く（世界樹の迷宮と同じ方式。レイキャストは使わない）。宝箱・採集・FOE は正面のマスにだけ絵を置く
- 新しいマップデータは不要

## 操作の変更（ここが一番大きい）
- 今は「上下左右へ1マス進む」。一人称では「前進・後退・左右に向きを変える（その場で回る）」になる＝**操作の仕様が変わる**
- 回転は1ターンに数えるか、FOE がその間に動くか、を決める必要がある（今は向きを変えるだけでは FOE は動かない）
- 押しっぱなしの連続移動（残す決定済み）は前進・後退にだけ効かせる案になる
- 周囲地図を「北が上」のままにするか「向いている方向が上」にするか
