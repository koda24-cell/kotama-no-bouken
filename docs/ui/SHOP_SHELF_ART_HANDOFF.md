# ショップ陳列棚 UI 画像差し替え

参考画像に合わせた棚・左カテゴリ・右店主・下部購入対象のレイアウト。画像はまだ提供されていないため、原本や第三者のイラストを追加していない。

- `shop-shelf.js` の `window.KotamaShopArt.merchant` に承認済みの透過店主画像の `./assets/...` パスを設定。
- `window.KotamaShopArt.items` は既存商品IDをキーとする画像パス辞書（例: `potion`）。画像未設定時は既存アイコンを維持。
- `css/18-shop-shelf.css` の `--shop-bg-image`、`--shop-shelf-image`、`--shop-counter-image` に必要な承認済み背景画像を設定。現状は `none`。
- 元の購入、装備比較、解放条件、売却、所持数、ゴールド処理は `script.js` の既存ハンドラーを使う。チュートリアルでは既存レイアウトに戻す。
- 店主・背景・商品画像は後日差し替え。未設定ファイルを推測して読み込まない。スマホ向けに画像容量と寸法を確認してから登録する。
- この時点で実ブラウザ表示は未検証。専用の構文・接続チェックと実際の購入／売却操作の確認を区別する。
