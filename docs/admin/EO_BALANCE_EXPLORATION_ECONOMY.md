# EO風バランス・探索・素材経済の追加

## このPRで反映した内容
- 魔術師の初期魔法「ファイア／フリーズ／サンダー」の消費SPをすべて15に統一。
- 迷宮の視界半径を3.6マスから4マスへ変更。
- 近距離の迷宮表示を拡大し、操作パッドと調べるボタンも大型化。全体マップは従来どおり別表示で遠距離把握用とする。
- 状態異常の付与率を上方調整。通常敵の行動による付与率を1.35倍、FOEを1.25倍にし、敵への付与はボス補正を従来より緩和。
- 迷宮3Fの通常敵スケールを1.30から1.15へ下げ、階層終盤の雑魚が階層ボスを不自然に上回る問題を抑える。\n- 第1〜第3階層ボスの基礎HP・攻撃・防御を引き上げ、HP50%以下で強化形態へ移行するフェーズ行動を追加。ドラゴン／魔王の既存変身も維持。
- FOEのHP・攻撃力を大幅に上げ、接触すれば通常パーティが壊滅しうる危険度に変更。
- 育成画面に素材一括売却を追加。素材ごとに売却額を表示し、所持分をまとめてゴールドへ換金できる。

## 調整値について
FOEの攻撃力は階層ごとに220 / 240 / 280 / 320 / 380。コタマの現行HPを基準に、一撃で戦闘不能になりうる設計を狙った初期値です。
素材売却価格は序盤素材5〜15G、竜素材50〜60G、魔王素材100G、隠し素材150Gを初期値としています。

## 未完了・後続調整
- 第1〜第3階層ボスにHP50%の強化フェーズを追加済み。専用技・行動パターンの差別化は実戦確認後にさらに調整する。
- FOEの巡回経路は各マップで通路幅・迂回路を見ながら個別に再設計する必要がある。今回はFOEの脅威度を先に変更。
- 状態異常の耐性・治療コスト・リフレッシュの使い所は、実戦確認後に調整する。
- ユーザー指定により、ブラウザ／実機の大規模確認は後段にまとめる。今回も動作テストは未実施。
