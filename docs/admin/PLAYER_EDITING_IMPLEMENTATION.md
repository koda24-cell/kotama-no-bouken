# 管理者パネル プレイヤー編集 実装メモ

## 実装した機能
- ゴールドを数値入力して適用。
- 所持仲間ごとのレベル・現在HP・現在SP・育成ポイントを編集。
- 所持アイテムの個数を編集。
- 素材の所持数を編集。
- 適用時に入力範囲・整数を検証し、現在のキャラクター最大HP/SPを超えないよう補正。
- 適用後に画面を再描画し、既存のオートセーブへ保存。

## 入力制限
- ゴールド：0〜99,999,999
- レベル：1〜LEVEL_CAP（定数が利用できない場合のUI表示上限は99）
- HP/SP：0以上の整数。適用時に実際の最大値へクランプ。
- 育成ポイント：0〜9,999
- アイテム・素材：0〜9,999

## 変更ファイル
- `script.js`
- `style.css`
