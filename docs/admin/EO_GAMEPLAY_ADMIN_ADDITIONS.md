# 開発者機能・EO風基礎能力の追加

## 今回追加した実装

- 開発者パネルに「直接戦闘」「探索設定」「演出テスト」の拡張タブを追加。
- 敵データから選んで探索を介さず戦闘を開始するテスト導線を追加。
- テスト戦闘の勝利時は報酬・経験値・素材・討伐記録を付与せず、探索へ戻す処理を追加。
- 一撃撃破モードを追加。敵へのダメージ確定処理にテスト専用の大ダメージを渡し、敵の基本データは変更しない。
- ランダムエンカウント停止、FOE接触戦闘停止を追加。どちらも一時設定でセーブしない。
- SEファイル相対パスを指定して再生する機能、斬撃・魔法・回復の演出確認ボタン、SE音量スライダーを追加。
- 有効能力値にSTR（攻撃力）、TEC（SP攻撃力）、VIT（防御力）、AGI（速度）、LUC（運）の別名を追加。
- AGIは既存の速度順行動に接続。装備のspeedBonusが速度に加算される。
- 「疾風の靴」「風読みのブーツ」を追加。

## 運用上の注意

- 直接戦闘・一撃撃破・遭遇停止は一時的な開発者設定。
- 能力値編集や装備変更は通常ゲームデータへ反映する機能として別途扱う。今回の拡張タブでは実装していない。
- SEテストは assets/se/ からの相対パスを入力する。拡張子 .mp3 は省略可能。
- この変更群は実機・ブラウザ動作確認前。確認・修正は実装を一通り揃えた後にまとめて行う。

## 継続実装が必要な項目

- LUCによる命中・回避・状態異常付与率への反映。
- STR/TEC/VIT/AGI/LUCを含む全能力の成長・装備・ステータス画面への正式統合。
- 世界樹型スキルツリーの前提条件・スキルポイント・マスタリー段階をクラス別に拡張。
- 素材ドロップと装備製作の解放条件を階層・FOE・ボスに対応させる。
- ユニオンゲージの獲得・消費を支援行動まで含めて再整理。
- 迷宮を一度に複数階層解放しない進行管理と、各階層のコンパクト化。
