# 管理者パネル 戦闘データ編集 実装メモ

## 実装範囲
- 戦闘中・入力待ち状態に限り、味方の現在HP/SPを編集。
- 現在の敵のHP・最大HP・攻撃・防御・SP防御を編集。
- 集団敵は個体単位でHP・最大HP・攻撃・防御を編集し、集計HPを再計算。
- 味方の対応済み一時状態（スタン、行動不能、やけど、防御低下）を解除。
- 管理者パネルを再描画し、戦闘画面の敵HP表示も更新。

## 安全境界
- 戦闘処理中（battleState.busy）は編集不可。
- 戦闘中の一時データだけを変更し、敵の基本定義 data/enemies.js やセーブデータには保存しない。
- 敵HPを0にしても勝利処理は自動発火しない。戦闘終了処理・報酬付与を直接呼び出さない。
- 敵の差し替え、ステージ進行、報酬・経験値、ターン数、スキル・ユニオンゲージは変更しない。
- 状態解除は本実装が把握している一時状態のみ。新規状態異常は別途対応が必要。

## 入力制限
- HPは0以上、最大HPは1以上。HPが最大HPを超える入力は拒否。
- 攻撃・防御・SP防御は0以上の整数。
- 味方HP/SPはそれぞれ現在の最大値を上限とする。
- 集団敵は個体別のHP合計と最大HP合計を親敵データへ反映。
