## 0. 世界観と共通条件

第2層は「大滝の広間」「凍った滝壺」「氷晶の吹き抜け」がある地下の水源。光は天井の割れ目からの冷たい光と、氷の反射だけ。
花は**暗い洞窟で輪郭が読めること**を最優先にし、白・淡い水色・発光の芯で浮かび上がらせる。

| 項目 | 共通ルール |
|---|---|
| 単位 | メートル。1マス = 2m × 2m。花は床の小物（1マス内に複数置ける大きさ） |
| 原点 | 底面中央（`set_origin_bottom`）。+Z 上 / GLBは +Y up で書き出し |
| 写実と様式 | 実物の構造（花弁数・付き方・葉の形）は守り、色数と明暗はゲーム向けに整理する。原神系のPBR寄りスタイライズ |
| 材質 | Principled BSDFのみ（glTFに出る入力だけ）。花弁=Subsurface+Sheen、氷=Transmission+IOR1.31、発光=Emission |
| 予算 | 1アセット 8,000〜25,000 tri、GLB 2MB以下、テクスチャ画像なし（頂点色と材質色で表現） |
| 霜 | `frost_scatter` で縁・先端に実メッシュの小さな氷晶。量は「縁が光る」程度で、形を隠さない |
| 出力 | GLB / .blend / cave照明5枚（front, side, angle, top, close）/ studio照明2枚 / manifest.json |

## 1. 霜鈴草（しもすずそう）— `f2_frost_snowdrop`

**実物の基準: スノードロップ（Galanthus nivalis）** 参考 #9〜#14、霜の付き方 #21 #25

| 部位 | 形・寸法 | 色・材質 |
|---|---|---|
| 株 | 5〜7本の花茎＋地際の小さな雪と氷の盛り土（直径0.16m）。高さ 0.22〜0.34m のばらつき | 盛り土: 白い霜 #E8F0F6、氷片は透過 |
| 花茎 | 細い円柱 r≈2.2mm、まっすぐ立ち、頂部で**鉤状に曲がる**（花柄 25〜30mm）。曲がり始めに**緑の苞（へら状、15mm）** | 灰緑 #6E9474 |
| 子房 | 花柄先端の緑の小さな球 r≈3.5mm | 鮮緑 #6FA44A |
| 外花被 3枚 | 長楕円〜へら形、長さ 22〜28mm、幅 10mm、**深い椀状**、下向きに垂れて**少し開く**（開き角 15〜35°を株内でばらす） | 純白 #F4F7FA、Subsurface 強め。先端 3mm だけ淡い水色の**氷化** #CFE8FF |
| 内花被 3枚 | 外花被の内側、長さ 10〜12mm の短い筒状。**先端に緑のV字（逆ハート）模様** | 白＋先端 #5E9A3E（頂点色） |
| 葉 | 各株 2枚、細い帯状（長さ 0.14〜0.2m、幅 8〜10mm）、中央に竜骨、先端は鈍く、外へ弓なり | 青みがかった灰緑 #5E8A7A（粉白）、Coat 弱め |
| 霜 | 外花被の縁と葉の縁に小氷晶。花1輪あたり 20〜40 個 | 氷材質 |

チェック: 横から見て「茎→鉤→苞→子房→垂れた3枚の花弁」が一目で読めること。花弁が平板な板に見えないこと（椀の厚みと反り）。

## 2. 氷水芭蕉（こおりみずばしょう）— `f2_ice_mizubasho`

**実物の基準: ミズバショウ（Lysichiton camtschatcensis）** 参考 #15〜#20（#16 は浅い水辺の群生）

| 部位 | 形・寸法 | 色・材質 |
|---|---|---|
| 株 | 仏炎苞 3（大中小）＋葉 4〜5（うち若い巻き葉 1〜2）。浅い水面の凍った円盤（直径0.55m）から生える。全高 0.35〜0.45m | 水面: 半透明の薄氷 #BFDDEB＋割れ目 |
| 仏炎苞 | 舟形のフード、高さ 0.12〜0.18m。**下部は筒状に肉穂を包み、上半分が開いて先端が尖る**。縁は外へわずかに反る | 純白 #F6F8F4、Subsurface。基部はわずかに緑 #C9DDB6 |
| 肉穂花序 | 円柱 長さ 40〜60mm、径 12〜15mm、苞の中心に立つ。表面に**小花の六角の粒々**（実メッシュの凹凸） | 黄緑〜黄 #D8C24A→#B9B347 |
| 葉 | 大きな櫂（へら）形、長さ 0.25〜0.40m、幅 0.09〜0.14m、**太い中央脈**と浅い側脈の凹凸、葉柄は太く溝あり。若葉は筒状に巻いて立つ | 濃い緑 #4E7F3A、Coat 0.3（濡れた光沢） |
| 氷 | 茎の付け根に氷の縁（盛り上がった薄氷リング）。苞の縁の一部に霜 | 透過氷 |

チェック: 白い苞が暗所で最も明るく、黄色の肉穂が中心に見えること。苞が「白い板」ではなく、包む形の厚みと反りがあること。

## 3. 氷晶花（ひょうしょうか）— `f2_ice_crystal_bloom`

**実物の基準: 霜の結晶が付いた花＋氷の花弁の星形花** 参考 #0 #6（氷の花弁）、#21〜#25（霜の結晶）、#31（暗所での花の発光）。2層固有の幻想植物

| 部位 | 形・寸法 | 色・材質 |
|---|---|---|
| 株 | 低い岩（氷の付いた暗い石、幅0.25m）の割れ目から、花 3（大 φ90mm・中 φ70mm・小 φ50mm）＋つぼみ 1。全高 0.18〜0.26m | 岩: 青黒い石 #2B3440、粗さ0.8 |
| 花弁 | **2層×11枚**の細長い披針形（長さ 0.035〜0.05m）。外層は水平〜やや反り返り、内層は立ち気味で内層が外層の隙間に来る。**稜線のある多面体の氷**（中央に稜、断面がひし形） | 透過氷 #A8DBFF、Transmission 0.85、先端ほど透明、付け根は乳白 |
| 芯 | 中心の濃紺の萼の上に、発光する短い雄しべ状の氷柱 12〜16本 | 発光 #7FE3FF（強さ 3〜6）、萼 #1B2A4A |
| 茎・葉 | 短く太めの茎、霜で白く縁取られた小さな槍形の葉 3〜4枚 | 青緑 #3F6B6A＋霜 |
| 霜 | 葉と岩の縁に小氷晶 | 氷材質 |

チェック: 暗い背景で芯の発光と花弁の透過・縁のハイライトが読めること。花弁が単なる板ではなく稜線で光を拾うこと。

## 4. 品質ゲート（独立レビューで確認）

1. 実物の構造に合っているか（花弁数・向き・葉の形・付き方）
2. 正面・側面・斜め・上・クローズアップで破綻がないか（貫通、浮き、裏面の黒抜け、法線反転）
3. 暗い洞窟照明で読めるか、studio照明で形が成立しているか
4. tri数・GLBサイズが予算内か、原点が底面中央か
