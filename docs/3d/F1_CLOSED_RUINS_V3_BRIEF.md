# 一層3F・閉鎖神域 v3 制作指示（2026-11-17 JST）

ユーザーの実ゲーム画像付き6批評と制作継続依頼を根拠に改修する。主題は、湿潤な苔に長く覆われた禁足地の閉鎖ダンジョン。手入れされた開放的な神社庭園にしない。

1. 天井の閉塞感を持続。全面空は禁止。崩落した局所的な穴だけ空・光を許容。
2. 土色を減らし、苔、侵食、堆積、欠損で一層の緑のトーンと経年感を統一。
3. 描画距離を縮小。実遮蔽物で先を隠す。大きい空白と単調な直線の眺めを減らす。ボス前だけ少し余裕。
4. 水は揺らぎ・濃淡・水底・水中岩・藻。直線岸を岩・根・泥でほぐす。整った神社池にしない。
5. 単体の孤立配置を廃止。高低の植生、根、岩、落葉、瓦礫を関係させ、柱・梁・崩落跡で建築の成立を示す。
6. 床のマス感と石/土の矩形境界を隠す。以前のアーチ/トンネルを活用し、鳥居→参道→社を軸・距離・向きで関連付ける。

制作前にPinterest実画像調査、全体構造設計、個別部品/texture監査を保存する。参考ゲームはブレワイ・原神・エンドフィールドの自然環境における密度、大小の形、素材の統一、構図。画像・ゲーム資産をコピーしない。確認用平面/断面/材質資料を用意し、個別assetを一つずつ造形・GLB再import撮影してから次へ進む。

元17GLB/制作blend/前回証跡は保存。改修は新規v3候補に分離し、実ゲームopt-in試験で比較する。通常main公開、他層、戦闘/セーブ形式は変更しない。技術QAと美術評価を分ける。目線1.6mの実ゲーム画像で全6点を再評価し、未達を明記する。
