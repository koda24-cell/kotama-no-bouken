# B2 水車架台・下部横梁 V01 — 設計と未承認レビュー
日付: 2026-11-20 / NOT_APPROVED

目的：PR #680で斜め筋交いの下端が浮いた問題を改善するための**下部水平木梁を1本**作る。既存支柱V03、筋交いV02、込み栓V02、石基礎V07のGLBは編集しない。

## 単体寸法（m）
- 全長 1.16 / 横幅 0.22 / 高さ 0.18。架台実組立では水平に横向きで設置する仮寸法。PR #680のAABBと目視が基準で、確定寸法ではない。
- 両端は欠け・鈍角の面取りと、切断された木口。面ごとに不規則で、反復する均一な丸みは付けない。
- 8角の荒く削ったオーク材を、20区間で不規則に変形。緩い反り、非対称な木肌の欠損。
- 木目の方向は**材軸長方向**。自作512pxアルベド/roughness/木口画像をPBRとして埋め込む。濡れた暗褐色で強いオレンジを避ける。
- 1本のみの単体レンダリングとGLB。筋交い取り付けのホゾ／貫通穴／込み栓用穴は実測前につき掘らない。
