# 一層後半・朽ちた鎮守の杜：制作設計書

## 制作前設計 / 2026-11-16 JST
基準: development ae7995ae9ab7c36a547c6dbd7a5d601d3fc4bea5。既存一層前半とゲームルールは保持。既存未統合PR #382の古樹遺跡門は取り込まない。

## 空間の骨格
1. 根の参道: 既存4m通路から移行。崩れた布石と根、片側の苔、石灯籠が神域の方向を示す。
2. 天蓋の裂けた中庭: 低天井の反復を解消。通行床は平面のまま、周囲の落差・壁の崩落・高い樹冠で立体感。
3. 拝殿跡: 退色した鳥居、損耗した石碑、結界のお札、巨木の根が石造基壇を裂く。
4. 地下封印回廊: 中庭から再び圧縮する空間。壁厚0.8m/高さ4m、開口2m×3mを守り、暗がりの先に次の神域を予告。

## アートディレクション
暖灰色の石、湿った灰褐色の樹皮、彩度を抑えた深緑、点在する白花、退色した弁柄色。新しい朱色の連続や青発光の反復を避ける。森の生態が建築を回収する因果関係を造形する。足元の光沢、雨筋、欠けの新旧、根の張力、表土の堆積を同じ雨量/年代の設定で統一。

## 計画する個別アセット
各ファイルを個別造形→export→GLB再import→3方向実レンダ→検査してから次の素材へ進む。全景を一括生成して素材制作を代替しない。
- 建築: 侵食石壁4m、崩落壁4m、開口付き遺跡門4m、地表石床4m、根混じり土床4m。
- 神域: 経年木製鳥居、欠損石碑、石灯籠、しめ縄/紙垂、貼り札。文字は架空の紋様にし実宗教のお札を複製しない。
- 自然: 根張り古木、倒木、岩塊、シダ、広葉低木、花叢、垂れつる。

## 実装境界
1m単位、GLB+Y上/+Z正面、4mセル/目高1.6m、地面高0。既存b1_ancient_forestは書換禁止。候補はb1_sacred_forest_candidatesへ。新規点灯/霧VFXは既存共有方式を使う（今回のgeometry previewでは粒子実装しない）。ゲームのmap/FOE/save、他階層は変更しない。

## 品質ゲート
1asset1GLB、画像PBR/UV/normalsを埋込、頂点色と追加decoder拡張なし、基本1MB/hero4MB、全体40MB目安。床縁は高さ0、壁原点は内面下端。実形状の欠損と表面色は区別。GLBで実画像確認、三角形/容量/寸法/原点/材質/hashをmanifestへ。視線高さの全景、床2枚の継ぎ目、開口の2×3mクリアランスを検証。
