## 3. 3D座標へ変換
- 全身高さ H=7 Blender units。縮尺=7/(705-45)=0.0106061 unit/px。
- 正面中心 x0=197px: X=(x-197)*0.0106061。正面の高さ Z=(705-y)*0.0106061。
- 側面は前方が画像右側。側面の暫定体幹中心を x0_side=442px として、Y=-(x-442)*0.0106061。側面も同じZ式を使用。
- 重要: 側面中心442pxは暫定。胸・腹・後頭部・足の前後位置は局所中心を変えて検証する。
- 頂点/輪郭採寸誤差は概ね±3〜6px。元画像の白線は全て外縁ではないので、内部エッジは外形の採寸に混ぜない。

## 4. 既存モデルとの比較・修正順
- 既存Eevee正面PNGを頭頂・足裏で660pxに揃え、参照画像に半透明で重ねて比較済み。現状の肩が角張って横に突き出し、手先が参考より短く、腰・股関節・脚の輪郭がずれている。
- 側面では鼻先・後頭部・胸・臀部・足先の輪郭を先に合わせる。正面と側面を同じ高さで固定し、片面だけを調整しない。
- 次のメッシュ更新はこの座標を境界条件にする。各関節のループ高さを固定し、肩・股関節の四角面を連続させる。参考画像の正確なポリゴン総数は読み取れないため一致済みとは主張しない。
- 175点（正面102、側面73）の外形トレースをローカルJSON/PNGに記録済み。これは輪郭のサンプル点数であり、3Dモデルの頂点数ではない。
