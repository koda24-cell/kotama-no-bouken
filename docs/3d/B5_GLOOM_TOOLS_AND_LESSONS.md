## 既存資産・利用可能な技術
- **実スキャン岩**: Poly Haven CC0 `rock_07`。取得処理 `tools/b5-gloom/fetch_cc0_scan.py`、Blenderソース `rock_07.blend`。配布元・ライセンスを維持し、ゲームに入れる前にテクスチャ/出典を再確認。
- **Blenderメッシュ生成**: `bmesh` の三角化・poke、`mathutils.noise` による多段階の実頂点変形。ポリゴン数3倍だけでは凹凸が増えないため、面の大きさ・変位・法線・陰影を別々に評価。
- **シェーダー**: Principled BSDF + Noise Texture + Bump。岩と侵食膜の色・roughness・ノーマルを分離。バンプは視覚効果であり実形状の凹凸ではない。
- **岩に沿う黒い侵食膜**: 元のスキャンメッシュのコピーから一部の面を除去し、法線方向へ微小オフセットして配置。岩を変形した後は侵食膜を再生成するか、同一変形を適用して浮き・めり込みを防ぐ。
- **Blender Actions**: `tools/b5-gloom/render_v4.py` とB5スキャン岩レンダリング用workflow（現時点では試作ブランチ）。実行でGLB、正面・側面・斜め上PNGをArtifactsへ出力。成功runと実ファイルを毎回検証する。
- **VFX資料**: PR #331「黒い瘴気VFXのCC0素材と制作リスト」、PR #354「fog VFX catalog and animated distant window background」。これらの実装可否・ライセンス・利用先は個別に確認。資料に記載があることは導入完了の証拠ではない。
- **完成済みB5瘴気との比較**: 参照元の具体的なGLB/材質はまだ未特定。完成済みと断定して別の岩モデルから設定を流用しない。

## 品質改善チェック
1. 現行の原形状をバックアップ/コミットし、変更前後でメッシュ名・数・位置・スケールを照合。
2. **大きな岩面・深い割れ目・中粒の欠け・微細な凹凸**を別スケールで設計。細分化のみで改善したと判断しない。
3. スキャン岩を土台に埋め込み、浮遊・不連続・板状の輪郭をなくす。紫のトゲは縮小・埋め込み、削除しない。
4. 黒い侵食膜は岩の割れ目に沿って広げ、発光は亀裂内部に抑える。瘴気の煙・揺らぎは静的GLBの材質と別にVFXとして管理。
5. 正面・側面・斜め上を**実レンダ**し、浮き・破綻・見た目・三方向の厚みを評価。GLB/PNGのハッシュ・出典・workflow run・承認状況をmanifestに記録。
6. ClaudeにはBlender作業を要求せず、GLB/PNG/manifestを渡してThree.js統合を依頼。**未承認のGLBを正式素材へ昇格しない**。
