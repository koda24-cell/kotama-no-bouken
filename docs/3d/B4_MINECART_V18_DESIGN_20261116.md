## 2. 目標アートディレクション
「使用可能な鉱山運搬車が数十年使われ、岩石・熱・湿気で傷んだ状態」。ゼルダBotW/原神/エンドフィールドは、世界観の読みやすさ、マクロ〜ミクロのディテール階層、素材の一貫性を示す品質ベンチマークであり、ゲームのアセットを抽出・複製しない。現行B4の黒褐色岩と溶岩光に対して、彩度の低い焦茶木材と黒鉄、錆は継目・ボルト周囲に局所化。暗い洞窟用演出と、品質判断用の明るい白灰スタジオ画像を別途用意。

## 3. 実寸相対設計（Three.js cart local space）
前後をZ、左右をX、上下をY。寸法はゲーム内単位であり、実在する特定車輌の計測値ではない。
| 指標 | V17現状 | V18設計目標 |
| --- | --- | --- |
| 上端外側幅 X | 約 2.15 | 2.15〜2.30 |
| 上端長さ Z | 約 2.40 | **3.50〜3.70** |
| 上端縦横比 長さ/幅 | 約 1.12 | **1.55以上** |
| 底部幅 | 約 1.44 | 1.45〜1.55 |
| 底部長さ | 約 1.74 | 2.45〜2.65 |
| 車輪の前後位置 | ±0.43 | **±1.00〜1.10（軸間 2.0以上）** |
| 車輪トレッド左右中心 X | 約±0.95〜1.0 | **±0.59（B4 V11線路の左右レール中心）** |
| 車輪半径 | 約 0.30 | 約 0.35、幅・フランジ・ボスを強調 |
| 側面傾斜 | 見えにくい | 荷台下幅 ＜ 上幅、両側の傾斜を明示 |
- 重要: **幅不足を単純に幅増しで対処すると正方形に逆戻り**する。まずZ方向の長さと軸間距離を拡大し、X方向はレールゲージとシルエットの整合優先。
- B4 V11 railsの `field/b4-detailed-rails.js` ではレール中心線が **X=±0.59**。既存V17の車輪中心±0.95はゲージ不一致の可能性が高いため、V18では±0.59へ合わせる。レール接触Y座標と車体の衝突範囲は再検証。2F・3F・4Fのタイル寸法とは別に、実際の車輪接触をレンダーで確認するまでゲーム統合しない。

## 4. モデル構成と経年劣化
- **シャシー**: 前後をつなぐ2本の長い縦桁、2つの独立車軸、4輪、ボルト付き軸受け。新たな車輪を旧モデル車輪に重ねるのは禁止。変更前GLBを保存したまま比較候補を作る。元メッシュを削除しない。
- **荷台**: 傾斜面を3〜4段の独立板で構成、複数の材質、均一幅を避ける。金属フレームは縁と四隅の構造材を中心に入れ、不要な帯状リブは抑制。
- **車輪**: ダークアイアン、リム＋一体化したフランジ＋スポーク＋ハブ＋車軸。前後軸間を2倍以上にし、車体の前後端に近づける。
- **鉱石**: 元の積載物を残す候補との比較。大岩1個が全体を覆わないよう、局所的な荷重や小片を追加する場合は外形と相互干渉を評価。鉱石削除は承認なしにしない。
- **破損**: 木板端の一部欠け・小さな段差・反り・亀裂。傷は均一なノイズではなく、木目に沿う。鉄の錆は下端・継目・固定具周り。車輪は円周の磨耗、リムとボスの金属光沢の差を出す。
- **禁止**: 全表面に均一な点粒子、浮いたリング、テクスチャだけで誤魔化した破断、一枚の大きな平面で既存パーツを隠すこと。

## 6. Blender品質ゲート
1. 元版V17を維持、V18は別GLBとして制作する。
2. 本体を横・縦比で検証（上端長さ/幅 >=1.55、軸間/長さ >=0.55）。レールに接地し、車輪の重複が無いかチェック。
3. 1200px前後の正面/側面/斜め（余力あれば上）を中立明るい環境で撮影、材質色を保持。暗所版は別カメラ。
4. シルエット、接合、重なり、質感、実際の欠け、輪郭、色の統一を画像で評価。新しい問題は次の枝番に反映。
5. GLB＋PNG＋.blend＋マテリアル＋manifest/hashをArtifactsへ途中保存。API美観判定は未接続。作業中のループは今回のセッション内で明示的に実行し、無期限常駐や無制限処理は保証しない。
