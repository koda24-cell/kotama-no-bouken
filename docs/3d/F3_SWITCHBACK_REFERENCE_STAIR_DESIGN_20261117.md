## 見本の構造読み取り
- 2本の逆方向に上る階段を一つの中段踊り場で折り返す
- 下段は左手前から右奥へ、中段右で折り返し、上段は左奥へ
- 上端に大きめのコンクリート張り出しデッキ
- 2箇所の踊り場・支持柱・床下の梁が一体で荷重を支える
- 手すりは細い赤錆色の鋼管、階段・踊り場に取り付き
- コンクリートは湿った灰緑で苔や雨の縦筋、縁には部分的な破損
- 人物や余計な装飾はない
- 見本の正確な寸法は不明のため、これを2mタイルへ圧縮せず約6〜8mの大型独立アセットとして制作する

## アート・技術目標
1. 薄い板や玩具にならないよう、踏み板・桁・踊り場・柱・梁の支持関係を成立させる
2. 欠損は大きい構造破損から開始し、マテリアルで細かな凹凸を補う
3. 植生・雨筋・錆垂れは水の集まる箇所と接合部に配置
4. 色調は暗い湿潤灰緑＋赤褐色の低彩度、黒背景/ニュートラル照明でプレビュー
5. 第3層ゲーム向けにGLB/Blender作業ファイル/3方向PNG/manifestを出す
6. 形状・配置が既存2mタイルとは違うため、そのまま接続可能とは断定しない
