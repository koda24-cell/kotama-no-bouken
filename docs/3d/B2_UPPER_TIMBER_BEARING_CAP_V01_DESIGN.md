# 第2層 水車・木製軸受け 上側押さえ蓋1個 設計V01

2026-11-19 JST / DESIGN-FIRST / NOT_APPROVED / PR独立

## 設計対象
- 既存下部軸受け台 (PR #568) に対応する **上半分の木製軸受け蓋1個のみ**。固定金具・ピン・鉄板・装飾・2個目の蓋は制作しない。
- 既存を守る：ゲーム水車は車軸X、半径0.300m。下側候補はX=-0.60…+0.60、Y=-0.55…+0.55、Z=-0.70…+0.055m、U字半円軸座半径0.318m（軸周り18mmの設計余裕）。本モデルも下部の形を上書き・削除しない。
- 下側V03は木目側面の明るい横帯に美術課題があり未承認。今回の上蓋を作ることはV03合格やゲーム統合の意味ではない。

## 幾何設計
- X全長1.16m（下部の1.20mより20mmずつ短い）、Y幅約1.05m（下部1.10mより左右25mmずつ狭い）、Zは+0.055mから+0.63mまで。
- 下側へ向けて開く実U字溝：X軸中心(0,0,0)の **円筒半径0.322m** をブーリアンで削除。下部の0.318m座より4mm広げた設計案。これにより軸半径0.300mに対して22mmの半径クリアランス。見た目は実寸仮組み検証前の候補値。
- 木口の端は完全な矩形ではなく、軽い削り・不対称な角の摩耗と0.004〜0.007mの加工面取り。大きな均等ギザギザ／規則的なチッピングは避ける。
- 木材一本で成立する構造。木目に沿った上辺の局所割れ（別の装飾ラインでなく、木部の一部を変形）と側面のわずかな丸みを検討。ただし機能を損なう深い割れは作らない。
- 下側ブロックと面合わせするZ=.055m周辺はクリアランスを検証するため水平面を維持。最終組付けで実モデル間の衝突・隙間を別途測る。

## マテリアルと軽量化
- 既存外輪V11のBlend `b2_waterwheel_single_rim_segment_v11.blend` SHA256 `addae90dd199b9f6d0417c70f5152a32bd504e83e2deffa8e0965a0fdf5e2c67` からPacked CC0のPoly Haven Fine Grained Wood材質を読み取り専用append。ネット上の新規素材・コードは取得しない。
- 外周長手と木口でUV分け。V03で問題化した白い側面帯を避けるよう同一長手UV・暗色乗算を適用。写真PBRを捨てずに配色だけ抑制する。
- GLB一体メッシュ、原則材質3種類以内。凹弧面の材質は荒く油染み暗色。既存のゲーム当たり判定や他階層LODは変更禁止。
- 実4方向（正面/側面/斜め/背面）PNG + GLB + Blend + SHA256 manifest。モデルのループ法線・穴の見え方・曲面がきれいかチェック。実GLBのパフォーマンス監査は別Actionで行えた時のみ「実行」とする。
