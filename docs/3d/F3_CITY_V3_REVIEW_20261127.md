# 第3層 遺跡都市 V3 — 実ゲーム確認用

対象は第3層7–9F。第4層への移動は行っていない。正式採用前の確認用で、全22点は NOT_APPROVED。制作PRは [#851](https://github.com/koda24-cell/kotama-no-bouken/pull/851)。V2の原本と確認画像は保持している。

## 変更した空間

35×31セルの全域を路地と周回路に使い、7Fは552歩行セル・69周回、8Fは578・102周回、9Fは561・93周回。各階の出口、宝箱、採集、仕掛け、FOE経路へ到達できる。白花の庭と植物館を除き、広い平地を通路・建物・水路に分割した。

高さ場に従って足場とカメラ、イベント、FOEが移動する。7F/9Fは3.2m、8Fは6.4mまでの段差を連続した階段で繋いだ。鉄骨橋には支点、階段には踊り場・手摺・桁を設けた。装飾階段と実際の歩行階段は区別している。

壁の凹部は厚い側面・奥壁・内部コアで閉じ、接合部を全高の柱で繋いだ。階床の瓦礫は上層窓へ機械的に繰り返さない。近傍は個別原モデル、遠方は閉じた凹部を残す簡略形状に切り替える。透明植物、水、衝突形状を一括間引きしていない。

モニュメントは像6.4m＋台座1.5m、さらに花壇基礎0.75mの合計約8.65m。白花は前庭と段状の花壇を覆い、位相差のある風で揺れる。植物館は曲線リブ・破れた屋根ガラス・根の花壇・保存済みの第一層の樹木で構成。廃車は後退した車庫に置き、路地を塞がない。電柱、架線、蛍光灯、梁を連続させた。

水面は複数の青い平板ではなく、結合した反射面・波紋・透過で構成。水位−0.25m、沈んだ店舗と柱廊の基底−3m、地盤−6.05m。水中建築にも支持基礎を設けた。水際は低い連続手摺で区切り、接近時に視線が穏やかに下がる。曇天と靄、斜めの光条と屋根下の影を併用する。

## 検証の範囲

最終22点の実ランタイムGLBと外部画像をglTF Validatorで検査し、エラー0・警告0。[結果](../reviews/f3-city-v3-final/runtime-validation.json)。共有実GLB性能監査 [run45978652872](https://github.com/koda24-cell/kotama-no-bouken/actions/runs/45978652872) は22点・302,251三角形・86 primitive instances。これは元モデル合計であり実フレームの描画数やFPSではない。

ブラウザはChromium/SwiftShader。PC表示とスマートフォン相当のタッチ操作を検査する。実機のハードウェアFPSは未測定。GPU性能や美術承認を自動判定していない。

試遊は通常セーブから分離し、見学時のランダム戦闘を止める。通常戦闘へ切り替え可能。FOE接触は通常どおり。アセットは固定コミットのSHAで検証し、最初の配信先が失敗した場合は別ホストへ回復する。起動前のセーブ分離コードが取得できない場合はゲームを開始しない。

UI照合はdevelopment `536bb2f0` に対して実施。`script.js`、`style.css`、`home-ui.js`、`formation.js` は同一で、`index.html`の意味のある差分はV3の配置定義スクリプト追加だけ。V3の標高・視線・描画距離は確認用フラグと第3層に限定し、通常の他層へ持ち込まない。

## 実行結果

- PC操作の全検査はソース `2c0c63df` で実施。唯一の失敗は植物館の瓦礫6箇所の干渉。ソース `a7b71faa` で基礎を25cm沈め、当該8FのPC再検査で失敗0・干渉0を確認した。原失敗も隠さず保存している。
- 最終ソース `a7b71faa` のタッチ検査は7–9F、移動・旋回・壁への衝突、実カメラ昇降、宝箱・採集・仕掛け、階段遷移、保存復元、第一層往復、距離による近景/遠景切替で失敗0。縦画面の回転案内から844×390横画面へ移り、実際のタッチボタンで操作した。
- PCカメラは地面0→1.6→3.2mに対し1.6→3.2→4.8mへ移動。タッチでも同じ経路を確認。往復時の資源数はPCが第一層105 geometry/293 texture、第3層169/321、タッチが91/246と141/270で、同一階層へ戻っても増加しなかった。
- 最終ソースの全3階を、ローカルの試遊ラッパー＋実CDNの固定コード・実GLB・実画像で検査した。成功応答のモックなし。各階15/17/19モデル、`v3Complete=true`、取得SHA一致。最初の画像ホストを503にしても回復し、石像の対話も開始した。通常セーブの番兵は読み書きされなかった。分離コードを全配信先で503にすると明示エラーとなり、ゲームは起動しなかった。[CDN検証](../reviews/f3-city-v3-final/cdn-delivery.json)。
