# 第3層：折れた鉄筋コンクリート梁 V01 — 寸法・造形設計

Status: NOT_APPROVED。単体候補・正式素材化禁止。

先行するコンクリート瓦礫3種 V29 (PR #642) の続きとして、崩壊した建物を表現する中スケール構造部材を1個ずつ作る。第3層環境アート仕様（FLOOR3_WORLDCLASS_ENVIRONMENT_ART_BIBLE_20261116.md）ではコンクリート梁／柱／欠損壁を次の制作対象としている。

- もとの矩形梁：長さ約1200mm、断面幅320mm×高さ390mm。横倒しの梁片で、建物全体を一度に生成しない。
- 右側断面：12頂点の不整形断面。前端のX変位9–61mm、横の面に局所欠け。横断面の歪み・横からの厚みを持たせる。
- 鉄筋：直径14–16mm×3本、断面の奥から始まり外へ70–130mm突出、先端がそれぞれ不等に曲がる。全部の先端を同位置で切らない。材質は暗い錆褐色で、銀白色の線や突き出した白い骨材を使わない。
- 材質：旧市街の灰褐色コンクリートと露出した内部コンクリートを区別。錆材は独立して物理的な円柱カーブ。外部テクスチャ未導入で、このV01は形状検証用。現時点で写真PBR採用・UV再現などは未検証。
- Blender 5.3＋固定Docker/ClamAV、実モデル5方向(front/side/angle/top/break_detail)1000×800、GLB/Blend、SHA-256 manifestを作る。
- 品質基準：根本の鉄筋が壁断面内に埋まり、先端浮遊ゼロ、法線反転や破断面のギザギザの等間隔反復がない。可能ならGLB再読込も確認。
- 完了の前にユーザー画像レビューを経る。game assetsやdevelopment/mainへマージしない。
