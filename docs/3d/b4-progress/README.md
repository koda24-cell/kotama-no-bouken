## 20261121-02-chasms — 奈落（上下の空間）
- 壁の塊を最大6か所、深さ26 mの縦穴にした。通路側の壁は「黒き神殿の欄干」（台座・手すり子・3分割の笠木・端柱、欠けあり）に置き換え、隙間から下の溶岩の光が見える。
- 縦穴の側壁は神殿の石積みテクスチャで、深いほど橙に照り返す（`addUplight`）。熱の霞2層、立ちのぼる火の粉、側壁の裂け目から落ちる溶岩の滝。
- 01 は修正前（玄武岩パネルが欄干の位置をふさいでいた）。02 は照り返しが強すぎた途中経過。03〜06 が現状。

## 20261121-03-12f-vault — 12F 迷宮化・反重力の柱の間・竜の聖域
- 12F を迷宮（28×18）に作り直し。開けた場所は「反重力の柱の間（7×5）」と「竜の聖域（5×5）」の2か所だけ。聖域へは両側を溶岩に挟まれた参道で入る。
- 通れない溶岩（~）は GPT の V16 / P1〜P3（LOD）で覆い、2×2マスは原寸、段差は壁側へ向ける。通れる溶岩（*）とは見た目が別物。
- 壁は高さ 8.2 m の神殿の石積み＋化粧材。
- 柱の間：浮遊する黒曜のオベリスク9本＋逆さの7本、紋章の輪4つ、浮遊する破片、穴から立ちのぼる火の粉。
- 聖域：尖頭アーチ、逆光の竜の翼のシルエット、竜の背後の光輪、3段の階段、柱6本と火鉢4つ、艶のある黒い床と魔法陣、光の筋。
- 05 はアーチが板状に埋まっていた不具合（修正済み）。

## 20261121-04-b4-kit-brightness — 4層専用の配置物・明るさ
- 森の部品（苔の石段・青い灯・石の道標・苔の宝箱・根のアーチ・封印扉）を4層では使わない。`field/b4-kit.js` に黒き神殿版を作成：

  石碑（黒曜・竜紋・溶岩の割れ目）、宝箱（黒い木＋鉄帯、開くと中が赤く光る）、封印の扉（紋章の輪）、出口の門。
