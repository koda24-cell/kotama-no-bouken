## 追加した VFX（`field/b4-fx12.js`）
燃える炎 5 種（ダウンロードした CC0 の連番 `assets/vfx/flipbooks/`、出典は manifest.json）
- F1 火柱：溶岩から 3 段重ねの炎（flame_5x5）
- F2 地を這う炎：溶岩の縁（Mikodrak fire 1b）
- F3 聖火：聖域の金の火鉢の白金の炎（Mikodrak fire 1f）
- F4 燠火と火花：床の赤い燠と小さな火花
- F5 炎の渦：柱の間の穴の上を回る炎（tauran flame）

VFX 10 種
V1 陽炎の帯 / V2 溶岩から立つ光の柱 / V3 舞う灰と燃えかす / V4 柱の間の電弧 / V5 火の粉の竜巻 / V6 溶岩の噴き上げ（周期） / V7 降る光の粒（聖域は金） / V8 壁を流れる炎の文字 / V9 床に広がる衝撃波の輪 / V10 3 段の霧の層

横から見えるときに板に見えないよう、板状のもの（陽炎・光の柱・霧）は視線との角度で薄くする。

## 竜の聖域（`field/b4-sanctum.js`）
- 柱を 7 m → 15.5 m に伸ばし、金の帯 5 本と金の縦溝、金の柱頭
- 側壁を金縁の黒い艶石パネルで覆い、縦の光の象嵌（レンガ面を隠す）
- 天窓（y 20）から斜めに差し込む白金の神の光 7 本
- 竜の背後の光輪を白金の三重に、逆光の板を白金へ
- 火鉢を金にして白金の聖火、照明を白金寄りに
- 参道までの黒と赤から、聖域だけ金と白の配色
