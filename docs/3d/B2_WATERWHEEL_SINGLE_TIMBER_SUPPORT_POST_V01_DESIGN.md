# 第2層氷結水車：一本の古木支持支柱 V01（NOT_APPROVED）
2026-11-20 / DESIGN-FIRST / 試作素材

## 位置づけと引き継ぎ
- 既存の水車外輪・桶・スポーク・ハブV11・軸V02・軸受け上下・金具V05は保持。新造形は独立した木製支柱1本のみ。
- 参照：PR #629の仮組みは軸X方向、左右軸受けX±1.02m、車軸中心Z=0。仮設計上、支持架台は軸受けを下方から支える。実GLBの相互接触・クリアランスは未検証で、座標は実装時に再測定。
- 単独パーツとして約1.65m高、約0.31m角の長年水に晒されたオーク材柱。石基礎・梁・軸受けとまだ結合しない。

## 形状設計
- 太い木を荒く角材化：8方向断面で角の不揃い、縦方向に8段の局所的な反り、ささくれと縦割れ（明度だけでなく浅い溝を追加）。
- 側面4方向が一様な四角柱にならないこと。上面の圧縮潰れ・端面の不均一なリングを独立材質で見せる。
- 一部の大きな斜めの破断を幾何として保持し、頂面の毛羽立ちを過度に鋭くしない。接合ほぞは**設計のみ**。仮組み寸法が確認できるまでは既存木部の切削禁止。
- 色は湿った焦げ茶色・古材の灰色を基調に、局所的な青灰の湿り、苔汚れを制御。新品のオレンジ木材にしない。
