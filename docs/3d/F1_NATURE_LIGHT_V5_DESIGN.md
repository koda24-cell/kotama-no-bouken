# 一層V5: 揺れる採光・自然の群配置・閉じた天井と迷宮

根拠はユーザーの4実画面と追記。rootが単独・逐次で制作し、新規の並行agent/一括モデル生成は行わない。既存のモデルは保持して再配置する。

1. 光源として見えていた白いCircleGeometryを作らない。Drei SpotLight(MIT)とthree-good-godraysの設計を調査。React/postprocessing依存やNOASSERTIONの配布物を追加せず、既存Three.js r180で局所的な10sample volume/移流する筋と独自の葉影cookieを実装する。形のある光源は0、同時shadow mapは従来通り水場の1枚。
2. 苔石・根元の下草・疎らな草花・天井のつるを群として構成する。岩は少し地面へ沈めて接地させる。8つの手設計した植生の見所と通常の壁際の植生を組み合わせ、中心の幅1.8mを硬い物で塞がない。
3. 1F/2F/3Fの上部に石帯と連続した屋根の裏面を追加。根や曲面天井の既存形は保ち、その隙間から背景が見えるのを防ぐ。3Fの意図した3開口は塞がない。16m単位のinstancingで近景の形を落とさずまとめる。
4. 3Fは191歩行セル、31分岐点。旧版の106/11から、未利用の上左と下部/外周へ曲がる通路と周回路を追加。既存7固定物、11水セル、FOE隣接巡回、鳥居祠の枝道終端は保持。
5. 「通行不可」と「壁として描く」を混同していた問題も修正。元のsave/chest/sign/NPC2体の5物が壁で隠れていたことを、実GLBの視線検査で検出。物の位置や報酬/通行は変えず、物の床を見える形にし、壁を背後へ回す。

初回の岩の単体感を示す画像、止めた検査の状態、壁による5物の遮蔽検査を保持する。描画・移動・元イベント・資源解放・通常セーブ隔離を実ブラウザーで検証してから固定commitの試遊URLを提供する。実機FPSとユーザーの最終美術承認を代行しない。mainは変更しない。
