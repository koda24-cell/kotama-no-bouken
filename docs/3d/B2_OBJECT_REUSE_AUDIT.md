# 2層（凍てつく水源）配置物の使い回し調査と差し替え（2026-11-21, Claude）

ユーザー指摘（2026-11-21）：「宝やイベントオブジェクトなど２層のも１層の使いまわしになってる部分があるので変えてください」

## 調査結果（`field/field-3d-b2-water.js`）

| 配置物 | 差し替え前 | 状態 | 差し替え後 |
|---|---|---|---|
| 階段（上り・下り） | `sp.buildStairs`（霜の石と氷の段） | 2層専用（B2V4-S） | そのまま |
| セーブ地点 | 1層の `ancient_rune_floor_seal` ＋ `blue_wisp_torch` に霜の色をかけたもの | **使い回し** | `b2-kit.js` の霜の魔法陣＋氷石の六角祭壇＋浮かぶ氷晶 |
| 看板（床） | 1層の `ancient_stone_signpost` に霜の色 | **使い回し** | 霜をかぶった青灰の石碑（水色のルーン、氷の房） |
| 看板（壁） | `tpl.plaque`（2層の石板） | 2層専用 | そのまま |
| 宝箱 | 共通処理の 1層 `sealed_treasure_chest(_open)` に霜の色 | **使い回し** | 色の抜けた木＋青鉄の帯＋蓋の氷の殻。開くと水色に光る |
| イベント物（隠し以外） | 4層の `abandoned_mine_cart.glb`（「専用素材が無いので仮」） | **他階層の使い回し** | 置き去りの補給の木箱（木箱2・樽・ロープ・霜・氷柱） |
| イベント物（隠し） | 2層のいばら（なければ 1層の根） | ほぼ専用 | そのまま |
| 合図石・水門・ボス門・出口のアーチ | 2層の部品 | 2層専用 | そのまま |
| NPC | 共通の NPC 画像 | 全階層共通 | そのまま |

## 実装
- `field/b2-kit.js`：手続き生成（寸法はファイル冒頭）。ページ全体で1組を共有（`getB2Kit()`）。
- `frostify()` は `userData.b2Kit` の物を素通しする（最初から霜の素材）。
- 確認画像：`docs/3d/b4-progress/20261121-05-b2-kit/`。
