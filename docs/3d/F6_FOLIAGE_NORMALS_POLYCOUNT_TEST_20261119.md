# 第6層・葉群の法線と陰影に関する検証メモ（2026-11-19）

## 出典の区別
- 2019年 Polycount Obscura: https://polycount.com/discussion/209623/smooth-foliage-like-in-breath-of-the-wild-europa-by-helder-pinto-mini-tutorial
- **作者の確認済み手法**: 方向の違う葉カードの陰影差を抑えるため、細長い半球の方向を Normal Thief で葉へ転写。Unreal の TwoSidedSign/裏面法線処理を利用。木の中心へ向かうごく軽い暗色補正にも言及。
- **コメントによる補足**: Mark Dygert が頂点カラーAOベイクを提案。DFAOは計算コスト、風と影のずれによるちらつき懸念があり、コメントでは頂点カラーAOが実用的とされる。作者本人の技術とコメント者の手法を混同しない。
- **任天堂の実装と断定しない**。BotWの印象を再現した非公式の技術検証。
- **Blender公式API**: https://docs.blender.org/api/5.0/bpy.types.Mesh.html の normals_split_custom_set が Blender 5.0 にある。GLB/Three.jsでのシェーディング一致は未検証。

## 第6層への意義
- 保持: V25でユーザーが認めた樹冠の横方向の広がり／既存幹・根・枝。造形削除やゲーム採用はしない。
- 解決対象: 葉が一枚ずつ違う方向を向いて硬く陰影が分断すること、白飛び・黒い裏面・幹周辺の粒状の隙間。
- 類似表現を作る際、見た目を優先。軽量化・LODは美術承認後。

## 比較試験仕様
1. 同じ葉群を3組複製し、同じカメラ、ライト、緑マテリアルで撮影。A = 元の法線、B = 葉群の細長い半球に沿う投影法線、C = B + 樹冠中心ほど淡く暗くする頂点カラーAO。頂点法線以外の造形と配置を統一する。
2. 正面、斜め、裏側（または下側）のPNGを出力。BとCの NORMAL をglTFへ出し、出力形式・非ゼロ差分をチェック。裏面の見え方は別検証を残す。
3. 1枚葉だけでは実際の重なりを代表しないため、既存の実木V27 Blendの葉群から実物を抽出する。プレビューを本番木に無断転用しない。
4. 視覚チェック: 不自然なカード境界が減るか、塊の体積感が増すか、裏側だけ暗くならないか、内部AOが黒穴にならないか。
5. データチェック: 元BlendのSHA256、対象葉数、変更した法線ループ数、PNG/GLBのハッシュ、Blenderバージョンを記録。検証できたことと美術品質判定は別。

## 技術上の注意
- Custom split normals はメッシュの各コーナーで指定できる。貼り合わせた板の裏面向きは材質の両面レンダリング設定と連動しうるため、**両面法線の反転をBlenderで見ただけでThree.jsにも自動で適用済みとは言わない**。
- 頂点カラーの内部AOは「フェイクの陰影」で、実測遮蔽のAOベイクとは別。枝の遮蔽や実環境では影がずれることもありうる。
- ゲーム側に採用する場合、glTFの doubleSided / alphaMode、NormalMapの向き、Three.jsの side、影設定、Bloomと実機画角まで確認する。
- 最終判定は**実レンダリングを目視**してから。形式検証のみでは美術合格としない。
