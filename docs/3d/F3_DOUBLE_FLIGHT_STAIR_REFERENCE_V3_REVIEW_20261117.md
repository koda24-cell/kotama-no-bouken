## 参考との比較
- **再現した構造:** 二段のコンクリート階段、上下踊り場、支持柱と横梁、両側鋼管手すり、支柱取付金具、踏み板の欠け。
- **V1**: 重いコンクリート支持構造はできたが、白く新築に近い、苔は不十分。俯瞰視点では長い直線的な階段に見えやすい。
- **V2**: 錆色と湿りを追加したが、苔が緑の四角いパーツに見え、不自然。
- **V3**: 四角い苔ジオメトリを除去し、GLBにも持ち込めるテクスチャへ切り替えた。ただしテクスチャの緑模様が大きくぼやけた染みに見える。暗くなりすぎてコンクリートの細かな剥離や金属接続部が読みづらい。
- **現状の問題:** 元画像は上下フライトのZ字状の違いと、梁・支柱の物理構造、苔の局所性、剥離・赤錆の分布が優れている。V3はまだ統合された大きな廃墟建築に見える品質ではない。手すりの接続、踊り場の構造と高低差、法線/マテリアルのゲーム内見え方も追加評価が必要。

## 次回V4の優先修正
1. 下段・上段フライトの方向を広げて、見本に近い折り返し/Z字シルエットを出す。隣接経路を通れるモデルとして物理寸法チェック。
2. 柱と梁の荷重関係、踊り場の厚い断面をもっと強調。二段が単なる接続階段の連結にならないよう建造物全体の設計を再確認。
3. BaseColorの大きな緑の染みを弱め、継ぎ目・雨水が流れる縦面・鉄筋露出周辺だけに苔や錆汁を配置。
4. 錆びた手すりに接合フランジ・ボルト・腐食帯と一部曲がりを増やす。手すりは必ず階段や踊り場と接続。
5. 剥離/欠けは輪郭を変える立体造形、微細な凹凸はPBRで分離。見本と中立光で複数角度比較。
6. GLBのテクスチャ/Normal/UVのThree.js互換を実ブラウザで確認。未検証の状態を完成と呼ばない。
