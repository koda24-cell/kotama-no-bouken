# 第2階層：開けた水源空間の設計案（未実装）
## 課題
現在の迷宮は通路の景観が単調で、広さ・奥行き・視線の抜けが不足する。既存の氷結した古代石橋と氷洞窟の素材を保持する。
## 新規エリア
- **大滝の広間**: 入口の狭い洞窟から、幅広い水源空間へ出る。正面奥に凍結した巨大滝、足元に凍った滝壺。左右の岩棚に高低差をつける。
- **橋を見下ろす断崖**: 既存の古代石橋を遠景に配置し、同じ素材を別の視点から見せる。
- **氷晶の吹き抜け**: 天井の高い部屋、左右非対称の氷晶群、天井からの光。
## ゲーム実装上の注意
- 一人称3Dマップの既存のマス移動・衝突・FOE経路・ミニマップ・セーブを変更しない。
- まずは背景ジオメトリと装飾だけの独立プレビュー。歩行可能マスや通行判定を勝手に増やさない。
- 開けた部屋は視界だけを広げ、移動ルールと独立して扱う。視界半径4マスの既存仕様との整合はゲーム画面で要検証。
- GPU負荷対策として遠景メッシュ結合、LOD、テクスチャ共有、必要なら遮蔽・距離フェードを検討。
- 3Dレンダリングを正面・側面・斜めでレビュー後、ユーザー承認を得てからゲーム配置を別PRで実装する。
