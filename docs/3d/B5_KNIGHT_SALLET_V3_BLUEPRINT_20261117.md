# 第5層 朽ちた騎士像 — サレット兜 V3 造形設計図
作成: 2026-11-17 / 状態: DESIGN_ONLY, NOT_APPROVED

## 基準・非破壊
- 制作本流: PR #424 `feature/gpt-b5-knight-statues-v1-20261116`。現行兜V1/V2と騎士本体V14、台座亀裂V15を維持。
- 兜単体V2の既知欠陥: bucket-like silhouette, slab visor, weak tail-to-skull blend。小装飾の追加ではなく面構成を根本的に設計し直す。
- 他パーツ（鎧、肩、関節、剣、盾、台座）には触れない。生産素材への昇格はユーザー承認後。

## 造形の基準寸法（兜単体のローカル座標・仮案）
成人頭部との比率確認用。頭部高を1.00、横幅を0.72、前後長を0.90として正規化。実寸は騎士V14の頭部を読み込みフィットさせて確定する。
- 外殻最大幅 0.82–0.88、最大前後長 1.04–1.12、高さ 0.78–0.88。
- 正面: 単純な筒状の垂直側面は禁止。額から頬への面は内側へ絞り、頂部は滑らかな楕円アーチ。
- 側面: 鼻先側の眉庇は浅く前傾。眼スリットは薄い暗部として収め、厚い板状の大きなバイザーは付けない。
- 後面: 後頭部の連続曲面を首の付け根まで延ばし、その接線から短めの尾部を一体的に展開。急な段差や浮いた尾は不可。
- 下顎: 別体bevorは輪郭や隙間が自然に成立した場合のみ。首と鎧との干渉を確認。

## 正投影チェック項目
| view | 輪郭の主眼 | NG |
|---|---|---|
| front | 卵型頭頂、頬の絞り、左右対称だが完全均等ではない古びた表情 | バケツ形・巨大スリット・突き出た板 |
| side | 額→頭頂→後頭→尾が滑らかな一本の流れ、薄い眼部 | 屈曲した尾・水平な棚・頭の上下切断 |
| angle 3/4 | 金属面の滑らかな反射と面の連続、首鎧との奥行き | 重なって浮く板・隙間 |
| top | 前後長と後頭部の流線形、細すぎる頭頂なし | 四角断面・左右不自然な張出 |

## メッシュ設計
1. 主要外殻は断面リングを前後方向に並べた連続曲面。各リングは上・側・下の半径を独立調整し、前部狭・側頭中央広・後部滑らかに収束。
2. 眉庇／目の凹みは外殻曲率に追従した凹部で形成。離れた板として載せず、必要なら開口をソリッド化して切断面厚を表現。
3. 後部尾は独立の浮遊メッシュにせず、外殻輪郭に接続して継ぎ目の位置を実際の接線で検査。
4. 金属: 暗い鈍鉄、roughnessの局所差・溝への酸化・エッジの部分摩耗。完全鏡面や均一な黒線は避ける。
5. 打痕/薄い傷は法線・ラフネス中心。シルエットに影響する歪みのみ幾何学で追加。厚い石像的な縁取りをしない。
6. 全構成を名前付きオブジェクトへ分け、後から鎧側で位置合わせが可能なピボットを残す。

## 実制作・検証ゲート
1. PR #424ブランチのV2コードと既存GLB/PNGを先に確認、現行head SHAを記録。
2. `tools/b5-knights/build_sallet_v3.py` に独立造形。既存V1/V2は上書き禁止。
3. Blenderで正面・側面・斜め・真上を実レンダリング、.blend/GLB/PNG/manifest/hashを保存。ワークフローは新ソースのみに反応。
4. GLBのメッシュ有無/三角形数/法線、PNG非空と多視点の見た目、首へのfit、元V2比較を必須チェック。バケツ輪郭が残れば未承認のまま再造形。
5. 近景品質を優先しつつ静的剛体向け共通GLB監査・LOD候補を実施。LODは別ファイルで比較し原本を保持。ゲーム組込みはしない。
6. `approval=NOT_APPROVED`、データとClaude引継ぎはreview候補に限定。美術品質承認後に正式保存・development統合を検討。
