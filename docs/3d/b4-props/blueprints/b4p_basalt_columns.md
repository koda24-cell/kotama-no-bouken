# 設計図 b4p_basalt_columns（#20 柱状節理の小群）

原点＝底面中央。単位 m。人 1.6m と比較：最も高い柱 2.2m は人より 0.6m 高い。

| 項目 | 値 |
| --- | --- |
| 幅×奥行×高さ | 1.5 × 1.2 × 2.2 |
| 三角形 | ≦ 6,000 |
| テクスチャ | 1K |

## 柱（六角柱、角は 1.5cm 面取り）
| 項目 | 値 |
| --- | --- |
| 本数 | 7（＋足元に折れて転がった柱の節 1） |
| 対辺の幅 | 0.38〜0.50（各柱の六角形は辺の長さが ±15% 不揃い） |
| 配置 | 六角格子 間隔 0.47、中心 (0,0) とまわり 6 本。隙間 0.01〜0.03 |
| 高さ | 中央 2.20、他 1.85 / 1.55 / 1.30 / 1.05 / 0.82 / 0.60（段々に下がる） |
| 天端 | 傾き 3〜10°。3 本は天端が2段（段差 0.06〜0.15）、全柱の角に欠け 1〜2 |
| 横の節理 | 各柱 0〜2 本の水平の割れ目（幅 0.012、深さ 0.02）、うち1本は節で欠ける |
| 転がった節 | 長さ 0.5、対辺 0.42、正面の裾に横倒し |

## 劣化
- 天端の欠けと段差（新しい断面）、柱の角の摩耗
- 天端と段差の棚に灰、柱の隙間は暗い。下 0.3m は煤で黒い
