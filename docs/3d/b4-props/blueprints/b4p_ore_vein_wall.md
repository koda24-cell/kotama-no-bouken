# 設計図 b4p_ore_vein_wall（#21 壁に貼る炎竜鉱の鉱脈の岩板）

原点＝底面中央。裏面（+Y 側）は平らな面 y = +0.25 で、坑道の壁に密着させる。正面は −Y。単位 m。
人 1.6m と比較：高さ 2.2m は人の頭上 0.6m まで。

## 全体
| 項目 | 値 |
| --- | --- |
| 幅×奥行×高さ | 2.4 × 0.5 × 2.2（許容 ±0.15） |
| 三角形 | ≦ 10,000 |
| テクスチャ | 2K（basecolor / ORM / normal / emissive） |
| マテリアル | 1（ベイク後）。元は玄武岩＋結晶の2 |
| 点光源 | 鉱脈の前 0.12m に 3〜4 個（各 3〜6W、赤橙） |

## 岩板
| 部品 | 寸法・位置 |
| --- | --- |
| 元の塊 | 楕円体 半径 (1.25, 0.34, 1.15)、中心 (0, 0, 1.08)。底 z=0 で平ら |
| 裏面 | 平面 y=+0.25 で切る（壁に貼る面、割れ面扱いしない） |
| 正面の割れ面 | 10〜14 枚（法線は −Y 寄り）＋段差 6、新しい断面 35% |
| 外形の欠け | 右上の角を 0.3m 規模で欠く（段差）、左下に 0.2m の割れ落ち |

## 鉱脈（正面の2D座標 u=横, w=高さ）
| 脈 | 経路 | 幅（半幅） | 深さ |
| --- | --- | --- | --- |
| 主脈 | (−0.95, 0.25) → (−0.3, 0.9) → (0.15, 1.25) → (0.85, 1.95) を波打つ | 0.035〜0.05 | 0.05〜0.07 |
| 枝1 | 主脈 w=0.9 付近 → (−0.75, 1.55) | 0.02〜0.03 | 0.035 |
| 枝2 | 主脈 w=1.25 付近 → (0.75, 0.75) | 0.02〜0.03 | 0.035 |
溝の底が発光（奥ほど強い、縁は黒い冷却部）。脈から ±0.25m は煤、±0.06m は焼け。

## 結晶
| 群 | 本数 | 長さ | 半径 | 位置 |
| --- | --- | --- | --- | --- |
| 主脈の束 | 3 か所×4〜6 本 | 0.10〜0.38 | 0.02〜0.06 | 主脈 t=0.3 / 0.55 / 0.8 |
| 点在 | 8 | 0.06〜0.16 | 0.012〜0.03 | 主脈・枝に沿って |
結晶の向き：正面の法線（−Y）を基準に上向きへ 20〜40° 傾け、ばらつき ±25°。根元は 0.05+半径 埋まる。

## 欠け・劣化
- 外形の欠け（右上・左下）、割れ面と段差、角の摩耗
- 脈まわりの煤と焼け、上向きの棚に灰
