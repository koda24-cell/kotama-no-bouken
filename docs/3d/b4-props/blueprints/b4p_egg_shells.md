# 設計図 b4p_egg_shells（#15 割れた竜の卵殻と破片）

原点＝底面中央。単位 m。人 1.6m と比較：割れた卵の高さ 0.65m＝人の膝上。

| 項目 | 値 |
| --- | --- |
| 全体 | 約 1.5 × 1.2 × 0.65 |
| 三角形 | ≦ 6,000（卵 ≦ 3k、破片 合計 ≦ 2k） |
| テクスチャ | 1K |
| 点光源 | 卵の中 1（4W） |

| 部品 | 寸法 | 割れ口・置き方 |
| --- | --- | --- |
| 割れた卵（下半分） | 元の卵 高さ 0.82、最大半径 0.31、殻の厚み 0.016 | 割れ口は高さ 0.52±0.08 の三角の歯 7 枚＋細かいぎざぎざ。8° 傾けて 0.04 沈める |
| 大きな破片（頂部） | θ 幅 1.4rad、z 0.50〜0.82 | 凸面を上に、卵の右 (0.55, 0.10) |
| 大きな破片（側面） | θ 幅 1.1rad、z 0.22〜0.58 | 凹面を上に（内側の焦げた赤を見せる）、左手前 (−0.45, −0.30) |
| 小さな破片 | 5 枚、θ 幅 0.3〜0.5rad、z 幅 0.10〜0.16 | 裾に散らす（半径 0.45〜0.75） |

- 外：黒い殻、赤茶のまだら、所々に細い赤熱の亀裂、上向き面と凹みに灰
- 内：焦げた赤茶の膜、底ほど燠のように赤い
- 割れ口：殻の層の断面（灰がかった茶）
