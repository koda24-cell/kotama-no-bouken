# 設計図 b4p_dragon_skull（#13 半分埋もれた竜の頭骨）— v7 作り直し（断面 loft 方式）

リード判定（v6 不合格）: ボクセルの粘土塊に見え、骨の構造（下顎・歯列・眼窩・鼻孔）・薄い板・稜・穴が読めない、角がソーセージ状、色が明るい土色。
→ v7 から ボクセルをやめ、断面を loft でつないだ頭蓋に貫通穴を開け、歯・下顎・角は別部品にする。

原点＝底面中央。単位 m。人 1.6m と比較：角の頂 1.1m＝人の胸、長さ 2.4m＝人の 1.5 倍。
