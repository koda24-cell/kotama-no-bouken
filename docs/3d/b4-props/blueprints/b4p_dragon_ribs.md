# 設計図 b4p_dragon_ribs（#14 肋骨のアーチと椎骨、通路をまたぐ）

原点＝底面中央。通路は Y 方向に抜ける（アーチの下を人が通る）。単位 m。
人 1.6m と比較：アーチの頂 3.2m＝人の 2 倍、アーチの下の通れる幅 約 2.6m。

| 項目 | 値 |
| --- | --- |
| 幅(X)×奥行(Y)×高さ | 4.0 × 2.0 × 3.2 |
| 三角形 | ≦ 20,000 |
| テクスチャ | 2K |

| 部品 | 寸法・位置 |
| --- | --- |
| 背骨（椎骨 6 個） | X=−1.85 の地面に Y=−0.95〜+0.95 で並ぶ（間隔 0.38）。椎体 長さ 0.30・半径 0.20、棘突起 上へ 0.45（太さ 0.08→0.03）、横突起 左右 0.25。0.10 沈める |
| 肋骨 | 6 本、椎骨ごとに 1 本。根元 (−1.80, y, 0.35) → 頂 (0.2, y, 3.2) → 先 (+1.95, y, 0) で地面に刺さる。断面は扁平（面内の幅 0.18→0.09、厚み 0.10→0.05） |
| 折れた肋骨 | 2 本（2 本目と 5 本目）が 55% / 62% で折れる。折れた先は地面に転がる（長さ 1.0〜1.3） |
| まわりの岩 | 背骨の根元と肋骨の先に 12 個（径 0.12〜0.30） |

## 劣化
- 折れ口の断面（多孔質）、乾燥割れ・穴・剥離、下ほど煤（地面から 1.2m まで）、上向き面に灰
