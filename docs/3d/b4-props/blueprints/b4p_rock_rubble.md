# 設計図 b4p_rock_rubble（#19 崩れた岩の山）

原点＝底面中央。単位 m。人 1.6m と比較：高さ 0.7m は人の膝〜腰。

| 項目 | 値 |
| --- | --- |
| 幅×奥行×高さ | 1.8 × 1.5 × 0.7（許容 幅1.6〜2.0、高さ0.5〜0.8） |
| 三角形 | ≦ 8,000 |
| テクスチャ | 1K |
| 点光源 | 鉱石の欠片の近くに 1〜2 個（各 2〜4W） |

## 岩片（角張った玄武岩、割れ面多め）
| 群 | 個数 | 大きさ（最大径） | 配置 |
| --- | --- | --- | --- |
| 大 | 3 | 0.55〜0.75 | 山の芯。中央 ±0.35 に寄せ、1つは板状に斜めに立てかける |
| 中 | 8 | 0.25〜0.40 | 大の上と周り（下の岩に乗せる＝レイで支え高さを求める） |
| 小 | 16 | 0.08〜0.18 | 裾に散らす（半径 0.5〜0.95）、一部は中の上 |
| 鉱石の欠片 | 5 | 結晶 0.06〜0.16（半径 0.015〜0.035） | 岩の隙間から覗く・裾に転がる |

## 欠け・劣化
- 新しい割れ面 55%（崩れて間もない）、残りは灰をかぶった古い面
- 角の欠けと摩耗、上向きの面に灰、岩の隙間（凹み）は暗く
