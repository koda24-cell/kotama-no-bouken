# 第3層V3：上下に探索する風化した都市

## 制作の基準
ユーザーの11月27日の修正一式を今回の基準とする。V2の技術検査合格は美術合格ではない。最新development 80c93b27のUI・編成・育成・通常第一層表示・モバイル制限を取り込んだ独立ブランチで実装する。V2原本・正常画像・出典は保持する。通常ゲームへの正式素材昇格は行わず、検証用の第3層だけを差し替える。

制作前のPinterest検索6題材、40件のサムネイルを実視認。記録は research/F3_CITY_V3_PINTEREST_20261127.json。参考画像自体はゲーム素材や公開確認サイトへ流用しない。空だった崩落題材は、提示画像と実写真の骨組み・部材写真を補助資料にする。

## 空間の設計
- 7F「閉じた旧市街」：地図全域を使う路地・複数の周回・行き止まりの設備跡。住居入口、廃車、電柱、垂れた架線、連続する蛍光灯設備。最長の見通しを区切り、支持のある梁・パイプラックを重ねる。
- 8F「工場と廃植物館」：地上0mから階段で3.2m、上部6.4mへ歩く。踊り場、曲がる歩廊、建物側の出入口まで連結。廃植物館は錆びたトラスと破れたガラス屋根、育った根・湿った瓦礫・浮き上がった舗装。暗い側廊と斜めの陽光が届く吹き抜けを連続させる。
- 9F「水没都市と白い記憶の庭」：広い平地を廃ビルの塊、崩れた階床、水路、橋で分割。低い壁越しに水中の窓・柱・沈んだ路面が見える。モニュメント前だけは約20m四方の余白を作り、白い花と葉が足元を埋める。都市全体を広場にしない。
- モニュメント：像本体約6.4m＋段状台座約1.5m、全高約8m。通路中央を塞がず、対話地点を台座前縁に置く。周囲の白い花は低ポリゴンの透過カード／アトラスを群落として配置し、風を位相差で流す。
- 階高は4mの歩行セルと対応する高さ場で管理。階段セルを進むと足場・カメラ・NPC/FOEが同じ標高へ移る。装飾だけの階段と、実際に登れる階段を混同しない。上層経路は行き止まりでなく、踊り場・橋・別の下りへ接続する。
- 壁は正面だけでなく側面・背面・床・基礎を持つ塊。凹部には奥壁と側壁、継ぎ目には厚い接合材を用意。移動・旋回中に空が見えないことを確認する。傾斜・崩落は支持・破断面・堆積物を伴わせる。

## 質感と光
既存の検査済みCC0コンクリート、破断面、錆、アスファルトの写真PBRを優先再利用。新たな直接利用候補：Poly Haven Utility Box02 / Power Box01 / Abandoned Greenhouse、ambientCG AsphaltDamage001 / Asphalt022。公式ページのCC0を確認し、取得・読込・実レンダリングは別の状態で記録する。車など適切な直接利用原本が確保できない部品は、実写真を構造参考に独自造形する。

全域の照明を暗くするのではなく、屋根下の遮光・構造AO・接触影と、開口から斜めに通る陽光・微粒子・穏やかな揺らぎを分ける。花の広場は明るいが白飛びさせず、足元の葉の輪郭を残す。水は低彩度、反射・深度吸収・波紋・岸の堆積・水中の構造を組み合わせ、青一色のタイルにしない。
