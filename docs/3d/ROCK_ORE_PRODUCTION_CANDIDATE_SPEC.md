# 岩・鉱石制作の仕様候補 — V13/V14からの再利用

更新: 2026-11-19
状態: **仕様候補（任意）**。既存の3D品質・安全性・正式素材承認ルールを置き換えない。

## 適用場面
今後の岩、鉱石、結晶群、岩棚、崖用の小物を新規制作・改良するときに検討する。制作目的と対象階層に応じて必要な項目だけ採用する。

## 推奨候補
1. **既存の岩モデルと生成ノウハウを再利用**：実物の岩の不規則な輪郭・侵食・割れ目を優先。既存の元メッシュは破壊せず、複製や追加造形で差分を作る。元のPBRテクスチャと法線の情報は可能な限り保持する。
2. **形状のバリエーションを先に作る**：低く横長、背の高い岩、角張った岩、板状、非対称、小・中・大型など。単純な一様スケーリングだけでなく、輪郭、破断面、接地形状、侵食、結晶の成長位置を変える。
3. **ニュートラル色を基本に色替え可能な設計**：岩と結晶のマテリアルを分け、後から階層ごとの色調を適用できるようにする。既存の採用済みカラーは維持する。
4. **結晶の成長は実岩面に沿わせる**：レイキャストまたは近傍面への投影で根元を接地させ、浮き・埋没・不自然な均等配置を検査する。大きい結晶を少数、小さい結晶を多数などの非均一な密度を検討する。
5. **寄せて組み合わせやすく**：サイズ・幅・高さ・接地面・シルエット・結晶密度を変え、並べたときの反復模様を避ける。ゲーム内1マスや通路幅に応じて寸法を再確認する。
6. **実レンダリングで比較**：Blenderで正面・側面・斜めを確認し、比較シートで自然さ・輪郭・岩肌・結晶の付き方・テクスチャを判定する。PNG/GLBの実出力と成功ログを検証する。
7. **軽量化を同時検討**：近景品質を維持しながら、距離別LOD、見えない面、メッシュ・マテリアル数、描画負荷を検査する。GLBを実ゲームで確認するまで性能を断定しない。
8. **安全性と保存**：外部取得素材はClamAVとBlender Python安全検査を実施。実行中のGitHub Actions Artifactsは一時保存。承認後、GLB/PNG/マニフェストを正式保存する前に元run・ハッシュ・サイズ・ライセンス・品質を確認し、独立ブランチからdevelopment向けPRで管理する。
