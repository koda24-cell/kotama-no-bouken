# 第2層 木製水車・車軸本体1本 V01 造形設計（2026-11-19）

Status: NOT_APPROVED / design-first / individual model only

## 前提・既存モデルとの関係
- 既存ゲームの水車：車軸はX方向、軸半径R=.300m、中心座標Y=3.7m/Z=0（ゲームワールド系）。今回のGLBは独立ローカル原点(0,0,0)に設計し、既存ランタイムの車軸形状・挙動を変更しない。
- 木製ハブV11(PR #531)の中心貫通穴R=.303m。実接触許容差は未検証。鉄カラーPR #561 の内半径R=.306m。下部軸受けPR #568 はR=.318m、上部軸受けPR #580 はR=.322m。ボルト等PR #596/#623/#625は木材固定側の別パーツ。
- これまでの独立モデルを保存し、今回**車軸1本のみ**造形。組付け・衝突・軸端金具追加は後工程。『次』という指示で既存モデルの正式承認・統合を意味しない。

## 軸の立体造形
- X方向長さ3.45m（-1.725～+1.725）。中心部は広めの8～12角の手斧で削り整えた樫の丸太軸。
- 中央ハブ接触予定範囲：X±.30m、平均R=.297m。外側支持軸頸はX±(.60～1.18m)、平均R=.291m。手斧削りは数mm以下で、局所半径がR=.303mを超えてハブに食い込まない設計。
- 両端は直線的に切っただけでなく、軽い面取り、個別の端木口、局所的なひびの視覚的表現を加える。破断を規則的な三角溝にせず、曲がる幅の違う裂け目を使用。
- 木の芯を引っ張り伸ばした筒ではなく、方向に沿って少しずつ変わる楕円性・手削りによる微妙な平面をメッシュで再現。全体は**1つにつながるソリッドメッシュ**を前提とする。既存1マスのグリッド配置や水車の回転軸Xの設定を維持。

## テクスチャ
- 完全自作512×512茶色木目PNGと独立512×512木口PNGの2枚をPython/Blenderで生成（第三者画像やPinterest写真を直接利用しない）。長手木目の不規則なうねり、節/樹皮跡、汚れ、湿った変色、乾燥割れの暗色を表現。
- 端面は同心円の規則リングを避け、ずれた成長輪と部分的ひびを不均一に。長手側はgrain along X、端面はYZ平面UV。
- 完成後GLBに2枚のPBR画像を埋込。ゲームの遠景では細かな木目を省略するLOD候補を研究するが、今回ゲームへLOD統合はしない。

## Blender / 品質確認
- Blender 5.3.0 + ClamAV digest固定の共通Dockerを原則使用。描画は正面(X軸に沿った木口)／側面／斜め／背面の実Cy​​cles 4方向PNG(各850px)、GLB、編集用Blend、PNG素材、SHA manifest。実データファイルのダウンロードと検査が完了するまで「成功」と言わない。
- GLB内部は**1メッシュ、2埋込画像、カメラ・灯なし**。SHA256照合。出力はClamAVを定義DBをロードして実スキャンし感染0を確認する。外部ネット写真ダウンロードはしない。
- 近景の木目・木口・接触部・形状を4方向比較し、アート品質判定と技術検査を分離。木材としてプラスチック感が残る場合は別バージョンで再造形。
- 現行のBlender Docker SHA256: 5ce601f79b1ab09405b3ebc36b1a596be76cb8b105b1524fcbafcb186ebf7e99。検査用ClamAVデータベースの書込は UID100/GID101 に注意。
