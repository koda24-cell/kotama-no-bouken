# B2 水車用 鍛鉄座金1枚 V01 設計

前提：丸頭ボルトV04 PR #596の軸半径0.035m、六角ナットV02 PR #623の内穴R0.037mを参考。前モデル・木製軸受けPR #568/#580・ゲーム本体を変更しない。1枚の独立部品のみ。

- 中央貫通穴 R0.038m。外径は半径0.106m前後。厚さ約0.016m（場所によって不規則な反り）。実際に穴のある立体リングで、表裏と縁の面取りを備える。
- 古い鍛鉄を打ち出したような数mmの局所的な歪み、いびつな外周、小さな縁欠け、接触面の擦り跡。ギザギザの歯車にしない。

- ボルトの軸に通る理論クリアランスは半径3mm。実ボルトV04や木台との仮組み・干渉・螺合は未検証。
