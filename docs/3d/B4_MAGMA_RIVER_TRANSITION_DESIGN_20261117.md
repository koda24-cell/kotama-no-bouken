# 第4層 マグマ地帯 — 溶岩河川と灼熱洞窟の制作設計 V1

状態: **設計・参考収集段階**。GLB・PNG・レンダリングはまだ生成していない。完成承認前はdevelopmentへマージしない。

## 方針
- 第4層は廃坑に限定せず、**マグマが主役の灼熱洞窟**を広く展開する。既存の完成済みV33マグマ壁は再制作せず、床・流路・岸・洞窟への接続に活用する。
- 第1候補モデル: `b4-magma-river-bank-v1`。溶岩河川と冷却玄武岩の岸がつながるモジュール。直線・四角形・均等な岩塊配置を避ける。
- 空間構成: 暗い火山岩の崖、幅が不規則な溶岩河川、岸辺の半固化した黒い殻、裂け目から見える赤熱部、落石、岩の橋脚、熱の揺らぎ。
- 遠景には溶岩の滝・光る亀裂を配置し、プレイヤーの一人称迷宮視点からも赤熱の存在感が伝わるようにする。
- ゲーム用には通路接続方向（N/E/S/W）、溶岩/陸の隣接関係、衝突・通行可否を定義する。ランダム配置でも不自然な切断面を生まない。
- マテリアル: 黒褐色の多層玄武岩、PBR粗さ/法線/凹凸、明暗が不均一な溶岩表面。発光はメッシュと別のVFX（火の粉、噴気、熱ゆらぎ）として扱う。
- Blenderで正面・側面・斜め・ゲーム視点を撮影し、修正を繰り返す。GLB/PNG/manifestを成果物とする。実行成功を確認するまでレンダー完了と書かない。
