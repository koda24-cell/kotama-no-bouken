## 方針
- 第4層は廃坑に限定せず、**マグマが主役の灼熱洞窟**を広く展開する。既存の完成済みV33マグマ壁は再制作せず、床・流路・岸・洞窟への接続に活用する。
- 第1候補モデル: `b4-magma-river-bank-v1`。溶岩河川と冷却玄武岩の岸がつながるモジュール。直線・四角形・均等な岩塊配置を避ける。
- 空間構成: 暗い火山岩の崖、幅が不規則な溶岩河川、岸辺の半固化した黒い殻、裂け目から見える赤熱部、落石、岩の橋脚、熱の揺らぎ。
- 遠景には溶岩の滝・光る亀裂を配置し、プレイヤーの一人称迷宮視点からも赤熱の存在感が伝わるようにする。
- ゲーム用には通路接続方向（N/E/S/W）、溶岩/陸の隣接関係、衝突・通行可否を定義する。ランダム配置でも不自然な切断面を生まない。
- マテリアル: 黒褐色の多層玄武岩、PBR粗さ/法線/凹凸、明暗が不均一な溶岩表面。発光はメッシュと別のVFX（火の粉、噴気、熱ゆらぎ）として扱う。
- Blenderで正面・側面・斜め・ゲーム視点を撮影し、修正を繰り返す。GLB/PNG/manifestを成果物とする。実行成功を確認するまでレンダー完了と書かない。

### 合格基準（未達項目があれば再制作）
1. 俯瞰で溶岩の中心線が明確に蛇行し、均等幅の直線帯に見えない。
2. 正面と斜めでマグマが岩の隙間を流れていることが読める。岸の浮き・交差・大きな矩形輪郭がない。
3. 溜まりが流路につながり、唐突な円形の浮遊板にならない。
4. 上部からの落下流と落下先の位置が自然につながる。流れが板状・リボン状に見えない。
5. 玄武岩の色/質感が全体で統一され、マグマが白飛びせず、周囲への照り返しが見える。
6. GLBのテクスチャ埋め込み、正面/側面/斜め/俯瞰PNG、Blend、manifestの実ファイルを確認。

## V3評価 / V4重大修正（2026-11-17）
- V3 run https://github.com/koda24-cell/kotama-no-bouken/actions/runs/43988727667 **success**。Artifact 14287010707、GLB/Blend/4方向PNGを取得し目視確認。
- V3は冷却殻を62枚追加したが、広い茶色の板が溶岩を塞ぎ、発光が極端に細く見えるため**不採用**。
- **根本原因を発見**: V1–V3のメッシュ生成コードはThree.jsと同じY-upで座標を作成したのに、BlenderのZ-upに変換していなかった。そのため流路が実際には垂直な壁として立ち、滝が水平の帯のように見えていた。V1–V3のレンダはこの座標バグを含むため、ゲーム用地形として不合格。
- V4は全メッシュのワールド行列をY-up→Z-upに90°回転し、ライトとカメラ位置・注視点も同じ座標変換で整合させた。冷却殻を62→35個へ減らし、岩岸寄りに寄せ、サイズも縮小。
- V4は**本来の水平河川と垂直落下流が実際に見えるか**が最優先の確認対象。GLB書き出し後もZ-upを検証すること。
