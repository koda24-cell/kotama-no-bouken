# Five visual-first research passes
1. OpenCV shape descriptors https://legacy-docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html : Hu moments can compare shape independent of scale/rotation, unsuitable alone for fixed-view proportions; use absolute silhouette bounds and row widths first, contour simplification for editable landmarks later.
2. Blender curve geometry https://docs.blender.org/manual/en/latest/modeling/curves/properties/geometry.html (older 2.91 documentation reviewed), subdivision https://docs.blender.org/manual/en/latest/modeling/modifiers/generate/subdivision_surface.html : cubic control points, taper, bevel and creases; retain intentional sharp edges; start with sampled cubic curves, verify Blender 5.3 later.
3. Blender modifiers https://docs.blender.org/manual/en/latest/modeling/modifiers/introduction.html and instances https://docs.blender.org/manual/en/latest/modeling/geometry_nodes/instances/instance_on_points.html : preserve source mesh, ordered modifier recipes, seed-controlled decoration variation, selective placement and scale. Overlaps permitted. Verify GLB export and triangle budget separately.
4. Principled BSDF https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/principled.html : record base color, roughness, metallic, alpha, normal texture and lighting separately; compare under matched neutral and game lighting; hand-painted stylization not required to be physically realistic.
5. scikit-image metrics https://scikit-image.org/docs/stable/api/skimage.metrics.html : SSIM and Hausdorff complement silhouette IoU; fixed camera, resolution, exposure, alpha treatment; use regional scores and human review, not universal pass threshold. Save difference maps, parameters and revisions; never automatically optimize away intentional details.
Implementation in this revision: research notes and basic cubic sampling / mask profile utilities. Other functions are planned, not validated. External libraries are references, not installed. No internal intersection rejection. No asset promotion.
