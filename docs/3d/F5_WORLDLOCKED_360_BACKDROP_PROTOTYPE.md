# 5層 360度背景・視点固定問題の改善試作

## 問題
従来の5層遠景ビル背景は視線を回しても背景が張り付いて見える。画面固定の背景やカメラ回転に追従する板ポリゴンでは方位差・視差が成立しない。

## 今回の試作
- `tools/f5-backdrop/worldlocked-360-backdrop.mjs`: Three.jsを引数で受け取る独立モジュール
- 天空ドームはカメラの**位置のみ**追従し、回転には追従しない
- ビルはワールド座標に固定し、360度全方向に疎密のある遠景64棟・中景24棟を生成
- 近めのビルと遠いビルで、移動時に異なる視差が発生
- 共有BoxGeometry/Material、静的変換、固定seedで低コスト化を意識
- 外部画像を使用しない初期プロトタイプ。現在の5層ゲーム描画への接続は**未実施**

## 利用イメージ
```js
import { createFloor5Backdrop } from './worldlocked-360-backdrop.mjs';
const backdrop = createFloor5Backdrop(THREE, { seed: 51119 });
scene.add(backdrop.root);
// render loop, after camera position is updated:
backdrop.update(camera);
// on stage exit:
backdrop.dispose();
```

## 要検証
1. 実際の5層シーンで0/90/180/270/360度の連続回転。カメラ回転に対しビルが画面固定にならないこと
2. 前進・横移動による中景/遠景の視差と近接時のクリッピング
3. 建物のシルエット、窓明かり、瘴気、空の美術品質。現状は箱型ビルの**技術検証用**であり完成素材ではない
4. 視点高さ、床との接続、ビルの見切れ、fog/深度、既存の5層VFXとの競合
5. モバイルFPS、描画回数、ジオメトリ共有、LOD、シーン離脱時のdispose
6. 必要ならBlenderで全方位の遠景テクスチャを別途生成し、方向に整合する球体UVへ適用。実際の近景・中景3Dは残す

## 承認・保存
既存5層のビル背景とVFXは上書きしない。独立ブランチで試作し、実ゲーム上で全方向を検証してから承認・PR統合する。
