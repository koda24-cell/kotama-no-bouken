# 第一層・段階的な地下神域 V4

ユーザーの3枚の実画面批評を根拠に、今回は単独・逐次で制作する。新規の並行agent/並行モデル生成は行わない。元の素材/画像とV3の試遊URLを保存し、改修版を別branchで検証する。

## 順番と受入条件

1. **通路の構造を先に変更**。3Fの歩行セル106、行き止まり11、分岐点11の手設計。階段/ボス門の接続、NPC/箱/灯/看板の接近をBFSで確認。固定ID/座標/報酬と保存形式は保持。旧位置が新壁になるセーブは既存loadの通行検査と開始地点fallbackを利用し、フラグをリセットしない。
2. **一つ目の個別モデル: 両面石組アーチ**。原本を保持した新候補。背面を平らな下地で済ませず、裏にも欠けた石/目地/根を持たせ、側面の控え柱と壁の接続を作る。GitHub Actions共通Blender5.3+ClamAVで単体制作→書出GLB再import→4方向PNG→構造監査→目視して次へ。
3. **柱・梁と神域の行き止まり**。鳥居[50,0,12]→祠[44,0,12]を枝道の終端に置く。前の歩行セル[12,3]で正面へ向く。接続アーチと左右壁、石碑/お札/根/瓦礫でまとまりを作る。柱は廊下の左右と交差部に配置し、梁/天井まで構造をつなぐ。池内の柱で広い見通しも切る。
4. **水と採光**。緑/青を抑えた灰色寄りの水。実際の天井/柱を反射する単一平面reflectionを低解像度で共有し、距離/画面外で更新を抑制。11tileごとにreflectionpassを作らない。局所穴には下へ落ちる光の筋/塵とspotlightを合わせる。穴上部の明るさだけでは採光成功としない。
5. **1F→2F→3Fの移行**。元の1F/2Fの間取りと遊びを保ち、1Fは苔/壁根/少数の支持柱、2Fは柱と石の接続・蔓と湿潤表現を増やし、3Fで深い地下神域になる。全て同じ緑/湿石のトーンだが単純な一律scatterにしない。
6. **実ゲームを順に確認**。1F、2F、3Fの同じ目高1.6mで各段階の見え方を確認。水/穴光/アーチ裏/行き止まり/柱梁を別cameraで確認。map topology/セーブfallback/イベント/階段/戦闘/資源disposeも検証。main公開は変更しない。
