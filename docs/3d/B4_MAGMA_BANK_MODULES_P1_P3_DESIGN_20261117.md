## 品質条件
- 溶岩が水のように見えないよう高ラフネス・冷却殻・非周期的な熱亀裂を優先。
- 溶岩面を空中に浮かせない。地形の溝へ埋め、断面を暗い岩で覆う。
- 側面の直線的な板形状を避け、厚い岩盤・崩れた縁・岩の層理で輪郭を分割。
- 細かい粒の乱用や等間隔の岩ブロックは避ける。大中小の破断形状を混ぜる。
- 正面・側面・斜め・俯瞰の**Blender実レンダリング**とGLB・Blend・manifestを出力し、目視後に具体的な修正点を記録。
- モデルを並べたときの隣接タイル継ぎ目とゲーム内性能は未検証。実寸・タイル基準はClaudeが既存ゲームコードを確認してから合わせる。
- 3候補は**NOT_APPROVED**。完成承認まで正式素材フォルダやゲームには入れない。

## 実装計画
1. `tools/floor4/magma_banks/build_bank_modules.py` に3つの地形パターンを独立生成。
2. GitHub Actionsで3 GLB + 3 Blend + 12 PNG + manifest、ソースSHA/実行IDを記録。
3. 4方向PNGを実際に確認して形状・厚み・テクスチャ・境界を改善。
4. ユーザー承認後にのみ別PRで正式保存・developmentへ統合。Claudeはその後のゲーム実装を担当。
