## User request
「かけたような表現に使えるテクスチャを用意して貼ってください。何ならこれに合うのを生成してくれてもいいよ」

The independent texture was generated by Blender/Python as an **original 512×512 PNG**. Not sourced from Pinterest or another licensed photograph, so no third-party redistribution claim is made. Existing original hub mesh, actual Boolean wood chips and mortise sockets, and the packed V11 CC0 Fine Grained Wood photographic material remained in use for intact wood surfaces. The generated texture is applied only to fracture-face geometry.
