# 共有ツール・アドオン・技術情報 登録／検証ポリシー

最終更新: 2026-11-14。GPT・Claude共通の運用ルール。ゲーム内への素材統合とは独立した**情報系の即時共有**を扱う。

## 最重要: 発見したら同じ作業中に共有する
1. 3D/2D/アニメ/音楽/テクスチャ/シェーダー/Blenderアドオン/生成補助/自動化の**新しい情報・ツール・導入方法**を見つけたら、機能の完成やレンダリングを待たずに本台帳へ登録する。ユーザーへの個別確認は不要（有料購入・権限変更・破壊的変更は別）。
2. 登録項目: 名称、公式URL、目的、対象領域、ライセンス/再配布条件（不明なら未確認）、導入状態、検証状態、担当、導入手順、関連ブランチ/PR/Actions、注意点。確認できていないことは明示する。
3. 新規情報はまず共有ドキュメントだけの独立ブランチ/PRに記録し、レビュー可能なら**同じ作業の中で development にマージ**する。main は触らない。実装・モデル・外部コードを未検証で自動マージしない。
4. 導入・実行・実レンダリング・ライセンス確認後、同じ項目へ**検証日時・環境・実行コマンド・結果・証拠URL・既知問題**を追記する。成功したことだけでなく失敗・未確認も残す。
5. GPT/Claude は作業開始時に AGENTS.md → 本ポリシー → `docs/3d/SHARED_TOOLING_CATALOG.md` → 対象分野の技術資料を読む。Claude が Blender を直接操作できない環境では GLB/PNG/manifest を使う。
6. 画像参考資料は Pinterest を優先し、`koda24-cell/pinterest-reference-library` の AGENTS.md に従って依頼・取得・保存先・参考点を別途共有する。テクスチャや第三者画像のライセンスは個別確認する。
7. GitHub Actions Artifacts は一時保存。**情報の保存と、コード導入、実動作確認、完成素材承認は別の状態**として記録する。

## 「自動」の範囲
GPT/Claude が新規機能を見つけて GitHub に書き込める作業セッションでは、**その場で登録と共有PR・安全な情報のみのマージを実施する**。別チャットや別エージェントの発見を無条件にリアルタイム監視できるわけではない。継続的な完全自動同期には、各リポジトリのGitHub Actions/権限設定・イベントトリガーの追加検証が必要。未設定なのに自動同期済みと報告しない。

## 変更・マージの安全境界
情報・リンク・検証結果は即時共有。実行コード、アドオン本体、外部配布物、GLB、PNG、ゲームコードはライセンス・動作・ユーザー承認の既存ルールに従う。機能の評価は、再現可能なログと実レンダリングがある場合のみ「検証済み」とする。既存の制作PRや他チャットの作業ブランチを勝手に統合しない。
