# 一層3F・苔の封鎖遺跡 第3改訂の制作前設計

2026-11-17 JST / space_design_v3。状態: **制作前設計。配置・造形・実ゲーム検証はこれから**。旧試験の美術合格を引き継がない。根拠JSON: [f1-closed-ruins-v3-plan.json](drafts/f1-closed-ruins-v3-plan.json)。数値は検証済み実装値ではなく、次の制作と画像審査に使う目標値。

## 今回の主題と変更理由

**天井に覆われ、湿った深緑の根と苔に侵食された禁足の石造迷宮。空は崩落穴から局所的にだけ見える。** ボス前だけ少し高さと幅が緩む。庭園のような土色の広場は作らない。前半と同じ一層の暗さ・湿度を維持し、後半の変化は開放ではなく「埋没の深まり、根の侵入、祭祀の痕跡、水没」で付ける。

旧 `game-layout-trial.json` の実数は歩行床274、水11、天井17、壁178、props129、非歩行支持土177。非壁285セルのうち天井は17だけ、約6%だった。さらに # の支持土177が見渡せる庭面として露出し、孤立した杉25本・シダ42群・花14群では空白を埋められなかった。現在の実ゲーム画像04・05・14とユーザー提供画像を確認した。今回ここを構成から修正する。

ユーザーの6点を以下に反映する。

| 指摘 | 制作で変える内容 | 実画面の確認点 |
|---|---|---|
| 全面の空 | 連続天井・壁上の接続・穴3箇所に限定 | 普通の通路に空の帯や地平線を出さない |
| 土色、手入れ感 | 苔・湿った根・葉の堆積を面でつなぐ | 一層の緑が画面全体の基調、朱と白は局所 |
| 空白と一直線 | #島を柱・根塊・崩落塊で埋め、狭い建築断面を作る | 霧だけで隠さず手前に実形状の遮蔽がある |
| 水が単色、岸が格子 | 水中石材・藻・弱い揺らぎ、崩れた岸の前後層 | 装飾的な神社の池でなく、水没した廃構造 |
| 物が孤立 | 主役ごとに基部・根・瓦礫・下草を結ぶ | 茎だけ/石碑だけ/幹だけが裸地へ刺さらない |
| 床のマス感、素材未使用、宗教物が無関係 | 連続苔床、トンネル再利用、鳥居祠の同軸 | 4mごとの茶/石の矩形と無関係な配置を解消 |

## 座標とゲーム保持境界

4m/セル、world=(tx×4,Y,ty×4)、北=-Z、視点高1.6m。床の歩行高0、全移動sweep幅2m/高さ3mを確保。map配列28×18、#219、非壁285、水11、固定7対象・FOE・保存形式・戦闘・1F/2Fは変更しない。#の表面を庭に見せないが、歩けるようにはしない。通行セルへ木の幹や倒壊柱を置いて「見た目だけ通行不可」にはしない。

**この設計は本当の通路曲折を増やさない。** 既存の最短進路には(5,15)〜(19,15)の長い東西リンクがある。nav保存の条件では根・柱をその中心線へ立てて曲げることはできない。天井断面、アーチ、側方の大きい根塊、低い描画距離で場所ごとの差を作る。これで冒険性が足りない場合は、map/旧save移行を含む別設計が必要であり、単なる植生増量を新しい探索構造と呼ばない。

## 建築断面、屋根と局所穴

- 基本の天井下面4m。壁4mの上端へ確実につなぎ、崩落壁の背後にも屋根か閉じた根・石塊を続ける。旧支持土177を露出する空の庭として残さない。
- 歩行中心の天井被覆90%以上を最低目標とする。全非壁285セルを基本被覆し、宣言した穴の細部だけを開ける。#の島も閉じたmass/屋根で支え、単なる黒背景やfogに任せない。
- 穴は**3箇所**。セル丸ごとの庭開放ではなく、不規則な小開口として制作する。

| 穴 | tile / world XZ | 半径目標 | 内容 |
|---|---|---|---|
| 根の傷口 | (8,13) / (32,52) | 1.25m | #島の崩落。根と一本の太い幹が上へ続く。高木の枝・屋根干渉を別途検査 |
| 水の光井戸 | (15,8) / (60,32) | 1.6m | 水面を照らす部分開口。周囲は石天井、根、湿った梁 |
| 祠の光井戸 | (13,3) / (52,12) | 1.2m | 祠上の裂け目。広い中庭と樹海の空にしない |

高木は旧25本を維持せず、穴へつながる一本程度に限定する。屋内の密度は根・シダ・苔・低木・蔓で作る。完全な天井へ杉の樹冠を突き抜けさせない。幹だけ穴を通っていても低枝が石屋根を横断しないかGLB三角形と目高画像で確認する。

ボス前(22〜25,2〜4)だけ下面4.8mの案。既存壁が4mなので上部に根/石の閉鎖が必要。閉鎖部を制作できない場合は4mに据え置き、0.8mの空の隙間を出すことを許容しない。

## 鳥居と祠の関係を直す確定座標案

祠は既存 # (13,3) のworld **[52,0,12]** を維持し、rotationY=**+π/2**で東を向ける。鳥居は旧入口[28,0,60]から **[58,0,12]**へ移し、rotationY=**−π/2**。6mの東西同軸で、鳥居の先に祠が見える。鳥居はセル(15,3)→(14,3)の境界に置く。柱がx58付近/z10.2,13.8に入り、cardinal中心x56/60とz12の2m sweepから逃がせる見込みだが、**実GLB三角形の検証前に通行合格としない**。

拝礼停止セルは(14,3)、world[56,1.6,12]、左向き。`wall_14_3_left` は既存scaleY=.32の低い囲いを維持し、祠の#は通行不可のまま。`wall_13_4_up`は全高scaleY=1へ戻し、南の横漏れを閉じる。低い囲い、基壇、札、苔、石の導線を同じ軸へまとめる。鳥居・祠を単に近付けるだけでなく、正面から一枚の画像に収め、通り抜け→拝礼停止の意味が読めることを確認する。

旧入口は宗教物を散らさず、根のトンネルへ変える。鳥居を入口にも増設する場合は別物を個別制作し、同じ神域へ向かう理由を設計する必要がある。

## トンネル素材が見えなかった理由と再利用位置

実データを確認した結果、候補17点に `mod_sacred_arch_4m.glb` は存在するが、実ゲームtrialの129 propsには**0配置**。独立制作sceneでは `assemble_scene.py` の `sealed_corridor_mouth` と `inner_seal_arch` に使われていた。従って「制作したが実ゲームの配置へ入っていない」状態だった。

旧F1は非壁全セルへ `mod_ceiling_vault_4m` / `mod_ceiling_roots_4m` をy4で並べ、トンネルの断面を作っていた。`living_root_arch` は `exit` 専用で、3Fにexitがないため出ない。`ruin_archway`、`mod_pillar_corner`、`ruined_stone_pillar` も既存GLBがあるが、現共有FILESには未登録。いずれも原本不変で再利用可否を実読込検査する。

- 入口: tile(5,15)/(7,15)、world[20,0,60]/[28,0,60]に候補アーチ、Y回転−π/2。両側#と連続天井へつなぎ、根の圧迫と石の重みを作る。
- 北側封印通路: tile(10,4)/(12,4)、world[40,0,16]/[48,0,16]、Y回転−π/2。4mごと同じ門を並べず、2門の間を割れた梁/片柱/付着根で変える。
- アーチは2×3m以上の開口と全route sweep、固定対象の操作域を実形状で再検査する。geometry中心だけの判定で合格にしない。

## 緑・床・配置密度

基本色は暗い苔緑、湿った灰緑石、腐植の黒褐色。広い黄土色の面をなくす。朱は鳥居の剥落部分、白は小花と札に限る。1Fの青緑の湿度と暗さへ戻すが、全面真っ黒や均一な緑フィルタにはしない。

#島は柱の基部、根のまとまり、天井から落ちたブロックで埋め、外周にシダ/低木、手前に落葉と苔をつなぐ。床/柱/天井の荷重関係、崩落元と瓦礫の落ちる方向を合わせる。単一オブジェクトの散布数を品質指標にしない。

床は小さい石の目地と4mセル境界を区別する。石目地は残してよいが、土と石の切替線を4m矩形にそろえない。新規の湿潤苔capを個別制作し、破れた縁・石の埋まり・土の溜まりで隣へ連続させる。全ルート中央を横切る高い根や石は不可。中心sweep内の装飾は高さ.03m以下、支持面Y0を保つ。既存full_rootsoilを全セルに戻すだけの変更はしない。

## 水と岸

水11セルの通行不可は保持。見かけの岸は沈み石、崩落した石段の端、泥/苔の棚、根で階段状gridの前後を隠す。ただし歩ける橋や乾いた地面と誤読する張り出しは作らない。水中に沈んだ石材の輪郭、深浅の色、弱い2スケールの揺らぎと局所反射、岸影へ寄る藻を使う。蓮は整った花壇にせず、採用しても傷んだ葉を疎らにする。水の青い単色面や整備された神社池へ戻さない。

## 制作開始前の調査、個別制作順

rootが実画像確認したPinterest refs: `17592254793828502`（局所光口）、`438632509296728990`（湿潤根）、`1122381538407308579`（狭い石廊下）、`860680178830275106`（同軸鳥居祠）。詳細は参考調査担当の記録を合流する。第三者画像をそのままゲームtextureにしない。参考repoの調査完了commit `7ade42f` の確認後に、次の一個目から制作を始める。

1. 湿潤苔地表cap。一個だけ制作、2×2接続・石/土境界・近景を確認。
2. 根と瓦礫の島基部。一個だけ制作、#で支持土を隠す役割と周囲の通行を確認。
3. 天井の不規則な崩落縁。一個だけ制作、下面・端・光口・壁への接続を確認。
4. 支柱/折れ梁。一個ずつ制作し、連続屋根の構造を成立させる。
5. 小さな根/シダ/蔓群落。各一個ずつ、取付点・地面との接続・陰影を確認。
6. 水際の崩れ石/水中石/浮遊藻。各一個ずつ、単体と水面越しを確認。
7. 完成済みアーチ、鳥居、祠を上記座標へ再配置し、地下の神域として関連を確認。

全て個別GLB、blend、front/side/angle、manifest/hashと再読込画像を残す。まとめてsceneを生成することを一素材ごとの制作・審査の代わりにしない。引用作品は自然の層、湿度、材質の統一、発見の見せ方の比較基準であり、同等品質到達を文書だけで宣言しない。
