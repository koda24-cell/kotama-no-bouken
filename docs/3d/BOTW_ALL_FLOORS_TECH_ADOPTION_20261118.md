## コタマに取り込む設計（公式実装の複製ではなく独自方式）
| テーマ | 適用先 | 実装単位 | 品質・安全ゲート |
| --- | --- | --- | --- |
| 近/中/遠景レイヤー | 全階層 | 距離別の材質・フォグ・彩度/明度・シルエット調整を共通プリセット化 | 同一カメラ・同一露出の3距離画像比較、暗所の可読性 |
| 時間・空間の絵作り | 全階層 | 照明/霧/環境VFXを階層プリセットに集約 | 既存演出保持、色飛び/過度な暗転なし |
| 草・葉の風 | 第1・6層 | 既存草原アニメを保持し、低周波の風波伝播＋葉の位相差を候補追加 | 近景葉形状維持、ループ/ちらつき、fps |
| 水・氷 | 第2層 | 流向マップ、反射/深度色/岸際マスク、滝の縦流動を分離 | タイル継ぎ目、透明ソート、接地 |
| 廃墟・自然侵食 | 第3層 | 地形シルエット・大中小の破損、蔓/苔の配置ルール | 壁高さと通行/衝突保持、視線誘導 |
| マグマ | 第4層 | PR #505の黒い皮膜・亀裂・遅い流動を独立検証。岩との接触、側面厚み、熱気 | WebGL/Blender実レンダリング、正面/側面/斜め/動画、GPU負荷 |
| 瘴気・粒子 | 第5層 | 既存承認済みVFXを保持し、境界ぼかしとプリセット共有 | 水平境界の再発防止、視認性 |
| 花園・樹木 | 第6層 | 既存樹木/草/白百合を保持、遠景樹冠ImpostorとLOD候補 | 原本と8方向比較、近景品質不変 |
| 化学的状態遷移 | 全階層・将来 | 火/水/氷/雷/風と対象材質の組合せを**独立仕様**に定義 | 戦闘属性・セーブ互換を変えない。明示承認前はゲーム実装しない |
| データ駆動VFX | 全階層 | 種別/強度/風向/温度/密度を設定JSONで共通化 | 既存VFXを破壊しない、個別演出と比較 |
| 制作パイプライン | 全階層 | Blender/Actionsで原本GLB、4視点PNG、manifest/SHA、途中保存 | 技術QAと美術承認を分離。未承認はNOT_APPROVED |
| UI/視認性 | 探索/戦闘 | 背景のコントラスト・情報の優先順位を別検証 | 既存操作/レイアウト/アクセシビリティ保持 |
| オープンエアーサウンド | BGM/SE | 距離・階層・環境状態に応じた音響レイヤーの設計 | 外部音源ライセンス確認、既存BGM保持 |

## 全階層で共通の実装インターフェース案（未実装）
- `EnvironmentVisualPreset`: `fogNear/fogFar/fogColor`, `ambientIntensity`, `distantSaturation`, `vfxDensity`, `windDirection`, `windStrength`。型/実際の値は現行レンダラ調査後に決定。
- `MaterialReactionRule`: `element`, `targetMaterial`, `trigger`, `visualEffect`, `duration`。戦闘処理とは分離。
- `DistanceQualityPolicy`: 近景オリジナル/中景バッチ/遠景Impostor。既存の全階層LOD方針と監査Actionsを再利用し、未対応の透明水/溶岩/瘴気には剛体decimationを適用しない。

## 実装の順序と合格条件
1. **基準記録**: developmentと未マージPRの現状、各階層同一視点PNG、fps/draw calls、GLB hash。
2. **独立プレビュー**: 共通プリセットと第4層PR #505のマグマを別ブランチで検証。ゲーム本体は不変更。
3. **3方向+上面/動画**: Blender/Three.jsの実画像でアート評価。シェーダーコンパイル・GPU負荷・継ぎ目を確認。
4. **段階的拡張**: 第6層の風/葉、第2層の水、第3層の廃墟、第5層の瘴気、第1層の神域へ各独立PR。
5. **承認後のみ**: GLB/PNG/manifest正式保存、Claudeへゲーム接続の引き継ぎ、developmentへマージ。mainは別承認。
