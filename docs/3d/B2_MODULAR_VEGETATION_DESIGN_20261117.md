## 造形仕様
- 原点: 根元の地面接触点。地面はGLBに含まない。
- 実測試作: 約0.77×0.80×0.99m。11本の主軸、左右非対称の複葉。GLB約0.33MB。
- 第2層の寒色を浴びた深緑、葉裏の明度と黄緑ハイライト、太い主軸より細い葉柄。葉形状は編集可能な独立ジオメトリで生成。
- 改良優先: ①葉先が一様に直線的②茎が扇形に揃い過ぎ③葉の端に機械的な尖り④岩から生える印象を接地で強める。撮影後に1点ずつ修正。
- 完成条件: 葉が表裏両面表示、正面/側面/斜めでスカスカにならない、通路を塞がない、他モデルに接触しても違和感のない原点。
- 品質優先。まず造形・材質を詰め、必要ならマテリアルをPBRまたはアルファテクスチャに変更。軽量化は品質評価後。

## ランダム混合 API 契約
- `tools/b2-vegetation/placement.mjs` — ゲーム本体とは切り離したシード付き配置純粋関数。
- GLB本体を再利用し、位置/方向/倍率のみ変える。他の岩・氷岸・アーチモデルを変更しない。
- 地形タグ: `wet_rock`, `ruin_crack`, `shore_soil`, `cave_floor` を許可、`water`, `ice_smooth`, `walkway`, `door`, `stairs` に置かない。
- 位置決定には`tileKey + seed`の固定乱数を用い再現性を確保。他のオブジェクトの占有円`reserved`を尊重、最大試行回数を制限、タイル外や通路へのはみ出しを防ぐ。
- シダに当たり判定は設けず通路移動を邪魔しない。描画密度はタイルごと最大3株、生成確率0.42（未調整の初期値）。

### V03で必要な構造変更
1. 旧V01・V02は全保持。V03は別生成器/別GLBとし、葉の枚数の単純な増減ではなく**葉の階層構造**を変更する。
2. 葉柄 → 主軸 → 第一次側枝 → 小葉柄 → 小葉という分岐階層にする。基部側の枝が長く、先端側は短くなる。主軸の先端は長い棒だけでなく若葉で終端。
3. 株の大きさ: 現在の0.6m程度はホウライシダとして大きめの演出。自然サイズは0.15〜0.4m程度が中心のため、V03は0.24〜0.42mを基準にし、演出用大型株は別スケール設定。
4. 小葉は三角形メッシュではなく、楔形の基部＋丸い扇形外縁＋不規則な2〜5切れ込み、放射状の淡い葉脈を作り、表裏の見え方を確認。
5. 若葉は淡黄緑で小さめ、成熟葉は緑、葉縁枯れは一部のみ。第2層の照明で青く染め過ぎない。片面から消えないよう両面材質をGLB/Three.jsで検証。
6. 各枝の傾き・ねじれ・向き・空間占有を測り、V02の「水平に開いた皿形」を解消。幹と葉の密度を3方向から判断。
7. 接地・ランダム組み合わせ: 短い匍匐根茎を地面原点とし、岩の割れ目に置く位置制限。既存配置APIは維持、ゲーム側の変更は未承認ではしない。
