# 第2層 水車架台：木製込み栓（drawbore peg）V01
2026-11-20 / DESIGN FIRST / NOT_APPROVED

先行する木製支柱V03 (PR #646)、斜め筋交いV02 (PR #674) は独立部品であり、いずれも形状を変更しない。
一本のみ製作し、連結穴の掘削、組立接合とゲーム統合は未実施。

## 寸法と構造（m）
- 全長0.205、最大幅0.032、先端最小幅0.018。長手Y軸。木目は長手方向に沿わせる。
- 断面は円柱ではなく、手削りの8〜10角の不均一な木栓。中央断面28〜31mm、頭0.032m。
- 頭側は長さ約0.021mの小さな段差と、軽い手彫りの面取り。先端へ2段階で緩いテーパー。
- 5箇所程度の局所削り面を設け、塗装で黒い割れ線を引くのではなく、非対称な小欠けを浅く造形。
- 材質は古いオーク。512pxのオリジナル木繊維アルベド／roughness／木口テクスチャ。画像テクスチャをglTFに埋込。
- 仕上がり見本は古びた材質であり、錆や金属部品はない。水気を受けた薄い黒染みのみ。

## 実評価
- Blender 5.3 Cycles、正面・側面・斜め・先端方向の実PNG4枚。
- GLB、Blend、SHA256 manifest、ClamAV前後、GLB構造・性能監査を通す。
- 既存筋交い・支柱への仮差し込みや穴位置・強度は寸法未確認につき未実施。
- 重要：これは小さい支持部材なのでゲーム内ではLODや他の架台部品への統合を検討。正式素材に保存しない。
