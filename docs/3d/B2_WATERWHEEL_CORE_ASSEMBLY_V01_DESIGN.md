## 座標設計
- 全部ローカルZ上向き・車軸X方向、原点は車輪中心。木軸長X≒±1.732m、径は外側約R=.29m、中央約R=.30m。
- ハブの原点は(0,0,0)、幅X±.18m、穴R=.303m。
- 鉄カラーは **X≈+.183〜+.227m**。既存メッシュ位置を保持。現時点の実モデルは一つだけなので左右2個と誤称しない。
- 木製軸受けの元GLBは上下とも**原点周辺に配置**され、位置を変えずに重ねると木製ハブやカラーと衝突する。正しい候補は、下台と蓋を同時に **X+1.02m** 移動。X方向支持範囲おおむね+.42〜+1.62m（車軸端+1.73mの内側に収まる）。
- 見た目の左右対称配置の評価用に**下台と蓋を複製して X-1.02m** に置くことも可。ただし複製は仮組みシーン限定で正式素材を増やすものではない。
- 下台U座R=.318m、上蓋U座R=.322m。軸R≈.290〜.298m。公称円筒クリアランスは下+0.020〜0.028m、上+0.024〜0.032m。ただし実メッシュは非円・揺らぎを含むためこれは理論値であり、**実BVH交差を評価して初めて非干渉の証拠とする**。
- 元上下の木材接合面Z=.055mは一致するように設計済み。接合の意図された接触はゼロ距離で、衝突と区別する。

## QA
1. 5つの元ArtifactをGitHubから毎回ダウンロードし、各manifestの全GLB・PNG・BlendのSHA/bytes一致を確認。**感染の心配がある入力はBlender import前にClamAVで実スキャン**。
2. Blender5.3 Cyclesで全モデルを **編集せず** インポート。部品位置だけ組立用に動かし、各元オブジェクトのメッシュvertices/face countを保持。
3. BVH三角形交差はハブ-軸、鉄カラー-軸、左右上下軸受け-軸、軸受け-ハブ、軸受け-鉄カラーを確認。BVH overlap=0でも完全に内包する形状への非干渉は保証できないので、一部の重要径・各X位置範囲・軸の断面サンプリングを併記。
4. 正面／側面／斜め／真上の4方向Cycles PNGと全候補の組立プレビューGLB、編集用Blend、干渉report JSON、manifest。実画像を見て美観判定。元GLBには変更を加えない。
5. 出力をClamAVで再スキャンし、共通GLB監査 `tools/3d-performance/audit_glb.py` を実行。ゲーム内FPS、物理回転、正式衝突判定・正式assets保存・PR mergeは行わない。
