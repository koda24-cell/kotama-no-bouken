# 第6層・風に靡く草原床 V1 制作仕様（試作・未承認）

## 目的
既存の草株V5とは独立した、マップ1マス単位で敷き詰められる草原床。『ゼルダの伝説 ブレス オブ ザ ワイルド』の自然な草原を品質目標とする（形状やアセットの直接複製はしない）。

## 造形
- 1タイルをローカル座標 [-0.5,+0.5]×[-0.5,+0.5] とする。隣接タイルの地面頂点は同じ境界位置と高さを使用する。
- 地表は滑らかな起伏、土の濃淡、草の疎密を組み合わせ、単なる緑の板にしない。
- 地表から生える細い草葉を密生させ、短い葉・中くらいの葉・長い葉を混在。株状の偏りを避ける。
- 草葉の分布はタイルのワールド座標を使った決定的乱数で生成し、隣接マスの継ぎ目を避ける。
- タイル端では草を急に切らず、隣接する草葉の重なりを考慮。地表の高さと法線を隣接マスで揃える。
- 草株V5・白百合V13は別オブジェクトとして追加可能にする。

## 風アニメーション
- Three.js の ShaderMaterial / onBeforeCompile 等で草葉頂点をGPU変形。GLBそのものに「風の再生機能」が入るわけではない。
- 草葉の根元は固定し、先端ほど大きく曲がる: weight = pow(clamp(heightRatio,0,1), 1.8)。
- ワールド座標の連続ノイズ（低周波の風の帯）と周期波、高周波の微細な揺れを組み合わせる。
- 隣接タイルの同じワールド座標では同じ風位相になるようにし、タイルごとの同期ズレを防ぐ。
- 風向き・強さ・速度はパラメータ化。通常は穏やか、時折強めの風が横切る。
- 根元の浮き、葉の地面への貫通、草全体の一斉同位相運動を避ける。

## 制作順序
1. Blenderで1マス床・草葉ジオメトリを生成し、斜め/正面/側面/真上から静止レンダリング。
2. ブラウザ上で実際の風のアニメーションを検証。静止PNGは動作証拠ではない。
3. 3×3タイルを連結し、継ぎ目・風の位相・地面のつながりを確認。
4. ユーザーの画像・動画レビュー後にGLB/PNGを正式素材へ昇格。ゲーム本体へは未承認で統合しない。
