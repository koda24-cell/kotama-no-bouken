## 選定の優先順位
1. 既存 v04 のシルエットと寸法を保持する。
2. つなぎ目の左右端は幾何形状と高さを揃える。ランダム配置の装飾は境界から離す。
3. 岩は大きな塊のシルエットを優先し、細かな凹凸やテクスチャを過剰に増やさない。
4. 氷柱・霜・岩は独立した追加モジュールとし、橋の本体を置換しない。
5. 出典URL、個別アセット名、ライセンス、取得日、ファイルSHA256、改変内容、利用先を台帳に記録する。
