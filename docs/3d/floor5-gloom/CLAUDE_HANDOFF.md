## Visual intent and constraints
Original dark abyssal organic infection, not a copy of Nintendo textures or assets. Approved design includes a jagged viscous black pool, irregular thin shoreline films, scattered islets, tapered tendrils, flattened asymmetrical creeping infection ribbons (not rubber tubes), red-purple capillaries, subtle surface pores and dark crust plaques. Smoke uses CC0 Kenney sprite in the Blender review. Keep organic nonuniform silhouettes and avoid geometric/round piping. Do not replace the approved original with an unreviewed redesign.

## How Claude should use it
1. Open PNGs to understand front/side/high-angle shape without Blender.
2. Load the GLB into a Three.js viewer, or use the original `createB5GloomPatch` module for procedural placement/animation. GLB is a static geometry export and **does not automatically include the original update() behavior**.
3. If applying smoke to browser runtime, verify textures and transparent sorting separately. The smoke cards are generated by the Blender review script; don't assume the procedural JS module contains them.
4. Verify SHA256 after copying assets. Never confuse Actions artifact (temporary) with the permanent GitHub assets.
5. Preserve existing game behavior. Integration into map is **not yet done**. Create a separate branch/PR for placement variants, with screenshots and tests.
6. Before future edits read `AGENTS.md`, `docs/3d/BLENDER_DOCKER_HANDOFF.md`, `docs/3d/ASSET_PROMOTION_POLICY.md`, and `docs/3d/FLOOR5_COMPLETED_ASSETS.md`.
