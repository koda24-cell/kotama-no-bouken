# 第6層 草原 V9 追加造形の独立レビュー (2026-11-19)

## 目的
承認済みV7草原は風向32°に細い草が揃い、全体の輪郭が均一なため、BotW風の葉束と自然な方向差を追加造形で試す。V8シェーダーPR #532とは別の、**Blender実造形候補**。

## 保全と実装
- V7原本GLBを run 43602069517 から取得し、Blenderへ読み込む。
- 元の9メッシュの頂点数・面数を保持したまま、**曲面断面・葉先テーパー・葉のねじれ・方向のばらつきを持つ660枚の新しい葉**を3つの追加メッシュとして生成する。
- V7の元草・下草・地面は削除・変形しない。元の形が強く残る可能性があるため、見た目はレンダリングで判定する。
- 3点断面×7段、湾曲した中肋、32°付近と横向きの混合、根元暗緑→葉先黄緑。追加葉は白色Emissiveを使用しない。
- `tools/floor6/meadow_v9_additive.py` がGLB、Blend、4方向PNG、SHA256 manifestを生成。
- `.github/workflows/f6-meadow-v9-blender-review.yml` がBlender実行とファイル形式・原メッシュ保全を検証する。
- これは形状の**追加試験**であり、V8の風アダプターにはまだ接続しない。新規の660枚が静止してしまうため、風と同時導入する前に専用属性を整備する。

## 判定
1. 正面・側面・斜め・真上のPNGで葉束に自然な方向差ができたか。
2. 追加葉が太すぎないか、根元に浮きがないか、境界に不自然な線がないか。
3. 元のV7に比べた三角形数/容量/マテリアル数を監査し、最終段階で軽量化。
4. Blender成功≠美術合格。承認までは `NOT_APPROVED`、ゲームに配置しない。
