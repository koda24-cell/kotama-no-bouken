# キャラクター3D形状比較研究（2026-11-16）

目的: コタマの暗殺者頭部V15の欠陥（後頭部の段差・穴・顔との非接合）を、合法的に入手した複数モデルのメッシュ構造を比較して改善する。

## 保存と権利
- 公開GitHubには **ソースURL・許諾記録・自作解析コード・権利上公開可能な集計結果** のみを保存する。
- 商用不可・改変不可・再配布不可・解析禁止・AI学習禁止などの制約をモデルごとに確認。解析禁止のものは読み込まない。AI学習禁止モデルをAIへの入力に使わない。
- 商用不可は直ちに私的な構造分析禁止を意味しないが、規約の目的・禁止行為を個別に確認する。
- 配布物本体は規約が明示的に許可する場合のみGitへ保存。それ以外は利用者の非公開領域に置き、GitHub Actionsへ投入する場合も再配布・共有・ログ漏えいに注意。
- 元モデルの形状そのものやテクスチャをコタマに流用しない。独立した新規造形に活かすのは一般的なトポロジー・比率・制作技法。
- 原神・ブルアカ・VOCALOID・VTuberの第三者モデルは各配布者の利用条件を確認するまで候補扱い。公式作品のモデルだから自由に取り込めるわけではない。

## 比較項目
- 頭部: 左右幅/前後深さ/高さ、耳と目の位置、頭頂・後頭部曲率
- メッシュ: 頂点・面・三角面、境界エッジ数、連結成分、非多様体、法線、UV
- 形状: 高さごとのX/Y断面、輪郭、顔から後頭部への境界ループ
- 構成: オブジェクト名、材質、ボーン、シェイプキー、髪と頭部の分離
- 実用性: GLB/VRM/FBX/PMXの読込互換、レンダリング再現性、権利上の利用範囲

## V16への適用
V15の失敗は、顔・耳など複数の境界を高さごとに平均していたこと。まず境界エッジを連結成分別に分離し、後頭部に接続すべき単一ループを特定する。対応点を決め、後頭部をブリッジし、法線・接合・背面マスクを検査する。V16は未実装・未検証。
