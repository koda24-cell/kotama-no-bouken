# キャラクター3D品質解析・再現設計仕様（2026-11-17）

## 目的と対象
参考3Dモデルから**品質改善に直結する数値・構造・レンダー比較**を抽出し、コタマ暗殺者V16を独立造形するための設計書を作る。元モデルの頂点配列・テクスチャ・シェーダーをそのまま複製しない。利用規約の確認が取れたモデルのみ入力する。

実装: `tools/character-mesh-research/extract_character_quality.py`
実行: `blender -b --python tools/character-mesh-research/extract_character_quality.py -- input.vrm output.quality.json`
Actions: `.github/workflows/character-mesh-research.yml`
PR: https://github.com/koda24-cell/kotama-no-bouken/pull/412
出力: `<model>.quality.json`。レビュー前のJSONは採用設計値ではない。入力元の座標・単位・前方軸の校正が必要。

## 1. 頭部トポロジー／顔・後頭部接続
- 実装: 面辺出現回数=1を境界辺として抽出、境界グラフの連結成分、各成分の頂点/辺数、全頂点次数=2の閉ループ判定、分岐有無、ワールド座標の外接範囲。3面以上共有する辺の件数。
- 品質に直結: V15のように耳や顔の複数境界を混合しない。**後頭部へ接続する単一ループ**を、位置・長さ・閉路性・隣接面で判定。対向ループの対応点・法線方向・重複面・接合後の穴をチェックする。
- 未実装: 面法線の連続性、曲率、対応ループの頂点並び順・再サンプリング、非多様体の全分類、左右対称度、顔ランドマーク自動推定。境界ループのJSONは集計のみで元座標列は出さない。
- V16合格条件案: 意図しない開口0、自己交差0、顔・後頭部の目立つ段差なし、正面/横/斜め/背面/背面上から目視合格。

## 2. 部位別寸法／比率
- 実装: オブジェクト単位の外接範囲・3軸寸法、11高さの±4%帯に含まれる頂点のX幅/Y深さ。
- 品質に直結: 頭部幅/高さ、後頭部膨らみ、顎の細まり、耳位置、眼球の前後位置、首付け根の断面を比較。
- 未実装: 目・鼻・口・顎・耳・首の意味的ランドマーク、同一単位への正規化、正面軸自動判定。名称推定だけで正しい部位と断定しない。
- 次段階: 人手で前方軸・頭頂/顎/耳/目位置を校正して比率表を生成する。

## 3. 髪の毛束・断面・影
- 実装: 名前に hair/bang/fringe/ponytail を含むメッシュの外形、11断面、境界、頂点数・三角面数。
- 品質に直結: 毛束の大小差、重なり、毛先の先細り、頭皮との距離、後頭部のシルエット。
- 未実装: 毛束単位の自動分割・中心線・断面積・先端方向・頭皮距離・髪カード透明ソート・影の評価。髪全体の幅を毛束断面と誤認しない。
- 次段階: 接続成分/UV島/材質ごとに分割し、各毛束の主軸に直交する断面を計測。

## 4. マテリアル・テクスチャ・照明
- 実装: Blenderノード種別、画像ノードの名称・色空間・ソース、Principled BSDF の Base Color/Metallic/Roughness/Alpha/IOR/Emission/Normal のリンク有無と既定値。
- 品質に直結: 肌の反射、髪の光沢帯、布の粗さ、金属のハイライト、アルファ表現、法線・トゥーン陰影。
- 注意: ノード入力がリンク済みなら既定値は**実際の最終見た目ではない**。VRMのMToon、拡張ノード、テクスチャの実画素・UV展開、Three.js変換後の見た目は別途解析/レンダー検証。
- 未実装: ノード接続グラフの完全復元、テクスチャ解像度/チャネル統計、MToon固有設定の正規化、実ライティング下のBRDF評価。

## 5. ボーン・表情・変形
- 実装: アーマチュアのボーン名/本数/親子リンク数、メッシュのArmature Modifier、頂点ごとの影響グループ数の分布、ウェイト最小最大、シェイプキー名/頂点数。
- 品質に直結: 顎・頬・目・首・肩の変形、ウェイト正規化、表情時の顔面崩れ、閉眼時のまぶたと眼球の干渉。
- 未実装: 頂点ウェイト和の異常検出、実ポーズ/表情を適用した変形テスト、ボーンのレスト姿勢・座標、シェイプキー変位量・干渉評価。
- 次段階: 表情（閉眼/笑顔/口開き）と首回転の検証レンダーを追加。

## 再現可能な制作への引継ぎフォーマット
モデルごとに以下を記録する。
1. source_url、原作者、ライセンスURL、許諾確認日、SHA256、入力形式、Blender版、単位/座標系、解析commit/run。
2. 各部位の寸法比、閉境界ループの数とサイズ、法線/穴/対称性、髪の毛束統計、材質ノード構造、リグ/表情の指標。
3. 正面・側面・斜め・背面・上方のPNG、光源/カメラ/露出設定、品質問題を画像の位置付きで記録。
4. V16の**独立した造形指示**（頭頂・後頭部の断面プロファイル、耳・顎位置、接続方式、髪の重なり、シェーダー、ボーンの要件）。
5. Before/After比較、QAの数値、目視評価、未解決点、ユーザー承認状態。

## 判定基準
- 技術検査合格と美術的な完成承認は別。JSON出力だけで「再現できた」とは扱わない。
- 頭部メッシュの自動選別は**オブジェクト名のヒューリスティック**。別名/統合メッシュでは誤判定する。
- 参照モデルの再配布や直接的な形状複製は行わない。一般的な造形原理・比率・品質指標を抽出し、新規造形で検証する。
- 初版の実行結果・JSON値・PNG目視評価は**未確認**。実行後にこの文書へ証拠URLと失敗/改善点を追記する。
