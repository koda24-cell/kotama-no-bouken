# Blueprint-first production gate V3
Before production modeling, complete reference provenance, scale and dimensions, front/back/left/right/top/oblique appearance, silhouette and section curves, part placement, ornament and variation, material/texture/color plan, neutral/game lighting plan and review. Design-only preview meshes allowed. Hidden gaps, overlaps and intersections never block. Intentional visible gaps allowed. Freeze a revision with image and numeric evidence and SHA256; preserve earlier revisions. Store reviewed designs permanently outside game assets; Actions artifacts are temporary. Review must assess appearance, not just file existence. Technical preflight is not artistic or asset approval.
The standalone preflight tool checks evidence completeness and integrity only. Blender production integration, actual preview generation and permanent archive are pending. Do not claim global enforcement yet.
