# 第6層 花園：自然物4系統の3D素材制作仕様

状態: **制作予定（未レンダリング・未承認）**。完成リストへは承認後に記録する。
参照: 草原床V7、`docs/3d/F6_MEADOW_V7_CLAUDE_HANDOFF.md`、`AGENTS.md`。

## 共通
- 1マス単位のGLBとして個別保存。草原床V7と共存し、既存モデルを置換しない
- 見た目は自然な非対称性を重視。単純な球体・円柱・同じ形の複製は避ける
- 接地面、原点、スケール、隣接タイルからのはみ出しを確認
- Blenderで正面・側面・斜め上・必要に応じ真上のPNGを実レンダリング
- GPT/Blender環境が制作。ClaudeはBlender操作不可、GLB・PNG・manifestを利用してゲーム統合
- 完成候補はユーザーが画像を確認して承認後に正式素材へ昇格。Actions Artifactは一時保存

## 1. 岩（最初の制作対象）
- `rock_small`: 小岩、地面から浅く突出、角張った面と欠け
- `rock_medium`: 中岩、非対称な輪郭、深い亀裂、少量の苔
- `rock_large`: 大岩、複数の岩塊が自然に接合、側面と背面も造形
- 岩肌は大きな破断面＋中程度の欠け＋細かい表面粗さの3段階。浮いた装飾は禁止
- 草原床の上に置いても下部が浮かないようにする

## 2. 砂利
- `gravel_sparse`: 草地の隙間に小石が散る
- `gravel_dense`: 岩の根元に集まる大小混在の砂利
- `gravel_path`: 踏み固められた細い道状の砂利
- 石の色・角度・埋まり具合を変える。完全な均等配置やタイル境界の不自然な切断を避ける

## 3. 茂み
- `shrub_low`: 背の低い茂み、枝と葉の層が見える
- `shrub_dense`: 非対称な大きい茂み、内部に陰影
- `shrub_flower`: 小花のついた茂み、花の密度は控えめ
- 板状の葉だけでなく、厚みと枝の接続を意識

## 4. 木
- `tree_young`: 若木、細い幹、疎らな葉
- `tree_mature`: 成木、幹の曲がり、根張り、葉群の大小差
- `tree_ancient`: 古木、太い根、幹の割れ、苔、非対称の樹冠
- 地面から根が生える構造。樹冠は球状の塊一個で済ませない

## 保存・受け渡し
- 仮出力: `render-output/floor6/nature/<asset_id>/`
- 承認後: `assets/models/floor6/nature/<asset_id>.glb`
- レビュー画像: `assets/models/floor6/nature/reviews/<asset_id>/`
- manifest: ID、バージョン、タイル寸法、接続方向、ファイルSHA256、制作元コミット、レンダリングrun ID、承認状態
- ClaudeはGLTFLoaderでGLBを利用し、PNGで見た目を確認する。Blender操作は依頼しない

## 進行
1. 岩の3種類を造形し実レンダリング
2. ユーザー評価を反映
3. 砂利、茂み、木を同じ手順で制作
4. 各承認後にGLB・PNG・manifestを正式保存し完成リストへ追記
