# 第4層・溶岩河川と滝 V14 — 水っぽさ／横から浮く問題の改善

## ユーザー指摘
- V13は「流れるマグマがかなり水っぽい」「横から見たときも直線で浮きすぎ」。
- V13の元岩、河川形状、池、岸、既存PBR、V12玄武岩破断面を保持し、重く粘る溶岩を追加造形で改善する。

## V13の原因（実コード）
- 河川は厚みのない平面メッシュで、粗さはPBR roughness mapに支配されており、水面のような連続光沢が残った。
- 溶岩滝は厚みのない片面のシート。上部 z=-3.20 に対し背面の崖は概ね z=-3.83、約0.6単位手前に離れており、側面から浮いて見える。
- 7本の連続発光線は細い光の棒・水筋のように見えた。

## V14造形
1. 元の熱マップを維持し、溶岩の粗さを0.86に固定。滝専用の低発光・高粗さマテリアルを新設。
2. 滝を前後面＋側面のある閉じた厚いメッシュへ。上部z=-3.69で崖へ近づけ、下部で溶岩溜まり方向へ曲がる（一直線の浮遊シートを解消）。
3. 25枚の埋め込み冷却殻、短く途切れる発光亀裂8本、着地部の粘性溶岩塊12個を追加。
4. 河岸に接する暗い冷却縁2本と、川の上に不規則な冷却舌19個を追加し、平坦な水面の印象を弱める。
5. 元の崖・河川・岩・既存VFXは削除しない。静止GLBで流動アニメーション・熱ゆらぎは未実装。
