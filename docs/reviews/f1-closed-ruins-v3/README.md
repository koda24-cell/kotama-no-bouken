# 苔むす封祠・閉鎖神域V3 制作と検証

ユーザーの画像付き6批評に対応する改修。開放的な庭ではなく、苔・根に侵食された屋根のある祭祀遺構を目標にした。制作前調査はPinterest新32候補を担当が実画像確認し、制作責任者は20枚contactを確認。公開参考と採用方向は `docs/3d/F1_CLOSED_RUINS_V3_DIRECTION.md`、座標/断面/順序はDESIGN、個別部品監査はASSET_AUDIT、水はWATERに記録。参考画像のゲーム転用・再配布なし。

新5素材は一度に全景生成せず、苔→下草→根巻き崩落石→天井の崩落孔→侵食岸の順に1モデルずつ制作。各モデルをGLBで出力後、source sceneを捨てて実GLB再import、Cycles24samples/640pxで正面/側面/斜め/上の4方向撮影。全20枚は `individual-assets-contact.png`。苔は実ゲームの初回確認で敷物感を見つけ、半透明混合ではなくMASKの欠け・縁を作って再撮影した。元17GLBは全SHA一致で保存。

## 改修の対応

| 指摘 | 実装した内容 |
| --- | --- |
| 全面空/閉塞感不足 | 外周も含む504天井、外周壁。開口は3か所の実穴だけ。ボス前の小区画だけ天井を少し高く |
| 土色/整備された庭 | 暗緑の苔が床境界を横断し、湿った石/土/樹皮の既存CC0材と統一 |
| 広い空白/一直線の眺め | far96→40m、緑の霧、非歩行島の支持柱・根巻き瓦礫、アーチ2区間、頭上根 |
| 単色の水/直線岸 | 青緑の時間変化normal、11水底・55沈み石・11藻溜まり、16不定形侵食岸。reflection target追加0 |
| 孤立した木/草/石碑 | 下草616、低木22、苔679、壁際/柱際の瓦礫と根、蔓45で周囲とのつながり。高木は崩落開口に限定 |
| 床格子/素材不足/鳥居祠が無関係 | 不定形MASK苔で境界を途切れさせる。既存アーチを実配置。鳥居と祠を6mの同軸へ移し、向きを合わせる |

map、ナビゲーション、固定7対象、FOE、NPC/宝箱/階段/戦闘/セーブ形式は保持。通れる場所を見た目だけで岩塞ぎしない。旧トンネルは根が経路へ干渉するためそのまま入れず、通行を検査したアーチでくぐる構成を作る。

## 実検証の範囲

- 新5GLBのKhronos errors0/warnings0。合計6694tris、GLB再import20枚。5編集Blendの全FILE画像pack/再open/decode成功。
- GLB実三角形＋全祖先/配置変換で104経路、幅1.8m/Y.12..2.1mを検査。25sourceのSHA一致、硬い932配置で交差0。苔・草・花・蔓・札など1377配置は明示的に別扱い。
- 追加の天井実geometry ray:274歩行床×3×3=2466上向きrayの全てに天井hit。指定3開口の中心はhitなし。壁/木/alpha/cullingを含まない幾何検査であり、画像での閉塞感も別に確認。
- 水の独立WebGL再検証はエラー・警告0、時間差画像を実比較。dispose時に元の11水材/geometryとGPU baselineへ復帰。旧色の結果は `../f1-closed-water-v3/history-before-teal-water/` に保持。
- 最終実ゲーム検証は `../f1-closed-ruins-v3-game/`。3 sessions / 18 checks / 実画像16枚でPASS。初回9画像は全入力/PNG SHA一致で再利用し、機能はfresh contextから再実行。実機FPS・最終美術承認には拡張しない。

`iterations` の暗い入口は初期配置/照明、緑の水場は色分離前で、最終画像ではない。途中の水面撮影と並行して配置/苔を編集したため入力不変guardが失敗したreceiptも保存する（`water-preview-inputs-changed.json`）。その撮影を機能suite合格とは扱わず、最終素材を固定してsuiteを最初から実行する。

実機FPS、全GPU、長期進行、最終美術承認は未完了。数値上の天井被覆や三角形数だけを芸術的な完成の根拠にしない。新開口の破断輪郭や植生の細部は今後の評価対象。公開mainの変更を含まない。
