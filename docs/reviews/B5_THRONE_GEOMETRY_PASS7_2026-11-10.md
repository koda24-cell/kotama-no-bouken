# 第5階層・魔王の間：追加造形パス7

PR #201 の既存モデルに破損した控え柱・尖塔・破断片・裂けた布を追加。新規モデル種やストーリー設定は追加していない。

- gothicArch：両側の控え柱と上部尖塔5本
- ruinedPillar：控え柱2組と石片
- fracturedAltar：左右の控え柱と背面尖塔9本
- brokenStair：左右の支柱と大型石材
- shatteredRoseWindow：両側の破損した柱状構造物
- hangingBanner：裂けて分離した布の先端
- candleSanctuary：高さの異なる破損柱3本

共通ヘルパー `buttressCluster` を追加し、石柱・梁・尖塔・瓦礫の複合シルエットを再利用。既存の `dispose` 管理対象に含める。

第5階層の固定方針 `docs/B5_ART_DIRECTION.md`（PR #195）を参照。魔王の間専用であり、通常迷宮と混同しない。通行判定・FOE・イベント・セーブ・他階層には変更なし。

**未実施**：本体統合、ブラウザ表示、実機FPS・ドローコール測定。高密度化による負荷増大の可能性があるため、次段階では実際の画面視点から配置と負荷を確認する必要がある。
