# 第5階層 魔王の間：追加造形パス6

PR #201 の既存3Dモデルを追加造形。今回は巨大建築物の立体的な骨格と破損を重視した。

- gothicArch：前後に張り出す立体的な天井リブと破片
- fracturedAltar：背面の5本の不規則な柱とアーチ
- shatteredRoseWindow：非対称な窓枠骨格、落下破片
- grandChandelier：多段構造の吊り骨格10組
- ruinedPillar：崩落した天井アーチの残骸
- brokenStair：中央に欠損のある欄干と破片

共通の `vaultRib` ヘルパーで複数の点を結ぶ梁を生成する。追加ジオメトリは既存の `dispose` 管理対象。

制作指針は `docs/B5_ART_DIRECTION.md`（PR #195）を参照。通常迷宮とは分離し、魔王の間専用。ゲーム進行、通行判定、FOE、イベント、セーブ、他階層には変更なし。

**未実施**：ブラウザ表示、ゲーム本体への組込み、実機テスト、FPS測定。装飾密度が増加したため、統合前にドローコールと画面視認性の確認が必要。
