## 2. 第2階層を3Dで見る方法

通常の進行では第2階層は**従来どおり2D表示**です（試験表示を有効にした端末だけ3Dになる）。

- URL に `?f3d=b2` を付けて開く（その場だけ。保存しない）
- または管理パネル → 戦闘タブ →「3D表示の試験（第2階層・凍てつく水源）」にチェック → 「第2階層 1F／2F／3F を3Dで確認」
  - 設定は localStorage `kotama.field3d.preview` に入るだけで、セーブデータには入らない
- 第2階層にいる間は HUD の「2D表示／3D表示」で切り替えられる（第1階層と違い、固定しない）
- 水の半透明が崩れる環境では localStorage `kotama.field3d.b2.water` を `opaque` にすると不透明の水になる

## 3. 使った GLB のメッシュ

222 メッシュ**すべて**を部品に分けて使っている（`omitted` は 0）。GLB は Z が上・頂点がシーンの位置に焼き込まれていたので、Y が上に回し、部品ごとに原点を底面の中心へ移した。

| GLB のメッシュ | 部品 | 置き方 |
|---|---|---|
| `Floor_Slab_*`（24） | 床板 | 通れるマスに 2×2 枚。すき間から暗い水底がのぞく |
| `Floor_Inlay_*`（8） | 象嵌の筋 | 道（`,` `_` `P`）に一筋 |
| `Cavern_Wall_Boulder_*`（18） | 壁の根元の岩 | 壁の面ごとに約半分。通路へのはみ出しは 0.5m 以内 |
| `Foreground_Rock_*`（8） | 小岩 | 開けた場所のふち、滝つぼの脇 |
| `Crystal_Base_i`＋`Crystal_Outcrop_i_*`（5群） | 結晶の群れ | 二方が壁の角だけ（正面をふさがない）。シアンの点光源つき。2F の合図石にも使用 |
| `Crystal_Outcrop_*`（単体） | 天井の結晶 | まれに壁ぎわの天井から下げる |
| `Thorn_Stem/Leaf/Hazard_Spine_i_*`（4株） | 荊（紫のとげ） | 浅瀬（`*`）の壁ぎわ＝危険の目印 |
| `Mineral_Vein_i_*` | 光る鉱脈 | 壁の面にまれに |
| `Ancient_Arch_*`・`Arch_Keystone_*`・`Arch_Central_Prism` | 古いアーチ | 出口 `E`。マスの奥の壁ぎわに立て、天井4mに収まるよう高さを詰めた |
| `Water_Gate_Pillar/Rune/Bar_*` | 水門 | 2F の「見張りの門」`h`（合図石を2つ鳴らすと**格子だけが上がる**）、3F のボス門 `B`（紫の光） |
| `Broken_Bridge_Stone_*`・`Bridge_Support_*` | 壊れた橋 | 浅瀬が3マス続く最初の場所に1つ（足場の見た目。通行は変えない） |
| `Waterfall_Sheet_*`・`Waterfall_Foam_*` | 滝 | 行き止まりの奥の壁（各フロア最大4か所）。滝つぼ・波紋・しぶき・点光源つき |
| `Water_Ripple_Ring_*` | 波紋 | 浅瀬と滝つぼ（フロアあたり最大24個）。広がって消える動き |
| `Water_Plane_Transparent` | （素材だけ） | 水面はマスの形に合わせて作るため、形は使わず「Clear blue water」の素材を使用 |

GLB に無い物は手続き型で作った：迷宮の壁（凸凹のある 4.3×4.1×0.8m の板）、天井、水底、浅瀬の水面、壁の石板。素材はすべて GLB の素材名に合わせた（`Deep cavern rock` など）。
宝箱・階段・採集点・NPC・導きの灯・床の看板は第1階層の素材を**コピーせず共有**。壊れた木箱（`ev-crate`）は専用素材が無いため、第1階層のトロッコで仮表示。

## 4. 当たり判定とカメラ

- **当たり判定は従来のまま**：通れるかどうかはマップの文字（`#` が壁）で決まる。3D 側は見た目だけで、GLB を当たり判定に使っていない。浅瀬 `*` も従来どおり歩ける（歩数は既存の 1.5 倍のまま）。
- 「見た目と当たり判定の分離」はこの構造で満たしている。岩・結晶・荊は壁ぎわと角だけに置き、壁の面より 0.5m 以上通路へ出ないので、見た目と通れる範囲が食い違わない。
- カメラ・移動・1マス4m・目の高さ 1.6m は第1階層と共通のまま（変更なし）。天井 4m を超える部品（アーチ 5.5m、滝 4.8m、水門 3.3m）は高さを詰めて収めた。

## 5. 水・滝の動き

既存の毎フレームの入口（`frame()`）から `theme.tick()` を呼ぶ形で実装した。新しいライブラリは入れていない。

- 水面：明るいゆらぎのテクスチャ（canvas で作成、外部ファイルなし）をゆっくり流す。半透明（不透明度 0.62）、退避用に不透明モードあり
- 滝：縦の筋のテクスチャを下へ流す（GLB の滝に UV が無かったので、読み込み時に付けた）
- 波紋：GLB の輪を広げながら薄くする
- しぶき：滝つぼに小さな粒（Points）。カメラから 20m 以上離れた波紋・しぶきは止める
- 反射（映り込み）は未実装（仕様 §3 のとおり高画質だけで足す想定。今回は入れていない）

## 7. 未対応・既知の制限

- GPU のある実機（PC・iPhone）では未確認。確認はソフトウェア描画のみ
- 反射する水面、水の音は未実装
- `ev-crate`（壊れた木箱）、NPC（行商人・見張り番）は専用素材が無く仮表示
- GLB は「blockout（仮組み）」なので、テクスチャが無く岩や結晶は面の明るさの変化だけで表現している。仕上げの素材が来たら部品の差し替えで対応できる
- 第1階層から第2階層へ移っても第1階層の素材はメモリに残す（宝箱などを共有しているため）。第2階層の組み立て直しでは前のジオメトリを破棄している
