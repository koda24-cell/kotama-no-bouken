# B5 魔王の間：既存モデル追加造形パス3（2026-11-10）

対象: PR #201 の `field/assets/b5-throne-props.js`。新しいモデル種類は増やさず、前回の造形に重ねてシルエットを強化。

## 実装
- **ruinedPillar**: 高さが周方向で異なる9角柱の破断メッシュ、倒れた柱の断片を追加。
- **gothicArch**: 完全な円ではなく途切れた円弧を組み合わせ、欠損したアーチ輪郭を表現。
- **shatteredRoseWindow**: 内外の複数の不連続な円環で、大きく失われた窓枠を表現。
- **grandChandelier**: 長さと傾きが異なる12本の金属腕を追加。
- **brokenStair**: 折れた欄干柱と倒れた長い梁を追加。
- **fracturedAltar**: 不規則な破断柱状の大きな欠損部品を追加。

## 方針と制約
- 固定制作方針 `docs/B5_ART_DIRECTION.md`（PR #195）に従い、形状優先。
- ゲーム本体への自動配置なし。FOE・通行判定・イベント・セーブ・他階層は無変更。
- 既存APIとdisposeを維持。ジオメトリは各生成インスタンスで管理。
- 破断面の造形は近似メッシュ。既存本体をブーリアンで切り抜く処理はしていない。
- ブラウザ実表示、視点確認、パフォーマンス計測、実機テストは未実施。Claudeによる統合・質感調整が必要。
