## 1. A-01 再検証（一部未解決）

### 修正内容
確定後 450ms の間、画面全体を透明な層で覆い、クリックとキー入力を捨てる（`installSkillUpgradeCommitShield`）。

### 結果
確定ボタンの位置を一定間隔で10回タップしました。

| 画面 | 間隔 | 修正前（PR #26） | 修正後（PR #27） |
|---|---|---|---|
| タブレット 1024×768（剣マスタリーを確定） | 100ms | 確認していないショックボルトを **4回** 強化 | ショックボルトを **1回** 強化 |
| 同上 | 200ms | 4回 | 2回 |
| 同上 | 300ms | 4回 | 3回 |
| 同上 | 500ms | 4回 | **4回（改善なし）** |
| 同上 | 800ms | 4回 | **4回（改善なし）** |
| PC・スマホ・小型・横向き | 60〜600ms | （未測定） | 誤操作なし |

マウス・タッチとも同じ結果です。回数は、最初に確認した剣マスタリーの1回を除いた誤強化の数です。
シールドは450msしか効かないため、それより間隔の長い連打（500ms以上）では修正前と変わりません。

### 原因
1. 450ms が過ぎた後のクリックが、確定ボタンの真下にある別スキルの強化ボタンに当たり、新しいダイアログが開く。
2. 新しいダイアログの「強化する」は前と同じ位置に出るため、次のクリックで確定してしまう。
3. 新しく開いたダイアログには、開いた直後のクリックを無視する仕組みがない。

全スキル・3つのスクロール位置で総当たりしたところ、確定ボタンの下に有効な強化ボタンが来る配置は、タブレット幅で10件ありました（こたま・騎士・治癒士・魔術師の基礎パッシブなど）。他の4つの画面サイズでは0件です。ただし、配置しだいでどの画面サイズでも起こり得ます。

### 修正案（参考・どちらか、または併用）
- **開いた直後の確定を無視する：** ダイアログを開いてから約500msは「強化する」を無効にする。または、押し始め（pointerdown）がダイアログを開いた後でなければ確定しない。
- **確定後しばらくは新しいダイアログを開かない：** 確定後、新規ダイアログを開けない時間を設ける（例：1秒）。

## 4. フォーカス制御（OK）

| 操作 | フォーカスの戻り先 | 背面の操作不可・スクロール停止の解除 |
|---|---|---|
| 開いた直後 | 「キャンセル」 | — |
| 表示中に Tab を連打 | 「強化する」と「キャンセル」の間だけを移動 | — |
| キャンセル | 押した強化ボタン | 解除される |
| Esc | 押した強化ボタン | 解除される |
| 背景クリック | 押した強化ボタン | 解除される |
