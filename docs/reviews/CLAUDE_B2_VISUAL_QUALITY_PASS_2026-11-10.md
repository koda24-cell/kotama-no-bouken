## 2. 直したこと

- **岩盤・石板・淡い石**：割れ目・層・粒の高さから色テクスチャと**法線マップ**を作り、凹凸に光が当たるようにした
- **照明**：環境光を 1.0 に下げ、霧を 0.03 にして奥を沈めた。カメラに付いて動く**手元の灯り**（第2階層だけ）で近くの起伏を見せ、遠くは結晶・滝の光で見せる。濡れた石・水面・結晶に**映り込み**（小さなグラデーション画像から作る環境マップ）
- **壁**：通路側の面1枚（12×11分割）に。下端を床の起伏より下まで伸ばし、通路への張り出しは最大 0.15m
- **天井**：垂れ下がりを最大 0.45m に。氷柱・岩の稜線・庇・結晶は `ceilY()` で実際の天井面に根元を付ける
- **氷柱**：長さの違う細い氷柱を3〜5本寄せた房（氷の素材）に置き換え。v8 の丸い氷塊は使わない
- **壁の中腹の球状の岩・横棒の鉱脈**：置かない。鉱脈の光は壁の根元の小さな結晶に移した
- **床**：目地をマスごとにずらし、すき間を黒い穴ではなく浅い目地にした
- **共有素材**：第2階層に置いた複製だけ、緑を霜の青白へ寄せる（元の素材・第1階層は変更なし）
- **水**：不透明度 0.66、浅瀬の底を明るい小石に。泡の輪を薄く、しぶきを細かく
- **魚**：浅瀬の水中（水面と底の間）をマスの中で回遊する影に移した（進む向きに頭を向け、尾を小さく振る。基準点の円からはみ出さない）
- **吹き抜け**：光の柱を加算合成で淡く・天井より上から、水面の光をぼかした斑点に。石材・岩・氷は静的バッチへまとめ（約180→13メッシュ）、作り直し時に破棄
- **滝**：帯を壁から 0.3m 手前へ
- **版番号**：`field-3d-view.js` と第2階層モジュールを `20261110-b2q` に更新

## 5. 第2弾（イメージ画像を受けて・同日）

ユーザーからのイメージ画像（発光する青い鍾乳洞）と要望「もっと鮮やかで明るく」「床のタイル感をなくす」「壁・鍾乳洞のとげとげ感とスケール感」に合わせて見直した。

| 項目 | 変更 |
|---|---|
| 色・明るさ | 霧を明るいシアンにし、奥が光ってかすむ空気遠近に。岩・天井を鮮やかな青へ、水・滝・結晶・氷の発光を強めた。第2階層だけ露出を 1.45 に（第1階層へ戻ると元の値に戻ることを確認） |
| 床 | 石板（タイル）をやめ、隣のマスと続く自然な岩盤に。くねって途切れる**光る水脈**（発光マップ）と、光る水たまりを散らした。最初はボロノイの境目をそのまま光らせて六角形のタイルに見えたため、座標のゆがみと途切れを加えた |
| スケール | 見た目の天井を **7m** に上げた（通行判定・目の高さ1.6mは不変）。滝も天井から落ちる高さに。吹き抜けも同じだけ持ち上げた。天井を上げて門の上に隙間ができたので、門の上を岩でふさいだ |
| とげとげ感 | 壁に鍾乳石の幕のような縦の襞（ひだ）と深い起伏。壁ぎわに**石筍**（最大約4m）と**鍾乳石**（最大約3.5m）の房を1つの壁に最大2か所ずつ、部屋の上に長い鍾乳石、4マスが通れる角に**床から天井まで届く柱**。物（門・宝箱・NPC）のあるマスと合図石・立て札の壁には置かない |
| 演出 | 天井から落ちる光る細い水流（フロア最大10本）、空中を漂う光の粒、壁ぎわの光るキノコを大きく・多く |
| 陰影 | 縦向きの面は床に近いほど暗くし、手前は暗く奥は明るい立体感に |
