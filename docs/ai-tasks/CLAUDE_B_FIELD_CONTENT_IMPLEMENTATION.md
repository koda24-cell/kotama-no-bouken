# Claude B 実装指示：迷宮のサブイベント・探索コンテンツ拡充

対象リポジトリ：`koda24-cell/kotama-no-bouken`  
基準ブランチ：最新 `development`  
担当：Claude B  
作業種別：実装  
優先度：中〜高

## 目的
既存の第1〜第5階層を、ボスへ進むだけでなく探索する意味のある迷宮にする。今回はテスト担当ではなく、探索コンテンツの実装担当とする。

## 既存仕様を維持
- 1エリア＝1階層、各階層3フロア。
- 既存のマップ構造、階段、導きの灯、宝箱、採取、FOE、ボスゲートを壊さない。
- 既存のストーリーシーンID・フラグ・一度きりイベントの挙動を維持する。
- 既存セーブデータの探索位置・既読フラグ・取得済み宝箱などを壊さない。

## 実装内容
- 既存NPCとマップ上の空きオブジェクトを活用し、各階層に探索中に発見できるサブイベントを追加する。
- NPC会話、看板、隠し通路の先の発見、採取地点に関係する短いイベントなど、既存のフィールド機能で実現できる範囲を優先。
- 報酬は既存のゴールド・素材・消耗品を利用する。新規通貨や複雑な独自システムは追加しない。
- 一度取得した報酬を再取得できないよう、既存のセーブ可能なフラグ方式に合わせる。
- 各階層で最低1つ、可能なら各フロアに探索目的を設ける。

## 作業方針
- 既存の `field.js` のイベント・フラグ・会話APIを読み、既存機構を再利用する。
- 大規模なマップ再配置は避け、現在の通行可能領域と座標を尊重する。
- ストーリーの大筋や既存キャラクター設定を変更しない。
- 仕様が不明な報酬や条件は既存データから妥当な範囲で選び、PRに明記する。

- 数px単位のUI調整
- BGMの最終決定
- 既存マップ全体の作り直し
