# Claude A 実装指示：職業変更システム

対象リポジトリ：`koda24-cell/kotama-no-bouken`  
基準ブランチ：最新 `development`  
担当：Claude A  
作業種別：実装  
優先度：高

## 目的
既存キャラクターの成長を長期的に活かせる職業変更の仕組みを追加する。

## 確定している条件
- 職業変更時、対象キャラクターのレベルを **5下げる**。
- 既存のキャラクター・職業データ・スキルツリー・装備・セーブデータを壊さない。
- 現在の職業解放条件（ステージクリアに応じた解放、インペリアルの隠しボス条件）を維持する。
- 変更前のレベルが5以下の場合の扱いは、レベル1を下限とする。
- 変更時にレベル経験値をどう扱うかは、現行レベル仕様と整合する方式を採用し、仕様書に明記する。

## 実装前に確認すること
現行コードではキャラクターIDと職業IDが強く結び付いている。単純に `character.id` を書き換える実装は禁止。
既存の `EXT_NEW_JOBS`、`characters`、`characterLevels`、`levelExp`、`equipment`、`skillLevels`、`unlockedSkills`、セーブ形式を確認し、キャラクター個体の識別と職業データを安全に分離できる方式を設計する。

## 実装範囲
- ホーム／育成画面から職業変更を開始できる導線
- 解放済み職業の選択
- 変更前後の職業・能力値・レベルのプレビュー
- 確認ダイアログとキャンセル
- 職業変更確定時のレベル5低下
- 職業に応じた装備適性・スキル・ステータスの切替
- セーブ／ロードへの保存と旧セーブ互換性

## 禁止事項
- 既存キャラクターを別IDへ単純置換して、装備・経験値・育成値を消失させない。
- 既存スキルツリーや戦闘処理を無断で作り直さない。
- 職業解放条件を変更しない。
- 今回は細かなレイアウト磨き込みや動作検証に時間を使わない。

## 不明点の扱い
キャラクター個体と職業を分離する前提が現行仕様と矛盾し、正しい実装を確定できない場合は、推測で進めず、実装可能な範囲まで進めたうえで残る設計判断をPRに明記する。
