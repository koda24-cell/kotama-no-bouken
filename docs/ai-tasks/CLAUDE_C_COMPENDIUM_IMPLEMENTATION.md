担当：Claude C  
作業種別：実装  
優先度：中〜高

## 目的
現在のモンスター図鑑は主にステージボス5種と隠しボスを対象としている。迷宮で遭遇する通常敵・亜種・FOEも記録できるようにし、探索と討伐の積み重ねが図鑑に残る仕組みを作る。

## 実装内容
- `data/field-maps.js` の通常敵・FOE定義を確認し、図鑑対象を一覧化する。
- 遭遇時に「遭遇済み」、討伐時に「討伐済み」を記録する。
- 通常敵、亜種、FOE、ステージボス、隠しボスを分類して表示する。
- 遭遇前は名前・画像・能力値を伏せ、遭遇後は名前、討伐後は能力値・属性・弱点・耐性・説明を表示する。
- 既存の5種図鑑と隠しボス解放条件は壊さない。既存条件を拡張する場合は、現在の条件を維持したうえで追加対象を明確にする。
- 既存セーブデータでは新規項目を未遭遇として初期化し、ロードエラーを起こさない。

## 実装方針
- 敵IDを主キーにする。表示名だけをキーにして同名の敵・幻影・亜種を混同しない。
- 既存の `registerEncounter`／`registerDefeat` と敵出現処理の接続を調べ、二重登録や討伐数の二重加算を防ぐ。
- 敵の能力値は既存の敵データを参照し、図鑑用に数値を複製しない。
- FOEを通常敵と区別して表示する。
