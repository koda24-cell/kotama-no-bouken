# 第4階層「竜炎の迷宮」3D制作・品質改善の恒久指針

更新日: 2026-11-10
対象: `koda24-cell/kotama-no-bouken` / 第4階層
用途: GPT・Claude・定期品質改善タスクが**毎回着手前に参照**する制作基準。

## 1. 世界観と空間の核（ユーザー確定）
- テーマは**ドラゴンと火**。鉱石とマグマがあふれる灼熱の岩石洞窟。
- 火山洞窟の複数箇所に**放棄された炭鉱跡地**を設ける。トロッコ、線路、つるはし、採掘設備、支柱などの造形が必要。
- 岩陰・遮蔽物・死角が多く、**警戒箇所の多い緊張した探索空間**。ただしゲームの視界・通行判定・FOE挙動を勝手に変更しない。
- 植生は枯れ果て、緑は基本的にない。荒涼とした寂しい印象と、マグマの熱量の対比。
- 遠景・一部の印象的な場所には巨大な火山城塞、尖塔、神殿めいた石造建築、石橋、崖、溶岩河川を配置してよい。ただし**主題は火山洞窟・鉱石・炭鉱・ドラゴン**であり、城塞都市一辺倒にしない。

## 2. 造形最優先（ユーザー確定）
- **GPT担当はモデルの形状・構造・シルエット・バリエーション・密度。** Claudeが質感・テクスチャ・ライティング等の調整を担う。質感の微調整よりモデル造形を優先する。
- 岩を単純な箱にしない。尖った突起、抉れ、断層、重なり、非対称な稜線、大胆な亀裂、崩れた断面を形状として作る。
- 神殿・地面・橋・建物の欠損は**遠くからでも分かる大きさ**に誇張する。小さな欠けを貼るだけで済ませない。
- 鉱石・岩・その他素材は**巨大・中型・小型**を用意し、単一サイズの均等配置を避ける。密集・重なり・群生によって新しい大きなシルエットを生む。
- 主役となる巨大形状、周辺の中型群、小型破片の3段階を意識する。細部だけでなく、引いた視点で輪郭の違いを確認する。
- 岩陰や死角の演出は重要だが、進路・敵・FOE・操作対象を不当に隠さない。プレイヤーが警戒できる情報を残す。

## 3. 必須モデル群・優先順位
1. **火山岩盤と地形**：突出した巨大岩、オーバーハング、裂けた断崖、崩落群、岩のアーチ、玄武岩の柱状節理、段差。
2. **鉱石群**：大型鉱脈、巨晶の束、壁から噴き出す結晶、大小のクラスター、採掘された断面。
3. **マグマ地形**：溶岩河川、溶岩滝、冷却した浮島、黒い殻の破砕面、噴出口。形状・高低差を先に作る。
4. **炭鉱跡地**：レール、トロッコ（空・鉱石積載・転倒）、つるはし、支柱、滑車、巻上機、採掘穴、崩落した坑道。
5. **枯死・荒廃の小物**：焼け焦げた根・枯木・煤けた残骸、崩れた資材、廃棄工具。緑の豊かな植生は避ける。
6. **大型ランドマーク**：巨大城塞、尖塔、石橋、門、神殿跡。破損を大胆に表現し、火山洞窟の一部として配置する。
7. **ドラゴンの存在感**：巨大な爪痕、焼けた岩肌、鱗状の残骸、骨、巣の痕跡など。ストーリー・敵配置・戦闘条件は変更しない。

## 4. 配置と品質
- 同じオブジェクトを規則的に敷き詰めず、密度の高い塊と空白を対比させる。
- 炭鉱の小物は単品の点在で終わらせず、**採掘現場として意味の通るセット**にする。
- 壁・地形の接合、浮き、モデル貫通、縮尺を確認する。大きな素材を優先する一方、画面を覆う過密配置は避ける。
- できれば再利用できる独立モデル／モジュールにし、材質を後からClaudeが差し替えられる構造とする。
- 描画負荷を考慮してインスタンシング・距離別表示・共有ジオメトリを検討する。数を増やすだけで品質改善としない。
- **品質評価**：遠景のシルエット、形状の誇張、大小の対比、群生の造形、炭鉱らしさ、火山らしさ、探索時の視認性、負荷。

## 5. 開発と安全ルール
- 毎回 `development`、第4階層関連コード・素材、最新PR、他階層の自動改善タスクを確認し、作業重複と競合を避ける。
- 通行判定、FOE、イベント、セーブ、他階層を維持。設定やゲーム進行を独断で増やさない。
- 独立ブランチに実装し、`development` 向けPRを作る。**`main` はマージしない**。
- 実機描画・FPSテストをしていなければ、必ず「未実施」と報告する。
- 既存の未統合PR（例：#164 #167 #172 #174 #178 #179 #182 #194）を毎回確認し、現在の状態を再取得する。PR番号は固定の進捗保証ではない。
