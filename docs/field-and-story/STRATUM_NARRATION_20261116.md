# 第1〜5層・初回侵入ナレーション（2026-11-16）

## 実装範囲
- `data/progression.js` のステージ導入イベント本文を以下の文面へ変更。
- `field/field-navigation.js` の初回侵入時再生対象に第5層を追加。
- 既存の導入イベントID（`forest-intro`, `goblin-intro`, `wolf-intro`, `dragon-intro`, `maou-intro`）を維持し、既存の `eventRead` セーブデータを利用。
- イントロを見終わった後（スキップを含む）既読として保存し、そのセーブでの再訪は自動再生しない。**イベント回想機能による任意再生は従来どおり可能**。
- 既に旧イントロを既読としている既存セーブについては、互換性優先で新イントロを**自動的に再再生しない**。新規ゲームで初回再生できる。
- 第6層は現状未実装のため本文なし。
- マップ個別の `enterScene`、旧プロローグ、ボス撃破後の旧イベントは今回変更しない。新ストーリーとの整合性調整は別PR。

## 既読判定・データ互換性
- `fieldPlayStageIntro` は `eventRead[ev.id]` を参照。
- `openEvent` の正常終了とスキップ終了時に `eventRead[id]=true`。
- `createSaveData().eventRead` に含まれるため、オートセーブ・手動セーブ・ロードで保持される。
- `fieldEnterArea` の導入完了後に `persistAutoSave()` を呼んで保存する。
- 戦闘画面からの同じIDの導入イベントについても既存の既読判定を共有し、重複自動再生を避ける。
- `stageEvents` のクリア後イベントは不変更。
