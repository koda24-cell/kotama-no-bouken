# 第1層イベント全面再構成 — 新人冒険者・地図試験・救援作戦

作成日：2026-11-16。独立PR向け。**シナリオはユーザーの決定した骨格を尊重し、細部の会話・先輩の名称・難易度数値は調整可能な実装案**。

## 前提と目的
- 主人公陣営は一攫千金を夢見て街へ来た新人冒険者のギルド。冒険者は採取・討伐・測量・探索・情報収集を仕事とする。
- 街は迷宮の恵みで栄え、最奥ですべての夢がかなうという伝承がある。
- 騎士団の調査隊が増えた魔物や異変を調べているが被害は拡大中。
- 第1層の1F〜3Fを「新人試験→先輩との交流→救援要請→孤立した調査隊→ボスの共同討伐」という筋で統一。
- 魔王と災厄の詳細は第1層で明かさない。
- 第1層の**初回入場ナレーション**（`data/progression.js` の `forest-intro`）は変更しない。以前のPR #434の文章が流れる。
- キャラクリ・ギルド結成のUIは将来のイラスト実装後に対応。現行の戦闘チュートリアルは維持。

## 1F：地図試験
1. 初回プロローグは、迷宮都市・最奥の伝承・近年の騎士団調査の背景。
2. 第1層入場：衛兵から新人地図試験を受ける。
3. 条件：
   - 1F地図の踏破率が **25%以上**（仮設定）。
   - 全体MAPで「宝箱」を選び、**発見済みの実際の宝箱マス**をクリックして記録。
   - 同様に「扉」を選び、**発見済みの実際の扉マス**をクリックして記録。
4. 規定を満たして2Fへ進もうとすると、衛兵へ地図を提出し合格判定。**80G＋ポーション×2**を一度だけ配布。
5. 未達成なら必要条件と達成状況を表示し、2Fへの進行を止める。MAPの目印は `fieldState.flags["a1:mark:chest:x:y"]` などで永続保存。
6. 1Fで既存の鉄格子・レバー・隠し箱・採取・宝箱・FOEは維持。1Fの切り株から調査隊の地形調査票を見つけるサブイベントを再構成。

### 地図の操作
- MAPで「宝箱」「扉」種別を選択し、対象位置をクリック。未探索／違うマスへの指定は拒否。
- 記録したアイコン位置に白い枠がつく。マーク状態はオートセーブ・手動セーブに入る。
- 既存の自動アイコン表示は保持し、試験ではプレイヤーによる**手動記録**を要求。
- 見た目・数値・対象種類は後から拡張可能。スマホ操作テストは未実施。

## 2F：普通の冒険から救援要請へ
- 初回到着時に先輩冒険者の**二人組**と会話。初仕事と安全な探索について助言。
- 任意会話：先輩たち、巡回衛兵、騎士団の伝令、別ギルドの冒険者（採取と迷宮経済の話）。
- 任意イベント：補給袋を見つけ、従来の回復品やゴールドを受け取る。
- **奥の階段付近を通過するだけ**で、負傷兵が3Fから逃れて来る強制イベントが起きる。
- 負傷兵の報告：本来いない大型魔物が調査隊を襲い、連絡が断絶。
- 二人組は分担。先輩Aが3Fで救援・戦闘、先輩Bが負傷者護衛・出口確保。
- 任意会話を見逃しても、到着時と緊急イベントで二人の関係が伝わる。位置イベントを見逃しても2F→3F階段操作時に必ず発火。

## 3F：孤立と共同ボス戦
- 3Fに入った時点で、損壊した装備、孤立した衛兵、連絡断絶を強制会話で提示。
- 3Fには既存NPCマスを再利用して「孤立した衛兵」と「先行した先輩冒険者」を配置。
- 任意イベント：1Fで拾った調査票を衛兵へ渡して救援資料とし、既存の報酬（60G＋エーテル×1）を受領。スライム素材3個を応急薬に使い、ポーション×3受領。
- **ボスゲート付近に接近すると**救援隊の苦戦を描写する強制イベント。
- ボスゲートで先輩が敵を半分まで追い詰めた後、主人公たちへ戦闘を引き継ぐ。
- 既存`SNOWDRIFT_BOSS_DATA`を複製して第1層**フィールドゲート経由限定**の調整版ボスに使用する。最大HP **740**、初期HP **370（50%）**、ATK32・SP ATK30・DEF10・SP DEF9（調整可能な初期値）。
- 新規の敵AI・報酬・セーブ機能を上書きせず、通常の初期戦・チュートリアル・他階層への影響を抑える。
- ボス撃破時の旧「スライム撃破」エピローグを「孤立した衛兵・先輩の救援成功」に変更。

## イベントフラグと再訪時動作
| フラグ／ID | 意味 |
|---|---|
| `prologue`, `a1-enter` | 初回の世界説明と新人試験説明（旧ID維持） |
| `a1:mark:chest:x:y`, `a1:mark:door:x:y` | MAPの手動記録 |
| `a1:exam-passed` | 1F地図試験合格・報酬取得済 |
| `a1:second-floor` | 2F到着イベント既読 |
| `a1:alarm` | 2F奥の負傷兵・先輩の役割分担 |
| `a1:third-floor` | 3F到着イベント既読 |
| `a1:besieged` | 3Fボス付近の調査隊の苦戦 |
| `a1:senior-fought` | 先輩との共闘ボスを開いたこと |
| `side:a1-old-stump`, `side:a1-axe-return`, `side:a1-herb-medicine`, `side:a1-root-cache` | 従来の報酬フラグ／互換性のためID維持 |

既存データでのアイテム報酬・FOE・宝箱・探索履歴・既読フラグは**リセットしない**。以前からのプレイヤーは一部旧シーンが既読になっているため、そのシーンは自動では読み直さない。地図試験は追加された独立の初回フラグで管理。

## トリガーの安全性
- フロア移動した瞬間のイベントは `fieldGoFloor` / `fieldEnterArea` の末尾で順番に開始。
- 移動時のイベントは `fieldAfterMove` から呼び出し。該当階層・座標のみで、未読フラグのとき一度だけ。
- キー入力をロックするのは既存の `fieldPlayScene`。再訪時にはフラグで再生しない。
- 2Fの救援要請は階段そのものでも補完し、見逃しを防ぐ。
- 大事なシーンがサブNPCの調査に依存しない設計にする。

## ユーザーに見直してほしい調整箇所
- 試験の踏破率（暫定25%）、試験報酬。
- 先輩二人組の名前・容姿・職業・性別（現時点では仮の話者名のみ）。
- 3Fのボス外見・ステータス・演出。現在は仮に巨大な獣／スノードリフト素材を使用。
- 怪我の描写、死亡者の有無、先輩の戦闘後の状態。
- 騎士団と街の管理機関の正式名称。
- ボス撃破後の街への帰還・報告シーンを追加するか。
