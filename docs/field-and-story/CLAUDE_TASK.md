# Claude担当作業指示：フィールド処理・エンカウント・ストーリー基盤・アナライズ

関連：`README.md`（分担表）、`FIELD_SPEC.md`（共通インターフェース）

## 担当範囲

### C1. 敵アナライズの開閉式化（ユーザー直接依頼）
- 常時表示の `#enemy-analysis` をやめ、`.battle-arena` の端に「敵」「味方」ボタンを置く。
- ボタンでパネルを開き、敵・味方それぞれの状態を確認できるようにする（`FIELD_SPEC.md` 6章）。
- 敵の能力値開示ルール（2回目の遭遇で開示）は変えない。
- 見た目は仮。最終的な見た目は GPT（G7）が調整してよい。

### C2. フィールドエンジン
- 見下ろし型の自由移動（8方向、斜めは速度補正）。マス単位ではなくピクセル単位で滑らかに動く。
- 当たり判定は主人公の足元の小さな矩形と、通れないマスの矩形で行う。
- カメラは主人公を中心に追従し、マップ端で止まる。
- 入力：キーボード（矢印/WASD、Z/Enter=調べる、X/Esc=閉じる）、タッチ（バーチャルパッド・Aボタン）。
- フィールド以外の画面ではループを止め、入力を受け付けない。

### C3. ランダムエンカウント
- 安全地帯以外を歩いた距離で歩数を数え、エリアごとの `min`〜`max` の間で決めた歩数に達したら戦闘。
- 出現敵はエリアの `table`（重み付き）。雑魚敵は `ai` 形式で既存処理を使う。
- 戦闘への接続は `battleState.encounterMode` で区別し、雑魚戦では：ステージクリア・ランク・スキルポイント・ステージ演出・ボス演出を発生させない。ゴールド・素材・実績・討伐数は加算する。
- 勝利 →「フィールドへ戻る」、撤退 → フィールドへ戻る、敗北 → ホーム（次回は最後の導きの灯から）。
- ボスゲート → ボス前会話 → 従来の `startBattle(stage)`（HP/SP全回復、数値は不変）。勝利後の「次へ」で次エリアのフィールドへ。

### C4. ストーリー基盤
- 会話ウィンドウ（文字送り、タップ/キーで全文表示→次へ、選択肢「はい/いいえ」）。
- NPC・看板・宝箱・導きの灯・出口・ボスゲートを「調べる」で処理。
- 初回入場の会話、既読フラグ、`once` / `repeat`、`ifParty`。
- 既存のステージ導入イベント（`forest-intro` など）は、ボス戦前ではなく**エリア初回入場時**に再生する（IDは変えない）。

### C5. シナリオ初稿
- プロローグ（ホームからの初出発）、各エリアの入場・NPC・看板・ボス前会話。
- 既存のステージ導入・クリアイベントの文章と矛盾しないようにする（魔法の石像・樹海・炎竜・魔王城）。
- 編成によって会話が破綻しないよう、コタマ以外のセリフは `ifParty` を付ける。

### C6. セーブ互換
- `field` 項目の追加と旧セーブの補完。戦闘中セーブに `encounterMode` を保存。
- 雑魚敵のアナライズ開示用の遭遇回数を保存（既存の `enemyEncounterCounts` は図鑑名だけを読み込むため）。

### C7. `field:*` イベント
- `FIELD_SPEC.md` 3章のイベントを発火する。通知のみで処理は待たない。

## 禁止事項
- 既存ボス・既存敵の数値、ダメージ計算、行動順、スキル効果を変えない。
- 既存イベントID・実績ID・ステージ番号を変えない。
- GPT担当の最終的な見た目・素材制作を独断で確定しない（仮スタイルと明記する）。
