# GPT担当作業指示：フィールドの見た目・演出・素材・シナリオ推敲

関連：`README.md`（分担表）、`FIELD_SPEC.md`（共通インターフェース）、`CLAUDE_TASK.md`

**着手条件：** Claude のフェーズ1b PR（`feature/ai-claude-field-story`）を読んでから着手する。マージ前でもブランチを参照してよい。`FIELD_SPEC.md` に無い情報が必要な場合は、推測で `field.js` を書き換えず Claude に追加を依頼する。

## 担当範囲

### G1. フィールドのタイル
- エリアごとのテーマ：`forest`（はじまりの樹海：明るい緑）、`goblin`（ゴブリンの森：踏み荒らされた道・柵）、`mist`（霧の森：青白い霧）、`lava`（焦土の溶岩洞窟：赤黒い岩と溶岩）、`castle`（魔王城・回廊：冷たい石畳）。
- `#field[data-theme] .tile-*` に対してスタイルを付ける。画像タイルを使う場合は `assets/field/` に半角英数字で置く。
- 壁と通路の区別が一目で分かること（当たり判定と見た目がずれないこと）。

### G2. キャラクター・オブジェクトの見た目
- 主人公（コタマ）：4方向 × 歩行コマ（`data-dir` / `data-moving` / `data-step`）。既存の `assets/characters/kotama.png` の設定に合わせたオリジナル素材。
- NPC・看板・宝箱（開閉）・導きの灯・ボスゲート・出口：`[data-kind]` と `[data-sprite]` で切り替え。`data-sprite` の一覧は `data/field-maps.js` の `objects` を参照。
- 素材が揃うまでは仮表示でよいが、仮であることを PR に明記する。

### G3. 会話ウィンドウ
- 画面下部の黒地・白枠を基本に、顔グラ枠（`portrait` が無い話者は枠を隠す）、名前、本文、▼送りマーク。
- 文字送り音は任意（`field:dialog:line` を使う）。既存SEを使う場合は音量を既存設定に合わせる。
- スマートフォンで本文が2〜3行に収まること。

### G4. エンカウント・入場演出
- `field:encounter` で「！」→画面点滅→暗転。`detail.delay`（既定900ms）以内に収める。
- `field:enter` でエリア名の表示（初回のみ・毎回は任意）。

### G5. バーチャルパッド
- `#field-pad` の配置・大きさ。親指で押しやすく、マップを隠しすぎないこと。PC幅では小さく、または非表示にしてよい（キーボード操作あり）。

### G6. シナリオ推敲
- `data/story.js` の `text` だけを推敲する。シーンID・`who`・`setFlag`・`once`・`ifParty` は変えない。
- キャラクターの口調を戦闘中のセリフ音声（`assets/serihu/`）と揃える。

### G7. アナライズパネルの見た目（任意）
- `FIELD_SPEC.md` 6章の DOM に対して見た目を整える。表示項目の追加が必要なら Claude に依頼する。

## 禁止事項
- `field.js` の移動・判定・エンカウント・セーブ処理、`script.js` の `[FIELD]` / `[ANALYZE]` フックを変更しない。
- 戦闘の数値・行動・ログ文言を変えない。
- 既存素材を削除・上書きしない。参考作品（アンダーテール等）の画像・文章を流用しない。
