# ゲームデータの管理

> リポジトリ全体の構造と注意点は、ルートの `AI_HANDOFF.md` を先に読んでください。

ゲームの固定データは、このフォルダ内の JavaScript ファイルで管理します。画面表示・戦闘進行・セーブ処理などのロジックは、原則として `script.js` と `battle-ext.js` に置きます。

## ファイルの役割

| ファイル | 管理する内容 |
|---|---|
| `battle-rules.js` | 基本戦闘ルール、職業補正、属性・ブレイク倍率 |
| `characters.js` | 初期6職業の能力値・基本スキル、ユニオンスキル |
| `jobs.js` | 追加6職業の能力値・SPスキル・素早さ・解放条件・初期装備 |
| `items.js` | 店売り装備、アクセサリ、製作レシピ、追加職業専用武器、強化素材 |
| `enemies.js` | 敵の基本能力値・属性・弱点・報酬 |
| `enemy-variants.js` | 1〜3面に出る追加の敵（毒スライム・ゴブリンアーチャー等）の能力値と行動パターン |
| `boss-phases.js` | 魔王のフェーズ行動（連撃・終焉の闇・魂喰らい）の確率・倍率・技名 |
| `status-effects.js` | 状態異常の定義（表示名・アイコン・悪い効果かどうか） |
| `progression.js` | ストーリーイベント、成長ポイント設定、実績 |
| `skill-trees.js` | スキルツリー、派生スキル、旧スキルとの対応表 |
| `field-maps.js` | 迷宮の階層・フロア（マップ・NPC・宝箱・採取・出現敵・FOE・BGM）と雑魚敵・FOEの能力値・行動・経験値 |
| `field-gathering.js` | 採集ポイントの種別（採取／伐採／採掘）・素材テーブル・回数・再出現ルール（`field-maps.js` の後に読み込む） |
| `levels.js` | レベル上限・必要経験値・成長率・ボスの経験値 |
| `story.js` | フィールドの会話シーンと話者 |

## 変更時のルール

1. キャラクターID・アイテムID・スキルIDは、既存セーブデータや装備情報との紐付けに使うため、原則として変更・再利用しない。
2. 職業を追加するときは、`jobs.js` の職業IDと `items.js` の装備適性 `classes` を一致させる。
3. 武器は `category: "weapon"` を維持する。表示用アイコンの文字列だけでカテゴリを変えない。
4. 解放条件を変更するときは、既存セーブの補完処理 `extSyncJobUnlocks()` と矛盾しないか確認する。
5. このフォルダには固定データを置き、所持金・所持品・進行状況などプレイ中に変化する値はゲームロジック側で管理する。
6. データファイルを追加・改名した場合は、`index.html` の読み込み順も更新する。

## 読み込み順

`index.html` では、データファイルを先に読み込み、その後に `battle-ext.js`、最後に `script.js` を読み込みます。データ間の参照があるため、読み込み順は変更しないでください。

## まだ `script.js` 内にあるデータ（今後の分割候補）

次のデータは、他のAIが `script.js` を編集中のため、まだ分けていません。作業が落ち着いてから、専用のPRで分割します。

- BGM・効果音のファイル一覧（曲の割り当て表）
- チュートリアルの文言と進行段階
- ドラゴンの行動（全体攻撃・火傷）— `script.js` の `enemyTurn` 内にある
- 敵のスピード・ボス名の一覧（現在は `jobs.js` の先頭にある。敵に関するものなので、将来は `enemies.js` に移したい）

## 数値を調整するときの早見表

| 調整したいこと | 触るファイル |
|---|---|
| 敵の強さ・報酬 | `enemies.js` |
| 追加の敵（毒スライムなど）の強さ・行動 | `enemy-variants.js` |
| 魔王の連撃や闇の確率・ダメージ倍率 | `boss-phases.js` |
| 職業の能力値・スキル・スピード・解放条件 | `jobs.js` |
| 装備・アイテムの価格や効果 | `items.js` |
| ストーリーの文章・実績 | `progression.js` |
