# ゴミ箱（保留・廃止した制作データ）

このフォルダは、**不要と判定した制作データの整理場所**です。消去する前の記録を残します。

- 現行のゲームは `development` を基準に開発し、`main` は変更しません。
- 不要と判定されたファイルは、実行時参照・素材クレジット・セーブ互換・他AIの作業を確認したうえで、元の場所から `_trash/files/` に移します。
- 移動の際は元パス、理由、移動日、復元方法を台帳に記録します。元パスに依存するコードがある場合は、移動せず台帳に記載します。
- **GitHubブランチはフォルダに移せません。** 不要ブランチは `BRANCHES.md` に最終コミットSHAを保存します。ブランチを削除する場合も記録は残します。
- `_trash/` に置いたファイルもGit履歴とリポジトリ容量に残ります。機密情報・巨大ファイルの完全削除には別途履歴の扱いが必要です。
- `_trash/` は原則ゲームから参照しません。必要なものは元の場所に復元してから使用します。
