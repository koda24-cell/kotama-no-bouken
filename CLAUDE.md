# Claude / GPT shared project entry point

Read [AGENTS.md](AGENTS.md) first for project rules, branch policy, and asset approval.

## Every 3D asset task
1. Read [docs/3d/STYLIZED_GAME_TECH_LIBRARY.md](docs/3d/STYLIZED_GAME_TECH_LIBRARY.md) **before starting**. This is a shared technique/tool reference for every floor and asset category, not only Stage 3.
2. Read [docs/3d/BLENDER_DOCKER_HANDOFF.md](docs/3d/BLENDER_DOCKER_HANDOFF.md) and [docs/3d/ASSET_PROMOTION_POLICY.md](docs/3d/ASSET_PROMOTION_POLICY.md).
3. Choose techniques suitable to the current asset. Do not apply all shaders/addons indiscriminately.
4. Check tool license, installation and compatibility independently. A listed link does **not** mean a tool is installed or validated.
5. Preserve existing shapes; improve through additional geometry. Render actual front/side/angle images and export GLB.
6. Store work on isolated branches, open PRs against `development`, and do not merge unapproved assets or changes into `main`.
7. For Pinterest references, read the separate [Pinterest reference library instructions](https://github.com/koda24-cell/pinterest-reference-library/blob/main/AGENTS.md). Record GPT/Claude handoffs there.
8. Record the exact source/technique used, outcome, render evidence, and any failures for future reuse.

The research index references techniques from Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Arknights: Endfield, Blender and third-party tools. Official game models/textures or extracted assets are **not** licensed for reuse merely because research materials are public.
