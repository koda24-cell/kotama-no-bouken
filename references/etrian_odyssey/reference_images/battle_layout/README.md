# 戦闘レイアウト参考画像

このフォルダには、戦闘画面の構成・配置・情報の見せ方を研究するための参考画像を保管します。

## 見るポイント
- 味方・敵キャラクターの配置
- コマンド欄、ステータス欄、HP/SP表示の位置と大きさ
- 戦闘画面全体の幅・余白・画面占有率
- 攻撃対象や行動順の見せ方
- PC画面とスマートフォン画面でのレイアウトの違い

## 利用ルール
- 参考・研究用として扱い、画像そのものをゲーム本編へ組み込まないでください。
- 『コタマのぼうけん』へ反映する際は、既存のデザインや操作性を確認し、独自のレイアウトとして設計してください。
- 出典が分かる場合は、ファイル名または別途メモに作品名・出典を記録してください。
