# 参考画像の保管場所

このフォルダは『世界樹の迷宮』シリーズなどの参考画像を、調査・比較用に保管する場所です。

## ZIPの配置
- 参考画像をまとめたZIPは、このフォルダ直下に配置してください。
- ファイル名は内容と作品名が分かるものにしてください（例：`etrian_odyssey_reference_images.zip`）。
- ZIP内は必要に応じて `characters` / `monsters` / `backgrounds` / `ui` に分類してください。

## 取り扱いルール
- ここに置く画像は参考・研究用です。ゲーム本編から読み込まないでください。
- 他作品の画像・素材を『コタマのぼうけん』へそのまま組み込まないでください。ゲーム用素材は別途オリジナルで制作してください。
- 出典、作品名、確認できる範囲で権利表記を記録してください。
