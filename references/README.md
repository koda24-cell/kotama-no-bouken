# 参考資料

このフォルダは『コタマのぼうけん』の開発・デザイン研究用資料を保管する場所です。

- 参考画像はゲーム本体から読み込ませないでください。
- 他作品の画像はデザイン研究・比較のための参考資料として扱い、権利者の許諾なくゲーム素材へ転用しないでください。
- 画像ごとに作品名・出典URL・確認日・参考にしたい点を記録してください。
- 実装用のオリジナル素材は `assets/` 側へ配置してください。

## 分類
- `etrian_odyssey/characters/`：キャラクター・職業デザイン
- `etrian_odyssey/monsters/`：モンスター・ボス
- `etrian_odyssey/backgrounds/`：迷宮・街・背景
- `etrian_odyssey/ui/`：画面構成・アイコン・UI
- `etrian_odyssey/notes/`：仕組み・演出・調査メモ
