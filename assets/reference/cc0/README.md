# CC0 rock reference library

The source GLBs are imported by the workflow into `kenney-nature-rocks/`. Source: [Kenney Nature Kit](https://kenney.nl/assets/nature-kit), CC0-1.0. GitHub mirror: [Hidencod/tge-assets](https://github.com/Hidencod/tge-assets).

See `docs/3d/cc0-rock-library.json` for exact model URLs. Run `python tools/b4-render/fetch-cc0-rocks.py` to fetch and verify GLB headers, then review the produced `PROVENANCE.json` for SHA-256 and sizes. This is a reference library, not a game-integrated asset; quality and approval required before promotion. Do not overwrite the existing stage 4 wall geometry.
