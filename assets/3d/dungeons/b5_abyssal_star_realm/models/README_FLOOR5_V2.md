# Floor 5 — Abyssal Star Realm / Demon Throne Refined v2

Refined modular GLB prototype, building on v1.

Added:
- layered abyss rim/cliff walls to visually occlude unseen routes beyond the chasm
- broken parapets, buttresses, gate mouldings and extra rune inlays
- throne lancet frame, finials, gold details and footplate
- additional frayed banners and hanging chandelier silhouettes
- distant mechanical megastructures with emissive cyan window strips
- denser violet flame tongues, embers and starfield markers

Still renderer-side:
- true infinite cosmic sky/nebula background and depth fog
- animated flame particles, falling embers and subtle rune pulses
- dynamic lighting, volumetric shafts and post-processing
- collision meshes and path validation

This remains a detailed blockout/prototype, not final hand-authored production art. Keep visual meshes separate from collision and test in the existing 3D dungeon renderer.
