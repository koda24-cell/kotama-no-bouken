**新規：23点**
- 床：石畳、崩れた石畳、根の這う土、段差の高台
- 壁：標準、苔と細根、崩落、アーチの開口

- 環境：シダ、光る苔、FOE の踏み荒らし跡

### 品質面の工夫

**形状**
- 岩や石材は細分化した形にノイズで凹凸と欠けを入れた。
- 根・幹は中心線に沿った管にし、樹皮の溝・板根・枝分かれを付けた。
- 壁は石を1個ずつ積んでいる（崩れ具合・欠けた石・傾き）。

**質感**
- 素材は31種類。テクスチャ（色・法線・ORM、一部は発光）はすべて継ぎ目なく繰り返せる。
- 石積み・風化石・石畳・樹皮・根・古材・錆鉄・緑青の青銅・苔・土・骨・布・結晶・発光キノコ・葉・繭の糸・ルーン石を作り分けた（`renders/materials_textures.jpg`）。

**苔**
- 上を向いた面だけに苔の層を重ね、縁は厚み0にして地の面へなじませた。
- 壁では最上段と一部の石だけに載せている（全段だと縞模様に見えたため）。

**発光**
- 基本は青白〜水色。青緑、紫（錬金・結晶）、暖色（樹液）、赤紫（FOE の呪晶・爪痕）で変化を付け、危険を示す色を分けた。
- 発光物の位置・色・強さ・届く距離を、GLB の `extras.b1.lights` に記録した。シーン側で点光源を置くときに使う。

**統一したルール**
- 単位はメートル、上は +Y、正面は +Z。
- 原点は底面の中央。壁・床・天井・扉は組み立て用の原点で、各素材の説明欄に書いてある。
- 1マスは 4m、壁の高さは 4m。
- 素材ごとに1メッシュへまとめている（描画回数を減らすため）。

### 検証用シーン（第4段階）

## 2-2. ブラウザで見るプレビュー（追加）

`prototypes/b1-3d-preview.html` を追加した。ゲーム本体のコードは読み込まず、`data/field-maps.js`（迷宮データ）だけを読み取りに使う。

**モードは3つ**
- 迷宮：第1階層のマップデータ（1F〜3F）を 1マス=4m の 3D 素材に置き換え、マス単位で歩ける。
  - 置き換えは次のとおり。宝箱 T＝宝箱、採集 G＝採集ポイント3種、導きの灯 S＝床ルーンと灯火、下り階段 ＞、上り階段 ＜、鉄格子の扉、レバー（壁）、草むら＝根の土とシダ。
  - FOE の巡回の起点には足跡を置いた。
- シーン：検証用シーンを回して見る。視点は5つ。
- 素材：63点を1つずつ見る。

**操作**
- ボタン：▲▼で前後、↶↷で向きを変える、⇐⇒で横に移動。
- キーボード：W/S/A/D、矢印、Q/E。

**表示と配信**
- 低画質・高画質の切り替えあり。高画質は光のにじみあり、点光源24個。
- 必要なときだけ描画するので、止まっている間は電池を使わない。
- three.js r180 は jsDelivr から読む（GPT の first-person 試作と同じ配信元）。インターネット接続が必要。
- GLB と JSON を fetch で読むため、`file://` で直接開くと動かない。http(s) で配信する必要がある。

**確認したこと**
- ヘッドレス Chrome で、3つのモード・フロア切り替え・移動・壁への衝突・スマホ幅（390×844）の表示を確認した（`renders/preview_walk_1f.jpg`）。
- **iPhone の実機は未確認。**

## 4. 未完了・既知の問題

1. **Blender 4.x での読み込みと表示は未確認。** 環境に Blender が無いため。glTF 2.0 標準なので読める想定だが、確認していない。
2. **Khronos 公式の glTF-Validator は未実行。** 独自の構造検査で代わりにしている。
3. **iPhone の実機での表示・負荷は未確認。** シーン全体は約103万三角形で、モバイルには重い。ゲームで使うときは LOD（距離に応じた簡略版）とテクスチャの縮小が必要。今回 LOD は作っていない。
4. **容量。** 合計 38.9MB で、テクスチャは GLB ごとに埋め込んでいる（共通の素材でも重複する）。リポジトリは約98MB から約140MB に増える。Git LFS は使っていない（設定が無い）。削る案は、素材間でテクスチャ画像を共有する（.gltf と外部画像）、KTX2 に圧縮する、512px を 256px にする、のいずれか。
5. **巨大古代樹の幹が暗所で読みにくい。** シーンでは上からの光（スポットライト）で補っている。幹の色を明るくするか、発光する苔を足すと改善する。
6. **細部の造形はまだ粗い。**
   - 守護像・石像の頭部は簡略的。
   - 根の先端がやや直線的。
   - 天井ヴォールトの肋材の石に隙間が見える。
   - 布の旗は1枚の面。
7. **アニメーションは無い。** 宝箱の蓋・扉・レバーは1メッシュで、回転軸は `extras.b1.markers` に記録しただけ。動かすなら部品を分ける必要がある。
8. **GPT の first-person 試作（`assets/field-3d/b1/`）とは置き場所と寸法の約束が別。** つなぐ場合は、マニフェストの形式（`assets/field-3d/manifest.schema.json`）に合わせる変換が要る。
