# B1F scene blockout

This directory contains the first 3D scene composition for B1F「深淵に眠る樹海」.

- Main exploration lane kept open.
- Giant tree/root landmark on the left.
- Ruined gate and guardian statues at the rear.
- Stairs, shrine and well on the right.
- Blue luminous props guide the eye.
- FOE clues are placed in side areas.

The downloadable GLB scene and JSON layout are provided as a separate generated bundle in the conversation. This repository entry documents the scene composition; it does not claim that the GLB binary has been committed.

Status: visual blockout. Not wired into the live game.
